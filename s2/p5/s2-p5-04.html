수정, 삭제 API 완성

응답 모델과 상태 코드를 적용하고, 수정(PUT, PATCH)과 삭제(DELETE) API를 추가해 메모리 기반 CRUD를 완성합니다.

실습 목표도서의 등록, 조회, 수정, 삭제 API를 알맞은 상태 코드와 응답 모델로 구현할 수 있습니다.

  1. 목록과 모델 바꾸기

    앞 페이지에서 본 대로 BOOKS에 isbn과 cost를 추가하고, 기존 BookCreate 자리에 모델 세 개(BookCreate, BookUpdate, BookRead)를 작성합니다. 맨 위 가져오기 줄에는 status를 추가합니다.

    main.py
    from fastapi import FastAPI, HTTPException, status

  2. 도서 찾기 함수로 중복 줄이기

    조회, 수정, 삭제 모두 "번호로 도서를 찾고, 없으면 404"라는 같은 일을 합니다. 이 부분을 함수 하나로 묶습니다.

    main.py
    def find_book(book_id: int) -> dict:
    for book in BOOKS:
        if book["id"] == book_id:
            return book
    raise HTTPException(status_code=404, detail="도서를 찾을 수 없습니다.")

    get_book은 이제 return find_book(book_id) 한 줄이면 됩니다.

  3. 등록 API에 201 적용

    main.py
    @app.post("/books", response_model=BookRead, status_code=status.HTTP_201_CREATED)
def create_book(book_in: BookCreate):
    new_id = max(book["id"] for book in BOOKS) + 1 if BOOKS else 1
    book = {"id": new_id, **book_in.model_dump(), "cost": 0}
    BOOKS.append(book)
    return book

    새 도서의 매입가는 아직 받지 않으므로 0으로 둡니다. 목록 조회에도 response_model=list[BookRead]를 붙입니다.

  4. 전체 수정 PUT

    main.py
    @app.put("/books/{book_id}", response_model=BookRead)
def replace_book(book_id: int, book_in: BookCreate):
    book = find_book(book_id)
    book.update(book_in.model_dump())
    return book

    PUT은 도서 정보를 통째로 바꿉니다. 그래서 등록과 같은 BookCreate로 모든 항목을 받습니다. isbn을 보내지 않으면 기본값 None으로 바뀐다는 점에 주의합니다.

  5. 일부 수정 PATCH

    main.py
    @app.patch("/books/{book_id}", response_model=BookRead)
def update_book(book_id: int, book_in: BookUpdate):
    book = find_book(book_id)
    # 보낸 항목만 꺼내고, null로 보낸 항목은 무시합니다.
    changes = book_in.model_dump(exclude_unset=True, exclude_none=True)
    book.update(changes)
    return book
    옵션하는 일
    exclude_unset=True클라이언트가 보내지 않은 항목을 뺍니다. 이 옵션이 없으면 보내지 않은 항목이 모두 None으로 덮어써집니다.
    exclude_none=True값을 null로 보낸 항목도 뺍니다. 제목에 null이 들어가 응답 모델 검사에서 서버 오류가 나는 것을 막습니다.

  6. 삭제 DELETE에 204 적용

    main.py
    @app.delete("/books/{book_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_book(book_id: int):
    book = find_book(book_id)
    BOOKS.remove(book)

    204는 돌려줄 내용이 없다는 뜻이므로 함수도 아무것도 돌려주지 않습니다.

  7. 요청 보내 확인하기

    Swagger UI에서 차례로 실행하고 결과를 적습니다. 서버가 다시 시작되면 목록이 처음 상태로 돌아가므로, 코드를 다 고친 뒤 한 번에 확인합니다.

    요청보낼 값기대하는 결과내 결과
    GET /books/1200, cost 없음
    POST /books{"title": "FastAPI 실전", "author": "최유나", "price": 27000}201, id 5
    PATCH /books/1{"price": 19000}200, 가격만 바뀜
    PUT /books/2{"title": "웹 개발 입문 2판", "author": "이도윤", "price": 24000}200, isbn이 null로 바뀜
    DELETE /books/4204, 본문 없음
    GET /books/4404

지금까지의 main.py

전체 코드 펼치기
main.py
from fastapi import FastAPI, HTTPException, status
from pydantic import BaseModel, Field

app = FastAPI(title="도서 관리 API")

# cost(매입가)는 내부에서만 쓰는 값이라 응답에 나가면 안 됩니다.
BOOKS = [
    {"id": 1, "title": "파이썬 첫걸음", "author": "김하늘", "price": 18000, "isbn": "9791100000011", "cost": 12000},
    {"id": 2, "title": "웹 개발 입문", "author": "이도윤", "price": 22000, "isbn": "9791100000028", "cost": 15000},
    {"id": 3, "title": "데이터베이스 기초", "author": "김하늘", "price": 25000, "isbn": None, "cost": 17000},
    {"id": 4, "title": "알기 쉬운 네트워크", "author": "박서준", "price": 20000, "isbn": None, "cost": 13000},
]


class BookCreate(BaseModel):
    """등록과 전체 수정(PUT)에 쓰는 입력 모델"""
    title: str = Field(min_length=1, max_length=100)
    author: str = Field(min_length=1, max_length=50)
    price: int = Field(ge=0, le=1_000_000)
    isbn: str | None = Field(default=None, pattern=r"^\d{13}$")


class BookUpdate(BaseModel):
    """일부 수정(PATCH)에 쓰는 입력 모델. 모든 항목이 선택입니다."""
    title: str | None = Field(default=None, min_length=1, max_length=100)
    author: str | None = Field(default=None, min_length=1, max_length=50)
    price: int | None = Field(default=None, ge=0, le=1_000_000)
    isbn: str | None = Field(default=None, pattern=r"^\d{13}$")


class BookRead(BaseModel):
    """응답에 쓰는 출력 모델. 여기에 없는 필드는 응답에서 빠집니다."""
    id: int
    title: str
    author: str
    price: int
    isbn: str | None = None


@app.get("/")
def read_root():
    return {"message": "도서 관리 API에 오신 것을 환영합니다."}


@app.get("/health")
def health_check():
    return {"status": "ok"}


def find_book(book_id: int) -> dict:
    for book in BOOKS:
        if book["id"] == book_id:
            return book
    raise HTTPException(status_code=404, detail="도서를 찾을 수 없습니다.")


@app.get("/books", response_model=list[BookRead])
def list_books(author: str | None = None):
    if author is None:
        return BOOKS
    return [book for book in BOOKS if book["author"] == author]


@app.get("/books/{book_id}", response_model=BookRead)
def get_book(book_id: int):
    return find_book(book_id)


@app.post("/books", response_model=BookRead, status_code=status.HTTP_201_CREATED)
def create_book(book_in: BookCreate):
    new_id = max(book["id"] for book in BOOKS) + 1 if BOOKS else 1
    book = {"id": new_id, **book_in.model_dump(), "cost": 0}
    BOOKS.append(book)
    return book


@app.put("/books/{book_id}", response_model=BookRead)
def replace_book(book_id: int, book_in: BookCreate):
    book = find_book(book_id)
    book.update(book_in.model_dump())
    return book


@app.patch("/books/{book_id}", response_model=BookRead)
def update_book(book_id: int, book_in: BookUpdate):
    book = find_book(book_id)
    # 보낸 항목만 꺼내고, null로 보낸 항목은 무시합니다.
    changes = book_in.model_dump(exclude_unset=True, exclude_none=True)
    book.update(changes)
    return book


@app.delete("/books/{book_id}", status_code=status.HTTP_204_NO_CONTENT)
def delete_book(book_id: int):
    book = find_book(book_id)
    BOOKS.remove(book)
