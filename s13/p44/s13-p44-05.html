정리: EC2

핵심 요약

주제핵심
EC2 구성AMI(Amazon Linux 2023), 인스턴스 유형(t3.micro, x86_64), EBS 8GiB, 퍼블릭 IP 자동 할당, IAM 인스턴스 프로파일
상태중지하면 EBS 요금만 남고 퍼블릭 IP가 바뀝니다. 종료는 삭제입니다.
접속키 페어 없이 Session Manager로 접속합니다. 사용자는 ssm-user이고, bash로 바꿔 씁니다.
권한 확인서버 안의 AWS CLI가 역할로 요청하고, 주지 않은 권한(S3)은 거부됩니다.
IMDSv2토큰 없는 메타데이터 요청은 401입니다.

확인 퀴즈

어제 쓴 EC2를 "중지"했다가 오늘 다시 "시작"했습니다. 달라질 수 있는 것은 무엇인가요?

퍼블릭 IP는 시작할 때마다 새로 받습니다. 고정하려면 탄력적 IP를 쓰지만, 이 과정에서는 8일차에 ALB 주소로 접속합니다.

인스턴스 시작 화면에서 보안 그룹을 "보안 그룹 생성"으로 둔 채 넘어가면 어떤 일이 생길 수 있나요?

기존 보안 그룹 선택에서 book-api-sg를 골라야 합니다.

서버 안에서 aws sts get-caller-identity의 Arn이 assumed-role/book-api-ec2-role/...로 나왔습니다. 무엇을 뜻하나요?

서버의 AWS CLI와 SDK는 인스턴스 프로파일의 역할을 자동으로 찾아 씁니다.
