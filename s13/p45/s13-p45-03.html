컨테이너로 API 실행

서버에서 도서 API 이미지를 만들고 컨테이너로 실행합니다. 데이터베이스는 다음 파트에서 RDS로 바꾸므로, 지금은 컨테이너 안의 SQLite로 동작을 확인합니다. 마지막으로 내 PC의 브라우저에서 서버의 퍼블릭 IP로 접속합니다.

실습 목표EC2에서 도서 API 컨테이너를 실행하고, 인터넷을 거쳐 내 PC에서 접속할 수 있습니다.

  1. 이미지 만들기

    cd ~/book-api
docker build -t book-api .
...

docker images book-api

    t3.micro에서는 처음 빌드에 1~3분이 걸립니다. S8에서 쓴 Dockerfile 그대로입니다.

  2. 설정 파일 만들기

    비밀 키를 서버에서 새로 만듭니다. 내 PC의 .env와 같은 값을 쓰지 않습니다. 환경마다 비밀 값을 다르게 두어야, 한 곳이 새도 다른 곳은 안전합니다(S10-P33).

    python3 -c "import secrets; print(secrets.token_urlsafe(32))"
w3Xk...(43자)

    설정 파일은 소스 폴더 밖인 홈 폴더에 book-api.env로 만듭니다. 소스 폴더에 두면 실수로 Git에 올리거나 이미지에 들어갈 수 있기 때문입니다. nano 편집기로 열어 아래 내용을 넣고, Ctrl+O, Enter로 저장한 뒤 Ctrl+X로 나옵니다.

    nano ~/book-api.env
    ~/book-api.env
    APP_ENV=development
DATABASE_URL=sqlite:///./data/books.db
SECRET_KEY=여기에_새로_만든_값
LOG_LEVEL=INFO
    chmod 600 ~/book-api.env
ls -l ~/book-api.env
-rw-------. 1 ssm-user ssm-user 112 Nov 23 10:12 /home/ssm-user/book-api.env

    chmod 600은 파일 주인만 읽고 쓸 수 있게 합니다. docker run --env-file은 따옴표를 값의 일부로 그대로 읽으므로, 값을 따옴표로 감싸지 않습니다. /docs로 동작을 확인하려고 APP_ENV는 아직 development로 둡니다. 운영 설정(production)은 S14에서 바꿉니다.

  3. 컨테이너 실행

    실행 명령
    docker run -d --name book-api \
  -p 8000:8000 \
  --env-file ~/book-api.env \
  -v book-data:/app/data \
  -v book-uploads:/app/uploads \
  --restart unless-stopped \
  book-api
    옵션뜻
    -p 8000:8000서버의 8000번 포트를 컨테이너의 8000번에 연결합니다. 보안 그룹이 연 포트와 같습니다.
    --env-file설정 파일의 값을 컨테이너의 환경 변수로 넣습니다.
    -v book-data:/app/dataSQLite 파일을 볼륨에 둡니다. 컨테이너를 지우고 다시 만들어도 남습니다(S8-P26).
    --restart unless-stopped컨테이너가 죽거나 서버가 재부팅되면 다시 시작합니다. 직접 멈춘 경우는 제외합니다.
    docker ps --format "{{.Names}}  {{.Status}}  {{.Ports}}"
book-api  Up 5 seconds  0.0.0.0:8000->8000/tcp

docker exec book-api alembic upgrade head
...

  5. 내 PC에서 접속

    내 PC의 브라우저에서 http://퍼블릭IP:8000/health를 엽니다. 이어서 http://퍼블릭IP:8000/docs에서 회원가입, 로그인, 저자 등록을 해 봅니다.

    curl http://3.35.120.45:8000/health
{"status":"ok","database":"ok"}

    휴대폰의 모바일 데이터처럼 다른 네트워크에서 열면 연결되지 않아야 합니다. 보안 그룹이 내 IP만 허용하기 때문입니다.
