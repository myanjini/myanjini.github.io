Docker 설치와 소스 받기

EC2 서버에 Docker, Git, Compose, Buildx를 설치하고, GitHub에서 도서 API 소스를 받습니다.

실습 목표서버에 Docker를 설치해 자동 시작되게 하고, 도서 API 소스를 받아 둘 수 있습니다.

  1. Docker와 Git 설치

    Session Manager로 접속해 bash로 바꾼 뒤 실행합니다.

    sudo dnf install -y docker git
sudo systemctl enable --now docker
sudo usermod -aG docker ssm-user
...
Complete!
Created symlink /etc/systemd/system/multi-user.target.wants/docker.service → /usr/lib/systemd/system/docker.service.

  2. 다시 접속해 그룹 적용

    그룹 변경은 새 세션부터 적용됩니다. 브라우저의 Session Manager 탭에서 종료를 누르고 다시 연결한 뒤 확인합니다.

    bash
cd ~
id
uid=1001(ssm-user) gid=1001(ssm-user) groups=1001(ssm-user),992(docker)

docker version --format "Client {{.Client.Version}} / Server {{.Server.Version}}"
Client 25.0.14 / Server 25.0.14

systemctl is-enabled docker; systemctl is-active docker
enabled
active

    groups에 docker가 보이고, sudo 없이 docker version이 서버(Server) 버전까지 보여 주면 됩니다. 버전 숫자는 설치한 날의 저장소에 따라 다릅니다.

  3. Compose와 Buildx 설치

    Windows에서 실행할 때

    아래 명령에는 bash 문법(이름=값, $(...) 등)이 들어 있습니다. 내 PC가 Windows라면 명령 프롬프트가 아니라 Git Bash에서 실행합니다(S12-P40-03). EC2 서버의 접속 화면에서 실행하는 명령은 그대로 입력합니다.

    sudo mkdir -p /usr/local/lib/docker/cli-plugins
sudo curl -fsSL -o /usr/local/lib/docker/cli-plugins/docker-compose \
  https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64
BUILDX_VERSION=v0.39.1
sudo curl -fsSL -o /usr/local/lib/docker/cli-plugins/docker-buildx \
  https://github.com/docker/buildx/releases/download/$BUILDX_VERSION/buildx-$BUILDX_VERSION.linux-amd64
sudo chmod +x /usr/local/lib/docker/cli-plugins/docker-compose /usr/local/lib/docker/cli-plugins/docker-buildx

docker compose version
Docker Compose version v5.8.0
docker buildx version
github.com/docker/buildx v0.39.1 ...

    Compose는 최신 버전을 받으므로 숫자가 다를 수 있습니다.

  4. 소스 받기

    내 GitHub 저장소 주소로 받습니다. 저장소 화면의 초록색 Code 버튼에서 HTTPS 주소를 복사합니다.

    git clone https://github.com/내아이디/book-api.git
cd book-api
git log --oneline -3
ls
Dockerfile  alembic.ini  app  compose.yaml  migrations  requirements.txt  tests  ...

    비공개 저장소라면

    비공개 저장소는 git clone할 때 아이디와 비밀번호를 묻습니다. 비밀번호 자리에는 GitHub 비밀번호가 아니라 토큰을 넣습니다. GitHub의 Settings, Developer settings, Personal access tokens, Fine-grained tokens에서 이 저장소 하나만, Contents 읽기 권한만, 만료 7일로 토큰을 만듭니다. 받은 뒤에는 서버에 토큰이 남지 않도록 Git이 비밀번호를 저장하지 않게 두고(기본값), 오늘 오후에 ECR로 바꾸면 토큰을 삭제합니다.
