실습 목표배포된 API로 시연하고, 설계 의도와 보안 조치 하나를 근거와 함께 설명할 수 있습니다.

    회고 한 문장

  2. 시연 스크립트 준비

    예시 프로젝트의 tools/demo.sh를 내 API에 맞게 고칩니다. 시연은 손으로 명령을 치기보다 스크립트 한 번으로 보여 주는 편이 실수가 없습니다. 실행할 때마다 새 계정을 쓰도록 이메일에 시각을 붙여 두었으므로 여러 번 연습해도 됩니다.

    Windows에서 실행할 때

    아래 명령에는 bash 문법(이름=값, $(...) 등)이 들어 있습니다. 내 PC가 Windows라면 명령 프롬프트가 아니라 Git Bash에서 실행합니다(S12-P40-03). EC2 서버의 접속 화면에서 실행하는 명령은 그대로 입력합니다.

    BASE=http://book-api-alb-1234567890.ap-northeast-2.elb.amazonaws.com bash tools/demo.sh
