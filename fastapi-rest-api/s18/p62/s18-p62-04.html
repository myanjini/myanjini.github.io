공통 강점설명
권한 검사를 서비스에 둠라우터마다 흩어 두지 않고 자원을 찾은 직후 한곳에서 검사해, 새 경로를 추가해도 검사가 빠지지 않습니다.
템플릿 재사용인증, 오류 처리, 로그를 다시 만들지 않고 주제에 시간을 썼습니다.
실패 장면 시연201만이 아니라 401, 403, 409, 422를 보여 줘 보안 요구사항을 눈으로 확인시켰습니다.
배포 파이프라인 재사용새 서비스도 역할과 경로만 넓혀 같은 방식으로 배포했습니다.

권한 테스트가 상태 코드만 확인다시 조회해 값이 바뀌지 않았는지까지 확인합니다.
