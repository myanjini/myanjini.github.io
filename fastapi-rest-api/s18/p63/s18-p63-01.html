질문 1. 9일 동안 가장 어려웠던 점은 무엇이고, 어떻게 해결했나요?

예시 답안 보기

답에는 "무엇이 어려웠다"와 함께 "어떻게 원인을 찾았는가"를 적습니다. 예: "배포가 502로 실패했는데, 서버의 컨테이너 로그에서 Parameter Store 권한 오류를 찾고 EC2 역할의 정책 경로를 고쳤습니다. 오류 메시지를 끝까지 읽는 습관이 생겼습니다."

질문 2. 현업(또는 다음 프로젝트)에 바로 적용할 것은 무엇인가요?

예시 답안 보기

구체적일수록 좋습니다. 예: "(1) 명세에 권한 표를 넣고 칸마다 테스트를 만든다. (2) 비밀 값은 처음부터 환경 변수로 받고 저장소에 넣지 않는다. (3) 개수를 바꾸는 쿼리는 조건부 UPDATE로 쓴다."

질문 3. 아직 자신 없는 것은 무엇인가요?

예시 답안 보기

자신 없는 것을 알고 있는 것이 다음 학습의 출발점입니다. 예: "IAM 정책을 처음부터 혼자 쓰기", "테스트용 픽스처를 설계하기", "장애가 났을 때 어디부터 볼지 정하기".

개인 학습 계획
