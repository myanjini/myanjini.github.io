핵심 요약

주제핵심
설치dnf install로 Docker와 Git을, GitHub 배포 파일로 Compose와 Buildx 플러그인을 설치했습니다. systemctl enable --now로 자동 시작하게 했습니다.
소스와 비밀 값소스는 Git으로 받고, 비밀 값은 서버에서 새로 만들어 소스 폴더 밖의 권한 600 파일에 두었습니다.
실행docker run에 포트, 설정 파일, 볼륨, 재시작 정책을 주고, alembic upgrade head로 테이블을 만들었습니다.
접속내 PC에서 http://퍼블릭IP:8000으로 접속했고, 다른 네트워크에서는 막힙니다.
점검 순서컨테이너, 앱, 포트 연결, 보안 그룹, 주소, 경로, 그 밖의 방화벽 순서로 안쪽부터 확인합니다.
