RDS 생성 과정 보기

RDS 생성 화면은 칸이 많아 보이지만, 보안에 중요한 칸은 몇 개입니다. 특히 "어디에 두는가(서브넷 그룹)", "인터넷에서 닿는가(퍼블릭 액세스)", "누가 닿는가(보안 그룹)" 세 가지를 실습 전에 확인합니다.

먼저 DB 서브넷 그룹을 만드는 이유

RDS 생성 화면에서 서브넷 그룹을 "새로 만들기"로 두면, AWS가 그 VPC의 모든 서브넷(퍼블릭 포함)을 넣은 서브넷 그룹을 자동으로 만듭니다. 그러면 RDS가 퍼블릭 서브넷에 놓일 수 있습니다. 그래서 프라이빗 서브넷 두 개만 넣은 서브넷 그룹을 먼저 만들고, 생성 화면에서 그것을 고릅니다.

생성 화면의 주요 칸

칸이번 실습 값이유
생성 방식표준 생성(전체 설정)간편 생성은 네트워크를 고를 수 없습니다.
엔진PostgreSQL, 버전은 18의 최신 버전S8 Compose와 같은 18을 씁니다. 기관 계정에서 18이 보이지 않으면 17을 고릅니다.
템플릿개발/테스트(또는 기관이 안내한 템플릿)프로덕션 템플릿은 다중 AZ 같은 비싼 기본값이 켜집니다.
가용성단일 AZ DB 인스턴스실습 비용
DB 인스턴스 식별자book-api-db콘솔과 엔드포인트 이름에 쓰입니다.
마스터 사용자 이름bookapiS8 Compose와 같은 이름
자격 증명 관리자체 관리, 암호는 직접 만든 값오늘 오후에 Parameter Store로 관리합니다.
인스턴스 클래스버스터블 클래스의 가장 작은 것(예: db.t4g.micro)실습 비용. RDS는 이미지와 무관하므로 Graviton이어도 됩니다.
스토리지gp3 20GiB, 스토리지 자동 조정 끔필요 이상으로 늘지 않게 합니다.
컴퓨팅 리소스EC2 컴퓨팅 리소스에 연결 안 함연결하게 두면 보안 그룹을 자동으로 만들어 붙입니다. 이번에는 직접 만든 보안 그룹을 씁니다.
VPC, DB 서브넷 그룹book-api-vpc, book-api-db-subnets프라이빗 서브넷에만 놓이게 합니다.
퍼블릭 액세스아니요공용 IP를 받지 않아 인터넷에서 닿지 않습니다.
VPC 보안 그룹기존 항목 선택: book-api-db-sg(default는 제거)API 서버에서 오는 5432만
가용 영역ap-northeast-2aEC2와 같은 가용 영역이면 가용 영역 간 데이터 전송이 없습니다.
추가 구성: 초기 데이터베이스 이름bookapi비워 두면 bookapi 데이터베이스가 만들어지지 않습니다.
백업 보존 기간1일실습에 충분합니다.
암호화활성화(기본값, AWS 관리형 키 aws/rds)만든 뒤에는 켤 수 없습니다(S13-P46-04).
삭제 방지끔과정이 끝나면 지워야 합니다. 운영 DB라면 켭니다.

마스터 암호에 쓰면 안 되는 문자

RDS 마스터 암호에는 /, ', ", @, 공백을 쓸 수 없습니다. 또 :, @, /, ?, # 같은 문자는 DATABASE_URL 안에서 주소의 구분자로 읽혀 연결 문자열을 망가뜨립니다. 이번 실습은 secrets.token_urlsafe(24)로 영문자, 숫자, -, _만 들어간 32자 암호를 만들어 두 문제를 모두 피합니다.
