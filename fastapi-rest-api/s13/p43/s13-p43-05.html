확인 퀴즈

"VPC 등" 마법사에서 실습 비용을 지키려면 반드시 확인해야 하는 항목은 무엇인가요?

NAT 게이트웨이는 만든 순간부터 시간당 요금이 붙습니다.

보안 그룹을 만들 때 VPC를 잘못 골라 기본 VPC에 만들었습니다. 무엇이 문제인가요?

보안 그룹은 만든 VPC 안의 자원에만 붙일 수 있습니다.

book-api-db-sg의 출처를 book-api-sg로 지정했을 때 RDS에 접속할 수 있는 것은 무엇인가요?

출처로 지정한 보안 그룹이 붙은 자원에서 오는 연결만 허용됩니다.
