1일차 핵심 요약

배운 것코드에서 어디에 있나요
REST: 자원은 명사 URI, 동작은 메서드/books, /books/{book_id}에 GET, POST, PUT, PATCH, DELETE
경로와 쿼리 파라미터, 타입 검증book_id: int, author: str | None = None
요청 본문 검증app/schemas.py의 BookCreate, BookUpdate
응답 모델과 상태 코드response_model=BookRead, 201, 204
공통 오류 형식app/errors.py와 app/main.py의 예외 처리기
기능별 파일 분리app/routers/books.py와 include_router

확인 퀴즈

APIRouter(prefix="/books")에서 @router.get("/{book_id}")로 만든 API의 실제 주소는 무엇인가요?

prefix가 라우터 안 모든 주소 앞에 붙습니다.

라우터 파일을 만들었는데 문서에 도서 API가 보이지 않습니다. 가장 먼저 확인할 것은 무엇인가요?

라우터는 앱에 연결해야 동작합니다.

fastapi dev app/main.py를 어느 폴더에서 실행해야 하나요?

가장 바깥 폴더에서 실행해야 Python이 app 패키지를 찾을 수 있습니다.
