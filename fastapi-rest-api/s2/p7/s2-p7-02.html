폴더 구조와 역할

이 과정에서 쓸 폴더 구조와 각 파일의 역할을 정하고, 파일끼리 서로 불러 쓰는 방법을 배웁니다.

목표 구조

book-api/
├── .venv/
└── app/
    ├── __init__.py
    ├── main.py          앱 만들기, 예외 처리기 등록, 라우터 연결
    ├── errors.py        AppError
    ├── schemas.py       BookCreate, BookUpdate, BookRead
    ├── data.py          임시 도서 목록 BOOKS
    └── routers/
        ├── __init__.py
        └── books.py     도서 API

앞으로 기능이 늘면 routers 폴더에 authors.py, auth.py처럼 파일이 하나씩 늘어납니다. data.py는 2일차에 데이터베이스를 연결하면서 사라집니다.

패키지와 __init__.py

Python에서 __init__.py 파일이 들어 있는 폴더를 패키지라고 합니다. 이 파일은 내용 없이 비어 있어도 됩니다. 폴더를 패키지로 만들어 두면 다른 파일에서 app.schemas처럼 점으로 이어 불러올 수 있습니다.

불러오기는 app부터 씁니다

# app/routers/books.py 에서
from app.schemas import BookCreate, BookRead, BookUpdate
from app.errors import AppError
from app.data import BOOKS

어느 파일에서든 app.으로 시작하는 전체 경로를 쓰면, 파일이 어디에 있든 같은 방법으로 불러올 수 있어 헷갈리지 않습니다.

실행 명령이 바뀝니다

fastapi dev app/main.py

명령은 항상 book-api 폴더(가장 바깥 폴더)에서 실행합니다. 그래야 Python이 app 패키지를 찾을 수 있습니다.
