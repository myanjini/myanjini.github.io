라우터 분리하기

도서 API를 별도 파일로 옮길 때 쓰는 APIRouter의 사용법을 강사 화면으로 봅니다.

APIRouter는 작은 app입니다

APIRouter는 경로 연산을 모아 두는 묶음입니다. app과 쓰는 법이 거의 같아서, @app.get을 @router.get으로 바꾸기만 하면 됩니다.

app/routers/books.py
from fastapi import APIRouter

router = APIRouter(prefix="/books", tags=["도서"])


@router.get("")                 # 실제 주소: /books
def list_books():
    ...


@router.get("/{book_id}")       # 실제 주소: /books/{book_id}
def get_book(book_id: int):
    ...
설정효과
prefix="/books"이 라우터의 모든 주소 앞에 /books가 붙습니다. 경로마다 /books를 반복해 쓰지 않아도 됩니다.
tags=["도서"]이 라우터의 모든 API에 같은 태그가 붙습니다. 경로마다 태그를 쓰지 않아도 됩니다.
@router.get("")prefix 그대로인 /books입니다. "/"로 쓰면 주소가 /books/가 되니 빈 문자열을 씁니다.

앱에 연결하기

app/main.py
from app.routers import books

app.include_router(books.router)

라우터를 만들기만 하고 include_router로 연결하지 않으면 그 안의 API는 동작하지 않습니다. 문서에서 도서 API가 통째로 사라졌다면 가장 먼저 이 줄을 확인합니다.

예외 처리기는 app에 남깁니다

예외 처리기는 앱 전체에 적용되는 설정이라 app/main.py에 둡니다. 도서 라우터에서 AppError를 내도 이 처리기가 받아 공통 형식으로 응답합니다.
