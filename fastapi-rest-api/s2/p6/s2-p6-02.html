404 오류를 공통 형식으로 바꾸고, 같은 ISBN으로 도서가 두 번 등록되지 않도록 409 오류를 추가합니다.

실습 목표사용자 정의 예외와 예외 처리기로 404, 409 오류를 같은 모양으로 보낼 수 있습니다.

  2. 예외 클래스와 처리기 추가

    app = FastAPI(...) 아래, BOOKS 다음에 추가합니다.

    main.py
    class AppError(Exception):
    """이 앱이 일부러 보내는 오류. 상태 코드, 오류 코드, 메시지를 담습니다."""

    def __init__(self, status_code: int, code: str, message: str):
        self.status_code = status_code
        self.code = code
        self.message = message


@app.exception_handler(AppError)
def handle_app_error(request: Request, exc: AppError):
    # 어떤 AppError든 같은 모양의 JSON으로 바꿔 응답합니다.
    return JSONResponse(
        status_code=exc.status_code,
        content={"code": exc.code, "message": exc.message},
    )

  3. find_book이 AppError를 내도록 바꾸기

    main.py
    def find_book(book_id: int) -> dict:
    for book in BOOKS:
        if book["id"] == book_id:
            return book
    raise AppError(404, "BOOK_NOT_FOUND", f"{book_id}번 도서를 찾을 수 없습니다.")

    조회, 수정, 삭제가 모두 find_book을 쓰므로 이 한 곳만 고치면 세 API의 404 응답이 한꺼번에 바뀝니다. 앞 파트에서 함수로 묶어 둔 덕분입니다.

  4. ISBN 중복 검사 함수 추가

    main.py
    def check_isbn_unique(isbn: str | None, exclude_id: int | None = None) -> None:
    """같은 ISBN이 이미 있으면 409 오류를 냅니다. 수정할 때는 자기 자신을 빼고 비교합니다."""
    if isbn is None:
        return
    for book in BOOKS:
        if book["isbn"] == isbn and book["id"] != exclude_id:
            raise AppError(409, "DUPLICATE_ISBN", "이미 등록된 ISBN입니다.")

    exclude_id가 필요한 이유는 수정 때문입니다. 1번 도서를 수정하면서 원래 ISBN을 그대로 보내면, 목록에서 1번 도서 자신과 ISBN이 같다고 판단해 409가 나 버립니다. 그래서 자기 자신은 비교에서 뺍니다.

  5. 등록과 수정에 중복 검사 넣기

    main.py
    # create_book: 저장하기 전에
check_isbn_unique(book_in.isbn)

# replace_book: find_book 다음 줄에
check_isbn_unique(book_in.isbn, exclude_id=book_id)

# update_book: changes를 만든 다음 줄에
check_isbn_unique(changes.get("isbn"), exclude_id=book_id)

    PATCH에서는 ISBN을 보내지 않을 수도 있으므로 changes.get("isbn")으로 꺼냅니다. 보내지 않았다면 None이 되어 검사를 건너뜁니다.
