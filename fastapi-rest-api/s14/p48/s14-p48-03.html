이미지 푸시와 EC2에서 실행

ECR 저장소를 만들고 내 PC에서 만든 이미지를 버전 태그와 커밋 태그로 올립니다. 그다음 EC2에서 그 이미지를 받아 서버에서 빌드한 컨테이너를 교체합니다.

실습 목표이미지를 ECR에 버전 태그로 올리고, EC2가 IAM 역할로 받아 실행하게 할 수 있습니다.

  1. 저장소 만들기(내 PC)

    Windows에서 실행할 때

    아래 명령에는 bash 문법(이름=값, $(...) 등)이 들어 있습니다. 내 PC가 Windows라면 명령 프롬프트가 아니라 Git Bash에서 실행합니다(S12-P40-03). EC2 서버의 접속 화면에서 실행하는 명령은 그대로 입력합니다.

    aws ecr create-repository --repository-name book-api \
  --image-tag-mutability IMMUTABLE \
  --image-scanning-configuration scanOnPush=true \
  --tags Key=Owner,Value=student07 \
  --query "repository.repositoryUri" --output text
123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/book-api

    한 계정을 여러 학생이 함께 쓰면 저장소 이름에 식별자를 붙입니다(book-api-student07). 아래 명령의 저장소 이름도 같이 바꿉니다.

  2. 이미지 만들고 두 태그로 올리기

    내 PC의 도서 API 폴더에서 실행합니다. Parameter Store 코드를 푸시한 최신 커밋인지 먼저 확인합니다. Windows 명령 프롬프트에서는 변수를 set REGISTRY=...로 정하고 %REGISTRY%로 씁니다.

    git log --oneline -1
4f2c9a1 Parameter Store에서 비밀 값 읽기

REGISTRY=123456789012.dkr.ecr.ap-northeast-2.amazonaws.com
VERSION=1.0.0
SHA=$(git rev-parse --short HEAD)
aws ecr get-login-password --region ap-northeast-2 | docker login --username AWS --password-stdin $REGISTRY
Login Succeeded

docker build --platform linux/amd64 -t $REGISTRY/book-api:$VERSION -t $REGISTRY/book-api:git-$SHA .
docker push $REGISTRY/book-api:$VERSION
docker push $REGISTRY/book-api:git-$SHA

  3. 올라간 이미지와 스캔 확인

    aws ecr describe-images --repository-name book-api --query "imageDetails[].[imageTags,imageDigest,imagePushedAt]" --output json
[
    [
        ["1.0.0", "git-4f2c9a1"],
        "sha256:9b1d...",
        "2026-11-23T14:20:31+09:00"
    ]
]
aws ecr describe-image-scan-findings --repository-name book-api --image-id imageTag=1.0.0 --query "imageScanFindings.findingSeverityCounts"

    두 태그가 같은 이미지(같은 digest)를 가리키는지 확인합니다. 스캔은 푸시하고 1~2분 뒤에 끝납니다. 같은 태그로 다시 푸시해 보면 태그 변경 불가 설정 때문에 거부됩니다.

    docker push $REGISTRY/book-api:1.0.0
... tag invalid: The image tag '1.0.0' already exists in the 'book-api' repository and cannot be overwritten because the repository is immutable.

  4. EC2에서 받기

    Session Manager로 접속해, 서버의 역할로 ECR에 로그인하고 이미지를 받습니다. 역할의 AmazonEC2ContainerRegistryPullOnly 정책이 이를 허용합니다.

    REGISTRY=123456789012.dkr.ecr.ap-northeast-2.amazonaws.com
aws ecr get-login-password --region ap-northeast-2 | docker login --username AWS --password-stdin $REGISTRY
docker pull $REGISTRY/book-api:1.0.0
docker images --format "{{.Repository}}:{{.Tag}}  {{.Size}}"
123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/book-api:1.0.0  536MB
book-api:latest  536MB

  5. 컨테이너 교체

    docker rm -f book-api
docker run -d --name book-api -p 8000:8000 \
  -e SSM_PREFIX=/book-api/ -e AWS_DEFAULT_REGION=ap-northeast-2 -e APP_ENV=development \
  -v book-uploads:/app/uploads --restart unless-stopped \
  $REGISTRY/book-api:1.0.0
curl -s localhost:8000/health
{"status":"ok","database":"ok"}
docker ps --format "{{.Names}}  {{.Image}}  {{.Status}}"
book-api  123456789012.dkr.ecr.ap-northeast-2.amazonaws.com/book-api:1.0.0  Up 8 seconds

    이제 서버에서 빌드한 이미지는 쓰지 않으므로 지웁니다.

    docker rmi book-api:latest
