정리: ECR

핵심 요약

주제핵심
레지스트리이미지는 한 번 만들어 ECR에 올리고, 서버는 받아서 실행만 합니다.
ECR 저장소프라이빗, 태그 변경 불가, 푸시 시 스캔
로그인get-login-password로 12시간짜리 암호를 받아 --password-stdin으로 넘깁니다. EC2는 역할로 로그인합니다.
빌드EC2용은 --platform linux/amd64로 만듭니다.
태그latest 대신 버전과 커밋 태그를 붙이고, 이전 태그로 되돌립니다.

확인 퀴즈

EC2가 ECR에서 이미지를 받을 수 있게 하는 것은 무엇인가요?

서버의 역할이 레지스트리 로그인과 이미지 받기를 허용합니다.

Apple Silicon Mac에서 만든 이미지가 EC2에서 exec format error로 실행되지 않습니다. 원인은 무엇인가요?

--platform linux/amd64로 다시 만들어 새 태그로 올립니다.

ECR 이미지 스캔이 pip-audit과 다르게 더 찾아 주는 것은 무엇인가요?

pip-audit은 Python 패키지만, ECR 스캔은 이미지 전체의 패키지를 봅니다.
