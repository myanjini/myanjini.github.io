확인 퀴즈

로그인한 사용자가 GET /loans/7로 남의 대여 기록을 읽을 수 있었습니다. 가장 근본적인 해결은 무엇인가요?

번호를 숨기거나 바꾸는 것은 보조 수단입니다. 권한 검사는 반드시 서버에서 데이터마다 합니다.

APIRouter(prefix="/admin", dependencies=[Depends(require_admin)])의 장점으로 알맞은 것은 무엇인가요?

기능 수준 인가를 한곳에서 걸어, 새 API를 추가할 때 검사를 빠뜨릴 수 없게 합니다.

model_config = ConfigDict(extra="forbid")를 요청 모델에 쓰는 이유는 무엇인가요?

모르는 필드를 조용히 버리지 않고 명확히 거절합니다.
