Book 모델 만들기

SQLAlchemy를 설치하고 Book 모델을 만들어, 서버를 실행하면 데이터베이스 파일과 테이블이 생기는지 확인합니다.

실습 목표SQLAlchemy 모델을 정의하고 SQLite 데이터베이스에 테이블을 만들 수 있습니다.

  1. SQLAlchemy 설치

    pip install sqlalchemy

    설치한 뒤에는 패키지 목록도 갱신해 둡니다. 다른 사람이 같은 환경을 만들 때 이 파일을 씁니다.

    pip freeze > requirements.txt

  2. database.py와 models.py 작성

    앞 페이지의 두 파일을 app 폴더에 만듭니다.

  3. main.py에 테이블 만들기 추가

    app/main.py
    from app import models  # noqa: F401  모델을 불러와야 테이블 목록에 등록됩니다.
from app.config import settings
from app.database import Base, engine
from app.errors import AppError
from app.routers import books

# 아직 없는 테이블을 만듭니다. 2일차 오후(S4-P14)에 Alembic으로 바꿉니다.
Base.metadata.create_all(bind=engine)

  4. 서버 실행과 파일 확인

    fastapi dev app/main.py

    book-api 폴더에 books.db 파일이 생겼는지 VSCode 탐색기에서 확인합니다.

  5. 테이블 들여다보기

    새 터미널을 열어 가상환경을 켠 뒤, Python으로 테이블 구조를 출력합니다.

    python -c "import sqlite3; print(sqlite3.connect('books.db').execute('select sql from sqlite_master').fetchall())"

    CREATE TABLE books (...)가 출력되면 성공입니다. 화면으로 보고 싶다면 VSCode 확장 SQLite Viewer를 설치해 books.db를 클릭하거나, DB Browser for SQLite 프로그램으로 파일을 엽니다.

문제 해결

증상원인과 해결
books.db가 app 폴더 안에 생김서버를 app 폴더에서 실행했습니다. ./books.db는 명령을 실행한 폴더 기준이므로 book-api에서 실행합니다.
테이블 목록이 비어 있음from app import models를 빠뜨렸거나 create_all보다 아래에 두었습니다.
No module named 'sqlalchemy'가상환경이 꺼진 상태에서 설치했습니다. (.venv)를 확인하고 다시 설치합니다.
