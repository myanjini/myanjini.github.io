관계형 데이터베이스와 ORM

이 파트의 학습 목표SQLAlchemy 2.0의 핵심 구성 요소로 모델을 정의할 수 있습니다.

서버를 다시 시작해도 데이터가 남아 있으려면 데이터를 파일이나 별도 서버에 저장해야 합니다. 이 일을 맡는 관계형 데이터베이스와, Python에서 데이터베이스를 편하게 다루게 해 주는 ORM을 알아봅니다.

관계형 데이터베이스

관계형 데이터베이스는 데이터를 엑셀 표와 비슷한 테이블에 저장합니다.

idtitleauthorpriceisbn
1파이썬 첫걸음김하늘180009791100000011
2웹 개발 입문이도윤22000(없음)
용어뜻
테이블같은 종류의 데이터를 모아 둔 표입니다. 여기서는 books 테이블입니다.
행(row)데이터 하나입니다. 도서 한 권이 한 행입니다.
열(column)데이터의 항목입니다. 제목, 저자, 가격 등입니다.
기본키(primary key)행을 하나로 특정하는 값입니다. 겹치지 않으며 보통 id를 씁니다.
고유 제약(unique)그 열에 같은 값이 두 번 들어가지 못하게 하는 규칙입니다. ISBN에 씁니다.

데이터베이스에는 SQL이라는 언어로 명령합니다. 예를 들어 SELECT * FROM books WHERE author = '김하늘'은 김하늘 저자의 도서를 모두 가져오라는 뜻입니다.

ORM

ORM(Object Relational Mapping)은 테이블을 Python 클래스로, 행을 객체로 다루게 해 주는 도구입니다. SQL을 직접 쓰는 대신 Python 코드로 데이터를 다루면 ORM이 SQL로 바꿔 실행합니다. 이 과정에서는 Python에서 가장 널리 쓰는 ORM인 SQLAlchemy를 씁니다.

좋은 점주의할 점
Python 문법과 자동 완성으로 데이터를 다룹니다.실제로 어떤 SQL이 실행되는지 보이지 않아 느린 쿼리를 놓치기 쉽습니다(오후에 N+1 문제로 확인).
데이터베이스 종류가 바뀌어도 코드를 거의 그대로 씁니다.아주 복잡한 조회는 SQL을 직접 쓰는 편이 쉬울 때도 있습니다.
값을 안전하게 SQL에 넣어 주어 SQL 삽입 공격을 막는 데 도움이 됩니다(5일차).ORM이 있어도 SQL 문자열을 직접 조립하면 위험은 그대로입니다.
