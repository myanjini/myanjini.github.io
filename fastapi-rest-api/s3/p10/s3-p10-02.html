SQLAlchemy 2.0 핵심 구성

SQLAlchemy 2.0으로 데이터베이스를 쓰려면 네 가지 구성 요소를 알아야 합니다. 각각이 무슨 역할인지 먼저 정리합니다.

구성 요소역할비유
Engine데이터베이스와 연결을 맺고 관리합니다. 앱 전체에 하나만 만듭니다.도서관으로 가는 길
Session데이터를 읽고 쓰는 작업 단위입니다. 요청마다 하나씩 열고 닫습니다.한 번 방문해 책을 빌리고 반납하는 일
DeclarativeBase모델 클래스가 상속하는 기본 클래스입니다. 이걸 상속해야 SQLAlchemy가 테이블로 인식합니다.도서관 장부의 양식
Mapped, mapped_column클래스 속성과 테이블 열을 연결합니다.양식의 칸

Engine과 Session 만들기

from sqlalchemy import create_engine
from sqlalchemy.orm import sessionmaker

engine = create_engine("sqlite:///./books.db")
SessionLocal = sessionmaker(bind=engine, autoflush=False)

sqlite:///./books.db는 "지금 폴더의 books.db 파일을 SQLite로 쓴다"는 주소입니다. sessionmaker는 세션을 찍어 내는 틀이고, SessionLocal()을 부를 때마다 새 세션이 만들어집니다.

모델 클래스

class Book(Base):
    __tablename__ = "books"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(100))
    price: Mapped[int]
    isbn: Mapped[str | None] = mapped_column(String(13), unique=True)
코드테이블에서는
__tablename__ = "books"테이블 이름
Mapped[int]정수 열. 값이 반드시 있어야 함(NOT NULL)
Mapped[str | None]문자열 열. 값이 없어도 됨
mapped_column(primary_key=True)기본키. 정수 기본키는 값을 넣지 않으면 1, 2, 3...으로 자동으로 매겨짐
String(100)최대 100자 문자열
unique=True고유 제약

Pydantic 모델과 헷갈리지 않기

이름이 비슷하지만 역할이 다릅니다. Pydantic 모델(BookCreate, BookRead)은 API로 주고받는 데이터의 모양이고, SQLAlchemy 모델(Book)은 데이터베이스에 저장하는 데이터의 모양입니다. 그래서 파일도 schemas.py와 models.py로 나눕니다.
