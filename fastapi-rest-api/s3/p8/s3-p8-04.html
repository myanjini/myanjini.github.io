의존성 활용하기

페이지 나누기 의존성을 직접 만들어 목록 API에 적용하고, 열고 닫아야 하는 자원을 다루는 yield 의존성을 미리 연습합니다.

실습 목표클래스 의존성으로 목록 API에 페이지 나누기를 적용하고, yield 의존성의 실행 순서를 설명할 수 있습니다.

  1. dependencies.py 만들기

    app 폴더에 dependencies.py를 만들고 앞 페이지의 Pagination과 PageDep를 작성합니다.

  2. 목록 API에 적용

    app/routers/books.py 위쪽에 가져오기 줄을 추가하고 list_books를 바꿉니다.

    app/routers/books.py
    from app.dependencies import PageDep
    app/routers/books.py
    @router.get("", response_model=list[BookRead], summary="도서 목록 조회")
def list_books(page: PageDep, author: str | None = None):
    """저자 이름(author)으로 거르고, skip과 limit으로 나눠 돌려줍니다."""
    result = BOOKS
    if author is not None:
        result = [book for book in result if book["author"] == author]
    return result[page.skip : page.skip + page.limit]

  3. 페이지 나누기 확인

    요청기대하는 결과내 결과
    /books?skip=1&limit=22번, 3번 도서
    /books?author=김하늘&limit=11번 도서만
    /books?limit=0422

  4. yield 의존성 만들기

    데이터베이스 연결처럼 "쓰기 전에 열고, 다 쓰면 반드시 닫아야 하는" 자원이 있습니다. 이런 자원은 return 대신 yield를 쓰는 의존성으로 다룹니다. app/dependencies.py 맨 아래에 연습용 함수를 추가합니다.

    app/dependencies.py
    def get_resource():
    """yield 의존성 연습용 함수입니다. 열고, 넘겨주고, 닫습니다."""
    print("자원을 엽니다.")
    try:
        yield "임시 자원"
    finally:
        print("자원을 닫습니다.")

    yield 앞부분이 먼저 실행되고, yield로 넘긴 값이 경로 함수에 들어갑니다. 경로 함수가 끝나면 yield 뒤의 finally 부분이 실행됩니다. finally는 중간에 오류가 나도 반드시 실행되므로, 자원을 닫는 코드는 여기에 둡니다.

    return find_book(book_id)
