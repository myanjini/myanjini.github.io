DB 세션 의존성

이 파트의 학습 목표DB 세션 의존성으로 등록과 조회 API를 데이터베이스와 연결할 수 있습니다.

API가 데이터베이스를 쓰려면 요청마다 세션이 필요합니다. S3-P8에서 연습한 yield 의존성으로 세션을 열고 닫습니다.

app/database.py
def get_db():
    """요청 하나에 세션 하나를 열어 주고, 요청이 끝나면 닫습니다."""
    db = SessionLocal()
    try:
        yield db
    finally:
        db.close()

S3-P8-04의 get_resource와 모양이 같습니다. 요청이 오면 세션을 열어 경로 함수에 넘기고, 응답을 만들고 나면 finally에서 반드시 닫습니다.

요청마다 세션을 하나씩 쓰는 이유

  • 여러 요청이 세션 하나를 함께 쓰면, 한 요청의 작업이 다른 요청에 섞일 수 있습니다.
  • 세션을 닫지 않으면 데이터베이스 연결이 쌓여 결국 새 요청을 받지 못하게 됩니다.

SessionDep

app/dependencies.py
from sqlalchemy.orm import Session

from app.database import get_db

SessionDep = Annotated[Session, Depends(get_db)]

PageDep처럼 이름 하나로 묶어 두면, 경로 함수에서는 db: SessionDep만 적어 세션을 받습니다.
