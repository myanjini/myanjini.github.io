생성과 조회 구현 보기

세션으로 데이터를 저장하고 꺼내는 코드를 강사 화면으로 하나씩 실행해 봅니다.

저장하기

book = Book(title="파이썬 첫걸음", author="김하늘", price=18000)
db.add(book)      # 저장할 목록에 올립니다.
db.commit()       # 데이터베이스에 실제로 저장합니다.
db.refresh(book)  # 데이터베이스가 정한 id를 다시 읽어 옵니다.
print(book.id)    # 1
단계하는 일
add세션에 "이 객체를 저장할 예정"이라고 알립니다. 아직 데이터베이스에는 없습니다.
commit모아 둔 변경을 데이터베이스에 한꺼번에 확정합니다. 이 순간 실제로 저장됩니다.
refresh데이터베이스가 정한 값(자동으로 매긴 id 등)을 객체에 다시 채웁니다.

하나 꺼내기

book = db.get(Book, 1)    # 기본키로 찾기. 없으면 None

조건으로 여러 개 꺼내기

from sqlalchemy import select

stmt = (
    select(Book)
    .where(Book.author == "김하늘")
    .order_by(Book.id)
    .offset(0)
    .limit(10)
)
books = db.scalars(stmt).all()
코드SQL로는뜻
select(Book)SELECT ... FROM books도서 테이블에서 가져옵니다.
.where(Book.author == "김하늘")WHERE author = ?조건을 겁니다.
.order_by(Book.id)ORDER BY id번호 순으로 정렬합니다.
.offset(0).limit(10)LIMIT 10 OFFSET 0건너뛸 개수와 가져올 개수입니다.
db.scalars(stmt).all()실행해 Book 객체 목록으로 받습니다.

SQL의 ? 자리에는 값이 따로 전달됩니다. 사용자가 입력한 값이 SQL 문장의 일부로 섞이지 않으므로 SQL 삽입 공격을 막는 데 도움이 됩니다. 5일차에 직접 확인합니다.

하나만 꺼내기

found = db.scalar(select(Book).where(Book.isbn == "9791100000011"))   # 없으면 None

scalars(...).all()은 목록을, scalar(...)는 첫 번째 하나를 돌려줍니다. ISBN 중복 검사처럼 있는지 없는지만 알면 될 때 씁니다.
