운영 설정 점검

컨테이너를 실제로 운영할 때 기본으로 챙기는 설정 세 가지를 정리합니다.

헬스 체크와 자동 재시작

db처럼 api에도 상태 확인을 붙이고, 멈추면 다시 시작하도록 합니다. 슬림 이미지에는 curl이 없으므로 Python으로 /health를 호출합니다.

compose.yaml
  api:
    build: .
    restart: unless-stopped  # 멈추면 다시 시작합니다(직접 멈춘 경우는 제외).
    ports:
      - "8000:8000"
    environment:
      DATABASE_URL: postgresql+psycopg://bookapi:${POSTGRES_PASSWORD}@db:5432/bookapi
      SECRET_KEY: ${SECRET_KEY}
      LOG_LEVEL: INFO
    volumes:
      - uploads:/app/uploads
    depends_on:
      db:
        condition: service_healthy
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"]
      interval: 30s
      timeout: 5s
      retries: 3
설정하는 일
restart: unless-stopped프로그램이 비정상 종료되거나 Docker가 다시 시작되면 컨테이너를 다시 시작합니다. 직접 stop한 경우에는 다시 시작하지 않습니다. db에도 같은 줄을 넣습니다.
healthcheck30초마다 /health를 부르고, 3번 연속 실패하면 unhealthy로 표시합니다. 8일차 로드 밸런서도 같은 방식으로 서버 상태를 확인합니다.

적용 후 docker compose up -d를 하고 30초쯤 뒤 docker compose ps를 보면 api에도 (healthy)가 붙습니다. 지금의 /health는 데이터베이스를 확인하지 않는데, S8-P28-04에서 보강합니다.

데이터 볼륨 백업

볼륨은 컨테이너를 지워도 남지만, 볼륨을 실수로 지우거나 디스크가 고장 나면 사라집니다. 정기적으로 백업합니다. pg_dump는 데이터베이스를 SQL 파일로 내보내는 PostgreSQL 도구입니다.

docker compose exec db pg_dump -U bookapi -d bookapi -f /tmp/backup.sql
docker compose cp db:/tmp/backup.sql ./backup.sql

컨테이너 안에 파일을 만든 뒤 docker compose cp로 내 PC에 복사합니다. 출력을 >로 바로 받는 방법은 Windows PowerShell에서 글자 인코딩이 바뀌어 복원할 때 깨질 수 있어서 이 방법을 씁니다. 백업 파일에는 사용자 정보와 비밀번호 해시가 들어 있으므로 Git에 올리지 않고 안전한 곳에 보관합니다. 복원은 반대로 파일을 컨테이너에 복사한 뒤 psql -U bookapi -d bookapi -f /tmp/backup.sql로 실행합니다. 7일차 RDS는 자동 백업을 제공합니다.

운영 설정을 모두 넣은 compose.yaml 펼치기
compose.yaml
services:
  db:
    image: postgres:18
    restart: unless-stopped
    environment:
      POSTGRES_USER: bookapi
      POSTGRES_PASSWORD: ${POSTGRES_PASSWORD}  # .env에서 읽어 옵니다.
      POSTGRES_DB: bookapi
    volumes:
      - db-data:/var/lib/postgresql  # 데이터를 컨테이너 밖 볼륨에 저장합니다.
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U bookapi -d bookapi"]
      interval: 5s
      timeout: 3s
      retries: 10

  api:
    build: .
    restart: unless-stopped  # 멈추면 다시 시작합니다(직접 멈춘 경우는 제외).
    ports:
      - "8000:8000"
    environment:
      DATABASE_URL: postgresql+psycopg://bookapi:${POSTGRES_PASSWORD}@db:5432/bookapi
      SECRET_KEY: ${SECRET_KEY}
      LOG_LEVEL: INFO
    volumes:
      - uploads:/app/uploads
    depends_on:
      db:
        condition: service_healthy
    healthcheck:
      test: ["CMD", "python", "-c", "import urllib.request; urllib.request.urlopen('http://localhost:8000/health')"]
      interval: 30s
      timeout: 5s
      retries: 3

volumes:
  db-data:
  uploads:
