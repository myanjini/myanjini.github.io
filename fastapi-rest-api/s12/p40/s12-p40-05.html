정리: AWS 개요

핵심 요약

주제핵심
클라우드컴퓨팅 자원을 필요한 만큼 빌려 쓰고 쓴 만큼 냅니다.
서비스 모델IaaS(EC2)는 운영체제부터 내가, 관리형 서비스(RDS)는 더 많은 부분을 AWS가 관리합니다.
공동 책임 모델AWS는 클라우드 자체를, 나는 클라우드 안의 설정, 권한, 데이터, 코드를 책임집니다.
리전과 가용 영역서울 리전(ap-northeast-2)만 쓰고, 중요한 자원은 두 가용 영역에 나눠 둡니다.
로그인루트 사용자를 쓰지 않고, CLI는 액세스 키 대신 aws login이나 aws sso login으로 임시 자격 증명을 받습니다.
비용시간, 용량, 공용 IPv4 주소에 요금이 붙습니다. 작게 만들고, 태그를 붙이고, 매일 정리합니다.

확인 퀴즈

가용 영역에 대한 설명으로 알맞은 것은 무엇인가요?

한 가용 영역이 멈춰도 다른 가용 영역은 계속 동작하므로, 중요한 자원을 두 곳 이상에 나눠 둡니다.

EC2 인스턴스를 "중지"했을 때 계속 요금이 나갈 수 있는 것은 무엇인가요?

중지하면 실행 시간 요금은 멈추지만, 저장 공간과 할당한 주소는 남아 있으므로 요금이 계속됩니다.

AWS CLI가 지금 누구의 권한으로 요청하는지 확인하는 명령은 무엇인가요?

권한 문제를 만나면 가장 먼저 실행해 계정과 사용자(역할)를 확인합니다.
