정리: 라우팅

핵심 요약

  • 경로 연산은 메서드, 주소, 실행할 함수의 묶음이고, @app.get() 같은 데코레이터로 등록합니다.
  • 주소의 {이름}은 경로 파라미터, 그 밖의 매개변수는 쿼리 파라미터로 값을 받습니다.
  • 타입 힌트에 맞지 않는 값은 함수가 실행되기 전에 422 오류로 걸러집니다.
  • 고정된 주소는 값이 들어가는 주소보다 위에 선언합니다.
  • 잘 모르겠으면 def를 쓰고, async def 안에서는 멈춰 기다리는 함수를 부르지 않습니다.

확인 퀴즈

@app.get("/books/{book_id}") 아래 함수가 def get_book(book_id: int, detail: bool = False)일 때, detail은 어디에서 값을 받나요?

주소의 중괄호 안에 없는 매개변수는 쿼리 문자열에서 값을 받습니다. 예: /books/1?detail=true

book_id: int로 선언한 경로에 /books/abc를 요청하면 어떻게 되나요?

FastAPI가 정수로 바꾸지 못하면 함수를 실행하기 전에 422 응답을 보냅니다.

/books/popular와 /books/{book_id}를 함께 만들 때 올바른 방법은 무엇인가요?

FastAPI는 위에서부터 비교하므로 고정된 주소를 먼저 선언해야 원하는 함수가 실행됩니다.
