과정 소개와 로드맵

이 파트의 학습 목표REST API의 자원, URI, HTTP 메서드, 상태 코드의 역할을 설명할 수 있습니다.

앞으로 9일 동안 도서 관리 API 하나를 처음부터 만들고, 보안 점검을 거쳐 AWS에 배포합니다. 이 페이지에서는 무엇을 만들고 어떤 순서로 배우는지, 그리고 교안을 어떻게 읽으면 되는지 살펴봅니다.

무엇을 만드나요

과정 내내 하나의 예제 서비스인 도서 관리 API를 조금씩 키워 갑니다. 화면 없이 데이터만 주고받는 서버 프로그램으로, 다른 앱이나 웹 화면이 이 API를 호출해 도서 정보를 다룹니다.

  • 도서를 등록하고 조회하고 수정하고 삭제합니다.
  • 회원가입과 로그인을 하고, 내가 등록한 도서만 수정할 수 있게 합니다.
  • 도서를 대여하고 반납하며, 표지 이미지를 올립니다.
  • 자동 테스트로 기능을 검증하고, 보안약점을 진단해 고칩니다.
  • 마지막으로 AWS에 배포해 인터넷에서 접속할 수 있게 만듭니다.

9일차에는 지금까지 익힌 흐름을 그대로 써서, 여러분이 고른 주제로 작은 API를 혼자 만들어 발표합니다.

교안 읽는 법

수업 1교시가 교안의 파트 하나입니다. 파트는 50분 수업과 10분 휴식으로 이루어지고, 50분은 여러 페이지로 나뉩니다. 화면 맨 위의 막대가 이 파트의 페이지들이며, 막대의 길이는 각 페이지에 쓰는 시간에 비례합니다. 지금 보고 있는 페이지는 진하게 표시됩니다.

페이지 유형하는 일
주요 개념새로운 개념을 배우고, 강사가 화면으로 보여 주는 과정을 함께 봅니다. 이 페이지에서는 따라 입력하지 않아도 됩니다.
실습직접 코드를 입력하고 실행합니다. 질문에 내 답을 먼저 쓰고 예시 답안과 비교하는 스스로 묻고 답하기도 실습에 들어갑니다.
정리파트의 핵심을 요약하고 확인 퀴즈를 풉니다.

스스로 묻고 답하기는 이렇게 합니다

질문을 읽고 답 칸에 내 생각을 먼저 씁니다. 다 쓴 뒤에 예시 답안을 펼쳐 비교하고, 다른 점이 있으면 왜 다른지 생각해 봅니다. 답 칸에 쓴 내용은 이 컴퓨터의 브라우저에 저장되므로 나중에 다시 볼 수 있습니다.

막혔을 때 비교할 완성 코드

실습 페이지 끝에는 "예제 저장소의 p5-done 브랜치"처럼 그 파트를 마친 코드의 위치가 적혀 있습니다. 예제 저장소 주소는 첫날 강사가 알려 줍니다. 완성 코드는 내 코드와 비교해 다른 곳을 찾는 데만 쓰고, 통째로 복사하지 않습니다. 복사한 코드는 다음 파트에서 고칠 때 어디를 바꿔야 할지 알 수 없게 만듭니다.
