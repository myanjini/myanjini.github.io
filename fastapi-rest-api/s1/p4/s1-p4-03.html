도서 등록 API

BookCreate 모델을 만들고, 검사를 통과한 도서를 목록에 추가하는 POST /books를 작성합니다.

실습 목표Pydantic 모델로 요청 본문을 검증해 새 도서를 등록할 수 있습니다.

  1. 모델 만들기

    main.py 맨 위의 가져오기 부분에 Pydantic을 추가하고, BOOKS 목록 아래에 모델을 작성합니다.

    main.py
    from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

# ... (app, BOOKS는 그대로)


class BookCreate(BaseModel):
    title: str = Field(min_length=1, max_length=100)
    author: str = Field(min_length=1, max_length=50)
    price: int = Field(ge=0, le=1_000_000)

  2. 등록 API 작성

    파일 아래쪽에 다음 함수를 추가합니다.

    main.py
    @app.post("/books")
def create_book(book_in: BookCreate):
    # 지금 있는 번호 중 가장 큰 번호에 1을 더해 새 번호로 씁니다.
    new_id = max(book["id"] for book in BOOKS) + 1 if BOOKS else 1
    book = {"id": new_id, **book_in.model_dump()}
    BOOKS.append(book)
    return book

    **book_in.model_dump()는 딕셔너리의 내용을 펼쳐 넣는 문법입니다. 결과적으로 {"id": 5, "title": ..., "author": ..., "price": ...} 모양의 딕셔너리가 만들어집니다.

  3. Swagger UI로 등록하기

    /docs에서 POST /books의 Try it out을 누르고 다음 JSON을 넣어 실행합니다.

    {
  "title": "FastAPI 실전",
  "author": "최유나",
  "price": 27000
}

    응답 본문에 "id": 5가 붙은 도서가 돌아오면 성공입니다.

  4. 목록에서 확인하기

    GET /books를 다시 호출해 5번 도서가 목록 끝에 추가되었는지 확인합니다.

  5. 서버 재시작 후 다시 보기

    main.py를 아무 곳이나 고쳐 저장해 서버를 다시 시작한 뒤 GET /books를 호출해 봅니다. 등록했던 5번 도서가 사라졌습니다. 데이터가 Python 리스트, 즉 메모리에만 있었기 때문입니다. 2일차에 데이터베이스를 연결해 이 문제를 해결합니다.

상태 코드는 아직 200

새 자원을 만들었으니 원래는 201이 더 알맞습니다. 상태 코드를 직접 정하는 방법은 오후 첫 시간(S2-P5)에 배웁니다.

지금까지의 main.py

main.py
from fastapi import FastAPI, HTTPException
from pydantic import BaseModel, Field

app = FastAPI(title="도서 관리 API")

# 데이터베이스 대신 쓰는 임시 도서 목록입니다. 2일차에 데이터베이스로 바꿉니다.
BOOKS = [
    {"id": 1, "title": "파이썬 첫걸음", "author": "김하늘", "price": 18000},
    {"id": 2, "title": "웹 개발 입문", "author": "이도윤", "price": 22000},
    {"id": 3, "title": "데이터베이스 기초", "author": "김하늘", "price": 25000},
    {"id": 4, "title": "알기 쉬운 네트워크", "author": "박서준", "price": 20000},
]


class BookCreate(BaseModel):
    title: str = Field(min_length=1, max_length=100)
    author: str = Field(min_length=1, max_length=50)
    price: int = Field(ge=0, le=1_000_000)


@app.get("/")
def read_root():
    return {"message": "도서 관리 API에 오신 것을 환영합니다."}


@app.get("/health")
def health_check():
    return {"status": "ok"}


@app.get("/books")
def list_books(author: str | None = None):
    if author is None:
        return BOOKS
    return [book for book in BOOKS if book["author"] == author]


@app.get("/books/{book_id}")
def get_book(book_id: int):
    for book in BOOKS:
        if book["id"] == book_id:
            return book
    raise HTTPException(status_code=404, detail="도서를 찾을 수 없습니다.")


@app.post("/books")
def create_book(book_in: BookCreate):
    new_id = max(book["id"] for book in BOOKS) + 1 if BOOKS else 1
    book = {"id": new_id, **book_in.model_dump()}
    BOOKS.append(book)
    return book
