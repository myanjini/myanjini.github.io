정리: 요청 검증

핵심 요약

  • Pydantic의 BaseModel로 요청 데이터의 모양을 정하고, Field로 길이와 범위 같은 세부 규칙을 정합니다.
  • 기본값이 없는 필드는 필수, 기본값이 있는 필드는 선택 항목입니다.
  • 함수 매개변수의 타입이 Pydantic 모델이면 FastAPI는 요청 본문에서 값을 받습니다.
  • 규칙을 어긴 요청은 함수가 실행되기 전에 422로 걸러지고, 응답의 loc와 msg로 원인을 알 수 있습니다.
  • 지금은 데이터가 메모리에만 있어 서버를 다시 시작하면 사라집니다.

확인 퀴즈

price: int = Field(ge=0)로 선언했을 때 통과하지 못하는 값은 무엇인가요?

ge=0은 0 이상이라는 뜻이므로 음수는 통과하지 못합니다. 문자열 "15000"은 정수로 바뀌어 통과합니다.

다음 중 보내지 않아도 되는 선택 항목은 무엇인가요?

기본값(None)이 있으므로 보내지 않아도 됩니다. Field(...)에 기본값을 주지 않으면 필수 항목입니다.

422 응답의 loc가 ["body", "author"]입니다. 무엇을 확인해야 하나요?

loc는 문제가 난 위치입니다. body는 요청 본문을 뜻합니다.
