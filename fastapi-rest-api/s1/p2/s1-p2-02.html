개발 환경 구성

책 전체에서 쓸 프로젝트 폴더와 Python 가상환경을 만들고 FastAPI를 설치합니다.

실습 목표가상환경을 활성화한 상태에서 FastAPI를 설치하고 VSCode에서 같은 환경을 쓰도록 설정할 수 있습니다.

  1. Python 버전 확인

    명령 프롬프트(macOS는 터미널)를 열고 Python 버전을 확인합니다.

    python --version

    Python 3.12 이상이 나오면 됩니다. macOS에서 명령을 찾지 못하면 python3 --version으로 확인하고, 이후 명령에서도 python 대신 python3을 씁니다.

  2. 프로젝트 폴더 만들기

    실습 파일을 모아 둘 폴더를 만들고 그 안으로 이동합니다.

    mkdir book-api
cd book-api

    폴더 이름과 경로에는 한글과 공백을 넣지 않습니다. 일부 도구가 한글 경로에서 오류를 내기 때문입니다.

  3. 가상환경 만들고 켜기

    가상환경은 프로젝트마다 패키지를 따로 설치하는 공간입니다. 다른 프로젝트와 패키지 버전이 섞이지 않게 해 줍니다.

    python -m venv .venv

    Windows 명령 프롬프트에서 켜기:

    .venv\Scripts\activate

    macOS 터미널에서 켜기:

    source .venv/bin/activate

    프롬프트 앞에 (.venv)가 붙으면 가상환경이 켜진 것입니다. 앞으로 실습할 때는 항상 이 표시가 있는지 먼저 확인합니다.

  4. FastAPI 설치

    pip install "fastapi[standard]"

    [standard]를 붙이면 FastAPI와 함께 Uvicorn, fastapi 명령, 자주 쓰는 부가 패키지가 한 번에 설치됩니다. 따옴표는 일부 터미널이 대괄호를 다르게 해석하지 않게 하려고 붙입니다.

  5. 설치 확인

    pip show fastapi
fastapi --version

    pip show 결과의 Location이 프로젝트의 .venv 폴더 안을 가리키면 가상환경에 제대로 설치된 것입니다. fastapi --version은 서버를 실행할 때 쓸 fastapi 명령이 설치되었는지 확인하며, FastAPI CLI version으로 시작하는 줄이 나오면 됩니다.

  6. VSCode에서 폴더 열고 인터프리터 고르기

    code .

    VSCode가 열리면 Ctrl + Shift + P(macOS는 Cmd + Shift + P)를 누르고 Python: Select Interpreter를 선택한 뒤, 목록에서 .venv가 들어간 항목을 고릅니다. 그래야 VSCode가 설치한 패키지를 인식해 코드에 빨간 밑줄을 긋지 않습니다.

    code 명령이 없다면 VSCode를 직접 실행해 파일 > 폴더 열기로 book-api 폴더를 엽니다.

Windows에서 VSCode 터미널을 쓸 때

VSCode의 기본 터미널이 PowerShell이면 가상환경을 켤 때 실행 정책 오류가 날 수 있습니다. 터미널 오른쪽 위의 아래 화살표에서 Command Prompt를 골라 명령 프롬프트로 바꿔 쓰세요.
