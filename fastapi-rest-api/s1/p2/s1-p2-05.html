정리: 서버 실행 흐름

핵심 요약

  • FastAPI는 요청 처리의 반복 작업을 대신해 주는 웹 프레임워크이고, Uvicorn은 포트를 열고 요청을 받아 FastAPI에 넘기는 서버 프로그램입니다.
  • 실습은 항상 가상환경을 켠 상태((.venv) 표시)에서 진행합니다.
  • @app.get("/경로") 아래 함수가 그 요청을 처리하고, 딕셔너리를 돌려주면 JSON 응답이 됩니다.
  • fastapi dev main.py로 실행하면 저장할 때마다 자동으로 다시 시작되고, /docs에서 API를 시험할 수 있습니다.

확인 퀴즈

Uvicorn이 맡는 역할로 알맞은 것은 무엇인가요?

경로와 처리 함수는 FastAPI 코드에 있고, 네트워크에서 요청을 받는 일은 Uvicorn이 합니다.

FastAPI가 자동으로 만들어 주는 API 문서를 보려면 어느 주소를 열어야 하나요?

/docs에서 Swagger UI 문서를 볼 수 있고, 그 화면에서 API를 직접 호출할 수 있습니다.

가상환경을 쓰는 가장 큰 이유는 무엇인가요?

가상환경은 프로젝트별 패키지 설치 공간입니다. 다른 프로젝트의 패키지 버전과 충돌하지 않습니다.
