표지 이미지 업로드 보기

표지 업로드 코드가 파일 검사, 저장, 데이터베이스 반영으로 이어지는 흐름을 강사 화면으로 보고, Swagger UI로 파일을 보내 결과를 확인합니다.

파일 저장 담당: covers.py

파일을 다루는 코드는 app/services/covers.py에 따로 둡니다. 이 파일은 데이터베이스를 모르고 파일만 다룹니다.

app/services/covers.py
"""표지 파일 저장소: 파일 검사와 저장, 삭제를 맡습니다. 데이터베이스는 다루지 않습니다."""
import uuid
from datetime import datetime
from pathlib import Path

from fastapi import UploadFile

from app.config import settings
from app.errors import AppError

ALLOWED_EXTENSIONS = {".jpg", ".jpeg", ".png"}
MAX_COVER_SIZE = 2 * 1024 * 1024  # 2MB
COVER_DIR = Path(settings.upload_dir) / "covers"
COVER_URL_PREFIX = "/covers/"
LOG_FILE = Path("logs") / "upload.log"


def read_cover(file: UploadFile) -> tuple[bytes, str]:
    """확장자와 크기를 검사하고, 파일 내용과 확장자를 돌려줍니다."""
    ext = Path(file.filename or "").suffix.lower()
    if ext not in ALLOWED_EXTENSIONS:
        raise AppError(415, "UNSUPPORTED_FILE_TYPE", "jpg, jpeg, png 파일만 올릴 수 있습니다.")
    data = file.file.read(MAX_COVER_SIZE + 1)  # 한도보다 1바이트 더 읽어 보면 넘었는지 알 수 있습니다.
    if len(data) > MAX_COVER_SIZE:
        raise AppError(413, "FILE_TOO_LARGE", "파일 크기는 2MB를 넘을 수 없습니다.")
    if not data:
        raise AppError(422, "EMPTY_FILE", "빈 파일입니다.")
    return data, ext


def save_cover(data: bytes, ext: str) -> str:
    """겹치지 않는 새 이름으로 저장하고, 브라우저에서 열 주소를 돌려줍니다."""
    filename = f"{uuid.uuid4().hex}{ext}"
    (COVER_DIR / filename).write_bytes(data)
    return COVER_URL_PREFIX + filename


def remove_cover(cover_url: str | None) -> None:
    """저장해 둔 표지 파일을 지웁니다. 없으면 아무것도 하지 않습니다."""
    if cover_url:
        (COVER_DIR / Path(cover_url).name).unlink(missing_ok=True)

file.file.read(MAX_COVER_SIZE + 1)은 최대 2MB보다 1바이트까지만 읽습니다. 그만큼 읽혔다면 파일이 한도를 넘은 것이고, 나머지는 읽지 않고 버립니다.

서비스: 순서가 중요합니다

app/services/books.py
def upload_cover(db: Session, user: User, book_id: int, file: UploadFile) -> Book:
    book = find_book(db, book_id)
    check_can_modify(book, user)
    data, ext = covers.read_cover(file)
    old_url = book.cover_url
    book.cover_url = covers.save_cover(data, ext)
    db.commit()
    covers.remove_cover(old_url)  # 데이터베이스에 반영된 뒤에 이전 파일을 지웁니다.
    db.refresh(book)
    return book
순서하는 일이 순서인 이유
1도서 찾기, 권한 검사남의 도서에 표지를 올리지 못하게 합니다.
2파일 검사검사를 통과하지 못하면 아무것도 저장하지 않습니다.
3새 파일 저장, 주소를 도서에 넣고 commit파일이 있어야 주소를 저장할 수 있습니다.
4이전 표지 파일 삭제commit이 성공한 뒤에 지웁니다. 먼저 지웠는데 commit이 실패하면 도서는 이미 없는 파일을 가리키게 됩니다.

파일 시스템은 데이터베이스 트랜잭션에 포함되지 않아 rollback으로 되돌릴 수 없습니다. 그래서 "되돌릴 수 없는 일은 확정한 뒤에 한다"는 순서를 지킵니다. 도서를 삭제할 때도 같은 이유로 commit 뒤에 표지 파일을 지웁니다.

StaticFiles는 폴더의 파일을 주소로 그대로 내보내 주는 기능입니다. app.mount로 /covers 아래의 요청을 uploads/covers 폴더와 연결합니다. 폴더가 없으면 서버가 시작하지 않으므로 먼저 만듭니다.

Swagger UI로 보내기

POST /books/{book_id}/cover를 펼치면 요청 본문 자리에 파일 선택 버튼이 있습니다. 이미지를 고르고 Execute를 누르면 multipart 형식으로 전송됩니다. 응답의 cover_url을 브라우저 주소창에 http://127.0.0.1:8000과 이어 붙여 열면 올린 이미지가 보이고, book-api/uploads/covers 폴더에는 무작위 이름의 파일이 생깁니다.
