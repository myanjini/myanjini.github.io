확인 퀴즈

모임 목록은 누구나 볼 수 있습니다. 다른 사람이 남의 모임을 삭제하려 하면 어떤 상태 코드가 알맞은가요?

모임이 있다는 사실은 공개 정보이므로, 권한이 없다는 뜻의 403이 알맞습니다.

"참가 신청" 기능의 URI로 가장 알맞은 것은 무엇인가요?

"모임의 참가자 목록에 추가"로 바꿔 생각하면 하위 자원에 POST하는 모양이 됩니다.
