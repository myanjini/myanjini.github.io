정리: 테스트 격리

핵심 요약

  • 테스트 격리: 테스트마다 빈 데이터베이스에서 시작하고 끝나면 버려, 순서와 횟수에 상관없이 같은 결과를 냅니다.
  • fixture는 테스트의 준비물을 만드는 함수입니다. yield 앞은 준비, 뒤는 정리이고, 다른 fixture를 받아 쌓을 수 있습니다.
  • 기본 범위는 테스트 함수마다 새로 만드는 function입니다.
  • app.dependency_overrides로 get_db를 테스트용 세션으로 바꿔 끼우고, 끝나면 clear()합니다.
  • 앱을 불러오기 전에 테스트용 SECRET_KEY를 환경 변수로 넣어 .env 없이도 테스트가 돌게 합니다.

확인 퀴즈

fixture에서 yield 뒤에 적은 코드는 언제 실행되나요?

yield 뒤는 정리 코드로, 테스트 결과와 상관없이 실행됩니다.

app.dependency_overrides[get_db] = override_get_db가 하는 일은 무엇인가요?

앱 코드는 그대로 두고, 의존성만 테스트용으로 바꿔 끼웁니다.

conftest.py 맨 위에서 os.environ["SECRET_KEY"]를 넣는 이유로 가장 알맞은 것은 무엇인가요?

SECRET_KEY는 기본값이 없어 반드시 필요합니다. .env는 Git에 올리지 않으므로 테스트가 직접 넣습니다.

다음 파트
