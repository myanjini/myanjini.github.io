3일차에 만든 것

주제한 줄 요약코드 위치
인증비밀번호는 Argon2 해시로 저장하고, 로그인하면 액세스 토큰(15분)과 리프레시 토큰(14일)을 발급합니다.app/security.py, app/routers/auth.py
인가로그인 여부는 401, 권한은 403. 본인이나 관리자만 도서를 고칩니다.get_current_user, check_can_modify
계층 분리라우터는 HTTP, 서비스는 규칙과 commit, 저장소는 쿼리를 맡습니다.app/routers, services, repositories
파일 업로드확장자와 크기를 검사하고 무작위 이름으로 저장합니다.app/services/covers.py
대여재고 감소, 재고 기록, 대여 기록을 하나의 트랜잭션으로 처리합니다.app/services/loans.py

어제 시험 표를 채우며 한 일

3일차 시험 표를 채우느라 Swagger UI에서 로그인하고, 계정을 바꾸고, 요청을 보내고, 결과를 눈으로 확인하는 일을 40번 넘게 했습니다. 오늘 코드를 한 줄 고칠 때마다 이 일을 다시 해야 한다면 어떨까요? 4일차 오전에는 이 확인을 코드로 적어 두고 명령 한 번으로 실행하는 자동 테스트를 만들고, 코드를 올릴 때마다 GitHub가 대신 실행해 주도록 설정합니다.
