S7. 테스트 자동화와 CI

섹션 목표pytest로 API의 정상 흐름과 오류 흐름을 검증하고, GitHub Actions로 테스트를 자동 실행합니다.

S7-P22 pytest와 TestClient

TestClient로 API 테스트를 작성하고 실행할 수 있습니다.

  1. 3일차 복습 주요 개념, 5분
  2. 테스트가 필요한 이유 주요 개념, 10분
  3. 첫 API 테스트 주요 개념, 10분
  4. CRUD 테스트 작성 실습, 20분
  5. 정리: 테스트 기초 정리, 5분

S7-P23 테스트 DB와 fixture

fixture와 의존성 재정의로 테스트를 서로 격리할 수 있습니다.

  1. fixture와 테스트 격리 주요 개념, 10분
  2. 테스트용 DB 연결 주요 개념, 10분
  3. 테스트 환경 구성 실습, 25분
  4. 정리: 테스트 격리 정리, 5분

S7-P24 인증 API 테스트와 커버리지

인증이 필요한 API를 테스트하고 커버리지로 빠진 부분을 찾을 수 있습니다.

  1. 인증 흐름 테스트 전략 주요 개념, 5분
  2. 인증 테스트 작성 실습, 20분
  3. 커버리지 측정 주요 개념, 10분
  4. 부족한 테스트 보완 실습, 10분
  5. 정리: 인증 테스트 정리, 5분

S7-P25 GitHub Actions로 테스트 자동화하기

저장소에 코드를 올릴 때마다 테스트가 자동으로 실행되도록 CI를 구성할 수 있습니다.

  1. CI와 GitHub Actions 주요 개념, 10분
  2. 테스트 워크플로 작성 주요 개념, 10분
  3. 내 저장소에 CI 적용 실습, 20분
  4. CI 결과 활용하기 주요 개념, 5분
  5. 정리: 테스트 자동화 정리, 5분
