부록 C. 배포 전 보안 점검 체크리스트

구분번호확인 항목
애플리케이션1비밀 키, DB 비밀번호가 코드와 저장소에 없고 Parameter Store로만 전달되는가
애플리케이션2오류 응답에 스택 트레이스, DB 오류, 내부 경로가 노출되지 않는가
애플리케이션3운영 환경에서 디버그 설정과 API 문서(/docs) 공개 여부를 정했는가
애플리케이션4CORS 허용 Origin이 운영 주소로만 제한되어 있는가
애플리케이션5로그인 실패 제한과 토큰 만료 시간이 설정되어 있는가
애플리케이션6업로드 파일의 형식, 크기, 이름이 검증되고 S3 버킷의 퍼블릭 접근이 차단되어 있는가
애플리케이션7bandit과 pip-audit 결과의 조치 대상이 모두 처리되었는가
AWS8루트 계정을 사용하지 않고 MFA가 설정되어 있는가
AWS9EC2 역할에 필요한 권한만 있는가
AWS10EC2 보안 그룹이 ALB에서 오는 요청만 허용하고 SSH 포트를 열지 않았는가
AWS11RDS가 프라이빗 서브넷에 있고 퍼블릭 액세스가 꺼져 있으며 저장 데이터가 암호화되어 있는가
AWS12GitHub Actions가 장기 액세스 키 대신 OIDC 역할을 쓰는가
AWS13CloudWatch 로그에 민감정보가 남지 않고 보존 기간이 설정되어 있는가
AWS14모든 자원에 Owner 태그가 있고 예산 경보가 설정되어 있는가
