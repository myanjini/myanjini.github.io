부록 E. 실습 데이터와 AWS 실습 수칙

회원가입과 로그인 실습에는 실제 이메일이나 개인 비밀번호 대신 가상의 계정(예: user1@example.com)과 실습용 비밀번호를 사용합니다. 파일 업로드 실습에도 개인 사진이나 문서 대신 강사가 제공한 샘플 이미지를 사용하고, 미니 프로젝트에서도 실제 개인정보를 넣지 않고 가상 데이터로만 시연합니다.

AWS 실습에서는 다음을 지킵니다.

번호수칙
1기관이 지정한 서울 리전에서만 자원을 만든다.
2모든 자원에 Owner 태그(본인 식별자)를 붙인다.
3액세스 키를 만들지 않고, 만들었다면 코드, 저장소, 화면 공유, 메신저 어디에도 남기지 않는다.
4보안 그룹에서 0.0.0.0/0 인바운드는 ALB의 HTTP·HTTPS 외에는 열지 않는다.
5보안약점 진단 실습과 공격 재현은 본인 자원과 강사가 제공한 예제에만 수행한다.
6과정이 끝나면 부록 G에 따라 자원을 모두 삭제한다.
