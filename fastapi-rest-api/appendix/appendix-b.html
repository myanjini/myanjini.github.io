부록 B. API 명세서 양식

기능메서드URI요청 본문과 검증 규칙응답상태 코드인증/권한
예: 모임 등록POST/studiestitle(1~100자), description(최대 1000자), capacity(2~50)StudyRead201, 401, 422로그인 사용자
예: 모임 목록GET/studies?keyword=&page=keyword(최대 50자), page(1 이상)페이지 정보와 StudyRead 목록200, 422없음
예: 모임 삭제DELETE/studies/{study_id}없음없음204, 401, 403, 404개설자 본인

명세서 아래에는 주요 위협과 보안 요구사항(예: 다른 사용자의 모임 수정 차단, 로그인 실패 제한, 첨부 파일 형식 제한)을 3개 이상 적습니다.
