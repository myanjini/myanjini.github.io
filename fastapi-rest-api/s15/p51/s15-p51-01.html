CloudWatch 개요

이 파트의 학습 목표컨테이너 로그를 CloudWatch로 모으고 경보를 설정할 수 있습니다.

서비스를 운영한다는 것은 "지금 잘 돌고 있는가"를 계속 알고 있는 것입니다. CloudWatch는 AWS의 로그, 지표, 경보를 한곳에서 다루는 서비스입니다.

기능뜻이번 실습
로그 그룹과 로그 스트림로그를 모아 두는 곳입니다. 로그 그룹은 서비스 단위의 묶음이고, 그 안의 로그 스트림은 보내는 쪽(컨테이너) 하나에 해당합니다. 보존 기간은 로그 그룹마다 정합니다./book-api/app, 30일 보존
Logs Insights로그 그룹에 질의 언어로 검색과 집계를 합니다. JSON 로그는 필드를 자동으로 알아봅니다.요청 ID로 추적, 상태 코드별 집계
지표(metric)시간에 따른 숫자입니다. EC2의 CPU 사용률, 상태 검사 실패처럼 AWS가 자동으로 모으는 것과, 로그에서 만들어 내는 것이 있습니다.CPUUtilization, StatusCheckFailed
경보(alarm)지표가 정한 조건을 넘으면 상태가 경보로 바뀌고, SNS 주제로 메일 같은 알림을 보냅니다.CPU 80% 이상, 상태 검사 실패

S8과 S10에서 준비해 둔 것

도서 API는 S8에서 로그를 JSON 한 줄씩 남기게 했고, 요청마다 요청 ID를 붙여 응답 헤더(X-Request-ID)와 로그에 함께 적었습니다. S10에서는 이메일과 토큰을 가리는 마스킹을 넣었습니다. 이 준비 덕분에 CloudWatch에서 "이 사용자가 오류 화면에서 본 요청 ID"로 그 요청의 로그를 바로 찾을 수 있습니다.

요금

CloudWatch Logs는 받아들인 로그의 양(GB)과 보관한 양에, 경보는 경보 개수에 요금이 붙습니다. AWS가 자동으로 모으는 EC2의 기본 지표(5분 간격)는 추가 요금이 없습니다. 보존 기간을 정하지 않으면 로그를 영원히 보관하므로, 로그 그룹을 만들 때 보존 기간을 꼭 정합니다.
