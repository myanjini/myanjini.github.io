교시만든 것핵심
1교시S3 표지 저장비공개 버킷, 미리 서명된 URL(5분), 서버가 만든 이름만 허용, covers/* 권한
2교시CloudWatch 로그와 경보awslogs 드라이버, 30일 보존, 요청 ID 추적, CPU와 상태 검사 경보
3교시ALB인터넷 입구는 ALB 하나, EC2는 ALB 보안 그룹만 허용, 진짜 사용자 IP, HTTPS 과정
4교시배포 자동화OIDC 역할, 테스트 통과 후에만 배포, Run Command, 배포 확인

이제 도서 API는 서버 안에 데이터를 하나도 갖지 않습니다. 데이터는 RDS, 파일은 S3, 비밀 값은 Parameter Store, 로그는 CloudWatch에 있고, 서버는 ECR의 이미지를 받아 실행만 합니다. 서버를 지우고 새로 만들어도 같은 서비스가 이어지는 구조입니다.
