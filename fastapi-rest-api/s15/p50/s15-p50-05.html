핵심 요약

주제핵심
S3버킷(전 세계에서 유일한 이름)과 객체(키로 찾음). 서버가 몇 대든 같은 저장소를 씁니다.
기본 보안퍼블릭 액세스 차단, ACL 비활성화, 기본 암호화를 그대로 둡니다.
미리 서명된 URL비공개 객체를 정해진 시간만 내려받게 합니다. 짧게(5분) 두고 로그에 남기지 않습니다.
코드저장 위치만 설정으로 바꾸고, 파일 검사와 API 주소는 그대로 둡니다. 키는 서버가 만든 이름만 허용합니다.
권한역할에 이 버킷 covers/*의 Put, Get, Delete만 줍니다.

확인 퀴즈

표지 버킷을 공개하지 않고도 브라우저가 이미지를 볼 수 있는 이유는 무엇인가요?

서명된 URL은 만든 쪽의 권한으로, 정해진 시간 동안만 동작합니다.

/covers/{filename}에서 이름 모양을 정규식으로 먼저 검사하는 이유로 가장 알맞은 것은 무엇인가요?

서버가 만든 이름만 받는 허용 목록입니다. S9-P31의 경로 조작 방어와 같은 생각입니다.

EC2 역할에 s3:GetObject가 없으면 무슨 일이 생기나요?

URL을 만드는 것은 계산일 뿐이고, 실제로 받을 때 서명한 쪽의 권한을 확인합니다.
