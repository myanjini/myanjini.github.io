저자와 도서 연결하기

Author 모델을 추가하고 도서와 연결한 뒤, 응답에서 저자 정보를 중첩해 보여 주는 과정을 강사 화면으로 봅니다.

모델

app/models.py
from sqlalchemy import ForeignKey, String
from sqlalchemy.orm import Mapped, mapped_column, relationship

from app.database import Base


class Author(Base):
    __tablename__ = "authors"

    id: Mapped[int] = mapped_column(primary_key=True)
    name: Mapped[str] = mapped_column(String(50), unique=True)

    # 이 저자가 쓴 도서 목록. Book.author와 서로 연결됩니다.
    books: Mapped[list["Book"]] = relationship(back_populates="author")


class Book(Base):
    __tablename__ = "books"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(100))
    price: Mapped[int]
    isbn: Mapped[str | None] = mapped_column(String(13), unique=True)

    # 테이블에 저장되는 열: 저자의 번호
    author_id: Mapped[int] = mapped_column(ForeignKey("authors.id"))
    # 파이썬에서 쓰는 속성: 저자 객체
    author: Mapped["Author"] = relationship(back_populates="books")

도서의 author는 이제 글자가 아니라 관계입니다. 저자 이름은 authors 테이블에만 있습니다.

등록할 때는 번호(author_id)를 받고, 돌려줄 때는 번호와 이름이 담긴 저자 객체를 넣습니다. 응답 모델 안에 다른 응답 모델을 넣는 것을 중첩 모델이라고 합니다. book.author가 Author 객체이므로 AuthorRead가 그 속성을 읽어 바꿉니다.

없는 저자 번호를 보내면

def check_author_exists(db: Session, author_id: int | None) -> None:
    """요청에 적힌 저자 번호가 실제로 있는지 확인합니다."""
    if author_id is None:
        return
    if db.get(Author, author_id) is None:
        raise AppError(422, "INVALID_AUTHOR", f"{author_id}번 저자가 없습니다.")

이 오류는 422로 보냅니다. 요청 주소의 도서가 없는 것(404)이 아니라, 요청 본문에 적힌 값이 유효하지 않은 것이기 때문입니다.
