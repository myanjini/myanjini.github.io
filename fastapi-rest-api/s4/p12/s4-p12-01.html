수정과 삭제의 흐름

이 파트의 학습 목표수정, 삭제 API와 검색, 정렬, 페이지네이션을 DB 쿼리로 구현할 수 있습니다.

오전에 등록과 조회를 데이터베이스로 옮겼습니다. 수정과 삭제도 같은 세션으로 처리하는데, 순서만 기억하면 어렵지 않습니다.

수정의 흐름

순서하는 일코드
찾기번호로 도서를 꺼냅니다. 없으면 404입니다.find_book(db, book_id)
검사하기바꿀 값이 규칙에 맞는지 확인합니다. ISBN이 겹치면 409입니다.check_isbn_unique(...)
바꾸기꺼낸 객체의 속성을 바꿉니다.book.price = 19000
확정하기데이터베이스에 반영합니다.db.commit()
다시 읽기저장된 최신 값을 객체에 채웁니다.db.refresh(book)

세션에서 꺼낸 객체는 세션이 지켜보고 있습니다. 속성을 바꾼 뒤 commit하면 SQLAlchemy가 바뀐 열만 골라 UPDATE 문을 실행합니다. 따로 add할 필요가 없습니다.

보낸 항목만 바꾸기

changes = book_in.model_dump(exclude_unset=True, exclude_none=True)
for field, value in changes.items():
    setattr(book, field, value)

1일차 PATCH와 같은 방법으로 바꿀 항목만 꺼냅니다. setattr(book, "price", 19000)은 book.price = 19000과 같은 뜻으로, 속성 이름을 문자열로 받아 값을 넣는 Python 내장 함수입니다. 어떤 항목이 올지 미리 모르기 때문에 이 방법을 씁니다.

삭제의 흐름

book = find_book(db, book_id)
db.delete(book)
db.commit()

PUT은 어디 갔나요

1일차에는 PUT과 PATCH를 모두 만들었습니다. 실제 서비스에서는 일부만 바꾸는 PATCH를 훨씬 많이 쓰므로, 데이터베이스 버전에서는 PATCH만 만들고 이후 과정도 PATCH를 씁니다. PUT을 만들고 싶다면 바꾸기 단계에서 book_in.model_dump() 전체를 넣으면 됩니다.
