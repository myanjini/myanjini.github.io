안전한 오류 응답 적용

앞 페이지에서 찾은 다섯 가지를 모두 고칩니다. 오류 응답은 정해진 모양으로 통일하고, 자세한 내용은 가린 채 로그에만 남깁니다.

실습 목표전역 예외 처리, 입력 값 없는 422 응답, 로그 마스킹, 운영 환경 문서 비활성화를 적용할 수 있습니다.

  1. 처리하지 못한 오류를 안전한 500으로

    요청 미들웨어에서 예외를 잡아, 로그에는 자세히 남기고 응답은 정해진 JSON으로 보냅니다. 처리 시간 헤더는 빼고 로그에만 남깁니다.

    app/main.py
    @app.middleware("http")
async def log_requests(request: Request, call_next):
    request_id_var.set(uuid.uuid4().hex[:16])  # 이 요청에서 남기는 모든 로그에 같은 ID가 붙습니다.
    start = time.perf_counter()
    info = {"method": request.method, "path": request.url.path}
    try:
        response = await call_next(request)  # 실제 경로 함수가 여기서 실행됩니다.
    except Exception:
        # 자세한 내용은 로그에만 남기고, 사용자에게는 정해진 문구와 요청 ID만 보냅니다.
        logger.exception("처리하지 못한 오류", extra=info)
        response = JSONResponse(status_code=500, content={
            "code": "INTERNAL_ERROR",
            "message": "요청을 처리하지 못했습니다. 문제가 계속되면 요청 ID를 알려 주세요.",
            "request_id": request_id_var.get(),
        })
    duration_ms = round((time.perf_counter() - start) * 1000, 1)
    response.headers["X-Request-ID"] = request_id_var.get()
    logger.info("요청 처리", extra={**info, "status": response.status_code, "duration_ms": duration_ms})
    return response

    S8에서는 예외를 다시 던져 FastAPI 기본 처리에 맡겼기 때문에 uvicorn도 같은 오류를 한 번 더 기록했습니다. 이제 미들웨어가 직접 응답하므로 오류 로그가 한 번만 남고, 500 응답에도 X-Request-ID가 붙습니다.

  2. 422 응답에서 입력 값 빼기

    app/main.py
    @app.exception_handler(RequestValidationError)
def handle_validation_error(request: Request, exc: RequestValidationError):
    # 기본 422 응답은 보낸 값(input)을 그대로 되돌려 줍니다. 비밀번호가 응답에 실리지 않게 위치와 이유만 남깁니다.
    errors = [{"loc": list(e["loc"]), "msg": e["msg"], "type": e["type"]} for e in exc.errors()]
    return JSONResponse(status_code=422, content={
        "code": "VALIDATION_ERROR",
        "message": "요청 값이 올바르지 않습니다.",
        "errors": errors,
    })

    가져오기에 from fastapi.exceptions import RequestValidationError를 추가합니다. 이제 모든 오류 응답이 code와 message를 가진 같은 모양이 됩니다. 앞선 단원의 화면에 나온 422 응답(detail 모양)은 이 시점부터 바뀝니다. 화면 개발자에게도 알려 줍니다.

  4. 로그 마스킹

    실수로 로그에 들어간 이메일, 토큰, 비밀번호 해시를 기록 직전에 한 번 더 가립니다. 마스킹은 안전망입니다. 비밀번호 원문처럼 모양으로 알아볼 수 없는 값은 가릴 수 없으므로, 애초에 로그에 넣지 않는 것이 먼저입니다.

    app/privacy.py
    # 로그에 섞여 들어오면 가릴 값들
EMAIL_PATTERN = re.compile(r"[\w.+-]+@[\w-]+(?:\.[\w-]+)+")
JWT_PATTERN = re.compile(r"eyJ[\w-]+\.[\w-]+\.[\w-]+")
PASSWORD_HASH_PATTERN = re.compile(r"\$argon2[a-z]*\$[^\s'\",)]+")


def mask_text(text: str) -> str:
    """글자 속의 이메일, 토큰, 비밀번호 해시를 가립니다."""
    text = JWT_PATTERN.sub("[TOKEN]", text)
    text = PASSWORD_HASH_PATTERN.sub("[PASSWORD_HASH]", text)
    return EMAIL_PATTERN.sub(lambda m: mask_email(m.group()), text)

    app/privacy.py 맨 위에 import re를 추가합니다. app/logging_config.py에서는 메시지, extra 값, 트레이스백 세 곳에 mask_text를 씌웁니다.

    app/logging_config.py
                "message": mask_text(record.getMessage()),
            ...
                data[key] = mask_text(value) if isinstance(value, str) else value
            ...
            data["error"] = mask_text(self.formatException(record.exc_info))

def login(client, email, password):
    return client.post("/auth/token", data={"username": email, "password": password})


def test_login_is_locked_after_five_failures(client, make_user):
    make_user("user1@example.com")
    for _ in range(5):
        assert login(client, "user1@example.com", "wrong-pass-0").status_code == 401
    response = login(client, "user1@example.com", "test-pass-123")  # 맞는 비밀번호여도 잠깁니다.
    assert response.status_code == 429
    assert response.headers["Retry-After"] == "900"


def test_successful_login_resets_failures(client, make_user):
    make_user("user1@example.com")
    for _ in range(4):
        login(client, "user1@example.com", "wrong-pass-0")
    assert login(client, "user1@example.com", "test-pass-123").status_code == 200
    for _ in range(4):
        login(client, "user1@example.com", "wrong-pass-0")
    assert login(client, "user1@example.com", "test-pass-123").status_code == 200

def make_token(payload: dict, key: str = TEST_KEY, algorithm: str = "HS256") -> str:
    return jwt.encode(payload, key, algorithm=algorithm)


@pytest.mark.parametrize("token", [
    make_token({"sub": "1", "exp": datetime.now(timezone.utc) - timedelta(minutes=1)}),    # 만료
    make_token({"sub": "1"}),                                                               # exp 없음
    make_token({"sub": "1", "exp": datetime.now(timezone.utc) + timedelta(minutes=5)}, "other-key-" * 4),  # 다른 키
    make_token({"sub": "1", "exp": datetime.now(timezone.utc) + timedelta(minutes=5)}, None, "none"),     # 서명 없음
])
def test_invalid_tokens_are_rejected(client, make_user, token):
    make_user("user1@example.com")
    response = client.get("/auth/me", headers={"Authorization": f"Bearer {token}"})
    assert response.status_code == 401
