확인 퀴즈

처리하지 못한 예외가 났을 때 사용자 응답에 담기에 알맞은 것은 무엇인가요?

자세한 내용은 로그에만 남기고, 사용자에게는 정해진 문구와 로그를 찾을 단서(요청 ID)만 줍니다.

FastAPI의 기본 422 응답에서 비밀번호가 새는 이유는 무엇인가요?

RequestValidationError 처리기로 위치와 이유만 응답하게 바꿉니다.

로그 마스킹에 대한 설명으로 알맞은 것은 무엇인가요?

비밀번호 원문처럼 모양이 정해지지 않은 값은 가릴 수 없습니다.

6일차 예고

6일차 오전에는 동시에 대여하면 재고보다 많이 빌려지는 경쟁 조건을 재현해 고치고, bandit과 pip-audit으로 코드와 패키지를 자동 점검한 뒤, 강사가 준비한 진단용 API로 보안약점 진단 실습을 합니다. 오후부터는 AWS 기초(클라우드, IAM, VPC)를 배우며 배포를 준비합니다.
