첫 API 테스트

pytest를 설치하고 첫 테스트를 실행하는 모습을 강사 화면으로 봅니다. 테스트가 성공할 때와 실패할 때 화면을 읽는 방법도 함께 봅니다.

설치와 폴더 구성

pip install pytest

pytest는 Python에서 가장 널리 쓰는 테스트 도구입니다. tests 폴더에서 이름이 test_로 시작하는 파일을 찾고, 그 안에서 이름이 test_로 시작하는 함수를 모두 실행합니다.

book-api/
├── pytest.ini              pytest 설정
├── app/
└── tests/
    ├── __init__.py         빈 파일. tests를 패키지로 만듭니다.
    ├── test_security.py    단위 테스트
    └── test_books.py       API 테스트
pytest.ini
[pytest]
# 프로젝트 폴더를 import 경로에 넣어 tests 안에서 app 패키지를 찾게 합니다.
pythonpath = .
testpaths = tests

pythonpath = .가 없으면 pytest가 tests 폴더 안에서 app 패키지를 찾지 못해 ModuleNotFoundError: No module named 'app'가 납니다. testpaths = tests는 테스트를 tests 폴더에서만 찾으라는 뜻입니다.

단위 테스트

tests/test_security.py
from app.security import hash_password, verify_password


def test_hash_is_not_plain_password():
    # 준비
    password = "practice-pass-1"
    # 실행
    hashed = hash_password(password)
    # 검증
    assert hashed != password
    assert hashed.startswith("$argon2id$")


def test_verify_password():
    hashed = hash_password("practice-pass-1")
    assert verify_password("practice-pass-1", hashed) is True
    assert verify_password("wrong-pass", hashed) is False

API 테스트: TestClient

TestClient는 서버를 실행하지 않고도 앱에 HTTP 요청을 보내 주는 도구입니다. client.get, client.post처럼 쓰고, 돌려받은 응답에서 status_code와 json()을 꺼내 검증합니다.

tests/test_books.py
from fastapi.testclient import TestClient

from app.main import app

client = TestClient(app)


def test_health():
    # 실행
    response = client.get("/health")
    # 검증
    assert response.status_code == 200
    assert response.json() == {"status": "ok"}


def test_list_books():
    response = client.get("/books")
    assert response.status_code == 200
    body = response.json()
    assert "items" in body
    assert body["total"] >= 0


def test_get_missing_book_returns_404():
    response = client.get("/books/999999")
    assert response.status_code == 404
    assert response.json()["code"] == "BOOK_NOT_FOUND"
