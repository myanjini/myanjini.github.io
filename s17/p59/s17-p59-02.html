권한 검사 적용

명세의 권한 표를 코드로 옮깁니다. 표의 칸마다 어떤 코드가 대응하는지 정해 두면, 빠뜨린 곳 없이 옮길 수 있습니다.

실습 목표권한 표에 따라 보호 API와 소유자 검사를 적용하고, 다른 사용자로 요청해 막히는지 확인할 수 있습니다.

권한 표의 칸과 코드

권한 표의 값코드막히면
없음(누구나)의존성을 붙이지 않음-
로그인 사용자경로 함수 인자에 user: CurrentUserDep401
소유자 본인(또는 관리자)서비스에서 자원을 찾은 뒤 check_can_modify(자원, user)403 또는 404
관리자만경로 함수 인자에 user: Annotated[User, Depends(require_admin)]403

  1. 소유자 검사 함수

    app/services/studies.py에 추가합니다. 도서 API의 check_can_modify(S5-P17-03)와 같은 모양입니다.

    app/services/studies.py에 추가
    def check_can_modify(study: Study, user: User) -> None:
    """개설자나 관리자만 모임을 수정, 삭제하고 명단을 볼 수 있습니다."""
    if user.role == "admin" or study.owner_id == user.id:
        return
    raise AppError(403, "FORBIDDEN", "모임을 개설한 사람만 할 수 있습니다.")

  2. 필요한 곳에서 부르기

    P58에서 주석으로 표시해 둔 자리를 검사 호출로 바꿉니다. 자원을 먼저 찾고(없으면 404), 그다음 권한을 검사합니다(남의 것이면 403).

    app/services/studies.py
    def update_study(db: Session, user: User, study_id: int, study_in: StudyUpdate) -> Study:
    study = find_study(db, study_id)
    check_can_modify(study, user)
    ...


def delete_study(db: Session, user: User, study_id: int) -> None:
    study = find_study(db, study_id)
    check_can_modify(study, user)
    ...

    검사를 라우터가 아니라 서비스에 두는 이유는, 같은 서비스 함수를 다른 경로(예: 관리자 화면)에서 불러도 검사가 빠지지 않게 하려는 것입니다.

  3. 다른 사용자로 확인

    # user1이 모임을 만들고, user2로 수정과 삭제를 시도합니다.
curl -s -X PATCH $B/studies/1 -H "Authorization: Bearer $TOKEN2" -H "Content-Type: application/json" -d '{"title":"x"}'
{"code":"FORBIDDEN","message":"모임을 개설한 사람만 할 수 있습니다."}
curl -s -o /dev/null -w "%{http_code}\n" -X DELETE $B/studies/1 -H "Authorization: Bearer $TOKEN2"
403
curl -s -o /dev/null -w "%{http_code}\n" -X DELETE $B/studies/999 -H "Authorization: Bearer $TOKEN2"
404
curl -s -o /dev/null -w "%{http_code}\n" -X DELETE $B/studies/1 -H "Authorization: Bearer $ADMIN"
204

  4. 권한 표 대조

    명세의 권한 표를 한 줄씩 보며, 칸의 값과 실제 응답이 같은지 표시합니다. 다른 칸이 있으면 명세와 코드 가운데 하나를 고칩니다.

    기능로그인 안 함로그인 사용자소유자 본인관리자

목록 API에도 권한이 있을 수 있습니다

"내 할 일 목록"처럼 본인 것만 보여야 하는 목록은, 검사 함수 대신 질의 조건(where(Todo.owner_id == user.id))으로 막습니다. 목록을 먼저 다 가져온 뒤 파이썬에서 거르면 페이지 개수와 전체 개수가 틀어지고, 거르는 코드를 빠뜨리기 쉽습니다.
