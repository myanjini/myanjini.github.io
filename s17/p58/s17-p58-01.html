명세를 넣은 뒤API 명세서 추가

저장소 만들기

내려받은 project-starter.zip을 작업 폴더로 옮긴 뒤, 운영체제에 맞는 명령을 실행합니다.

Windows 명령 프롬프트:

tar -xf project-starter.zip
ren project-starter study-api
cd study-api
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(32))"

macOS 터미널:

unzip project-starter.zip && mv project-starter study-api && cd study-api
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(32))"

마지막 명령이 출력한 값을 .env의 SECRET_KEY= 뒤에 붙여 넣습니다. Windows 10 이상에는 tar가 들어 있어 zip 파일도 풀 수 있습니다. 이어서 테스트가 모두 통과하는지 확인합니다.

pytest -q

8 passed in 1.71s

S17-P57에서 작성한 api-spec.md를 프로젝트의 docs 폴더로 옮기고 첫 커밋을 합니다. 아래 Git 명령은 어느 운영체제든 같습니다.

mkdir docs
git init -b main
git add .
git commit -m "시작 템플릿으로 프로젝트 생성"

GitHub에 새 저장소(예: study-api)를 만들고 git remote add origin, git push -u origin main으로 올립니다. 푸시하면 배포 워크플로가 실행되지만, 배포 역할 변수(AWS_DEPLOY_ROLE_ARN)를 아직 등록하지 않았으므로 테스트와 보안 점검만 하고 배포 단계는 건너뜁니다. 배포는 S18-P61에서 켭니다.
