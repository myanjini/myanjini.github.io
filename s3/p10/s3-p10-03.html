모델 정의와 테이블 생성

데이터베이스 연결 파일과 모델 파일을 만들고, 서버가 시작할 때 테이블이 만들어지는 과정을 강사 화면으로 봅니다.

database.py

app/database.py
from sqlalchemy import create_engine
from sqlalchemy.orm import DeclarativeBase, sessionmaker

from app.config import settings

# SQLite는 기본적으로 한 스레드에서만 연결을 쓰게 되어 있어 이 옵션을 끕니다.
connect_args = {"check_same_thread": False} if settings.database_url.startswith("sqlite") else {}

engine = create_engine(settings.database_url, connect_args=connect_args)
SessionLocal = sessionmaker(bind=engine, autoflush=False)


class Base(DeclarativeBase):
    """모든 모델 클래스가 상속하는 기본 클래스입니다."""

주소를 코드에 적지 않고 설정(settings.database_url)에서 읽습니다. check_same_thread 옵션은 SQLite일 때만 필요해서 주소가 sqlite로 시작할 때만 넣습니다.

models.py

app/models.py
from sqlalchemy import String
from sqlalchemy.orm import Mapped, mapped_column

from app.database import Base


class Book(Base):
    __tablename__ = "books"

    id: Mapped[int] = mapped_column(primary_key=True)
    title: Mapped[str] = mapped_column(String(100))
    author: Mapped[str] = mapped_column(String(50))
    price: Mapped[int]
    isbn: Mapped[str | None] = mapped_column(String(13), unique=True)

1일차의 매입가(cost)는 실습을 단순하게 하려고 데이터베이스 모델에는 넣지 않습니다.

테이블 만들기

app/main.py
from app import models  # noqa: F401  모델을 불러와야 테이블 목록에 등록됩니다.
from app.database import Base, engine

# 아직 없는 테이블을 만듭니다. 2일차 오후(S4-P14)에 Alembic으로 바꿉니다.
Base.metadata.create_all(bind=engine)

Base를 상속한 클래스는 불러오는 순간 Base.metadata라는 목록에 등록됩니다. 그래서 models를 먼저 불러온 뒤 create_all을 실행해야 books 테이블이 만들어집니다. 이 줄의 models는 코드에서 직접 쓰지 않지만 지우면 안 됩니다.

실제로 만들어지는 테이블

서버를 실행하면 book-api 폴더에 books.db가 생기고, SQLAlchemy가 다음 SQL을 실행한 것과 같은 테이블이 만들어집니다.

CREATE TABLE books (
    id INTEGER NOT NULL,
    title VARCHAR(100) NOT NULL,
    author VARCHAR(50) NOT NULL,
    price INTEGER NOT NULL,
    isbn VARCHAR(13),
    PRIMARY KEY (id),
    UNIQUE (isbn)
)

create_all의 한계

create_all은 없는 테이블만 만듭니다. 이미 있는 테이블에 열을 추가하는 변경은 반영하지 못합니다. 그래서 2일차 마지막 시간에 테이블 변경 이력을 관리하는 Alembic으로 바꿉니다.
