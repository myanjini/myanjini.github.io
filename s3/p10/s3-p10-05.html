정리: ORM 기초

핵심 요약

  • 관계형 데이터베이스는 데이터를 테이블에 저장하고, 기본키로 행을 구분하며, 고유 제약으로 중복을 막습니다.
  • ORM은 테이블을 클래스로, 행을 객체로 다루게 해 주고, SQLAlchemy가 Python 코드를 SQL로 바꿔 실행합니다.
  • Engine은 앱에 하나, Session은 작업마다 하나씩 쓰고, 모델은 DeclarativeBase를 상속해 Mapped로 열을 정의합니다.
  • create_all은 등록된 모델 중 없는 테이블만 만듭니다.

확인 퀴즈

도서 한 권의 정보는 테이블에서 무엇에 해당하나요?

데이터 하나가 한 행입니다. 열은 제목, 가격 같은 항목입니다.

isbn: Mapped[str | None] = mapped_column(String(13), unique=True)의 뜻으로 알맞은 것은 무엇인가요?

str | None이라 값이 없어도 되고, unique=True라 중복을 막습니다. 숫자만 받는 검사는 Pydantic 모델의 pattern이 맡습니다.

Base.metadata.create_all을 실행했는데 테이블이 만들어지지 않았습니다. 가장 먼저 의심할 원인은 무엇인가요?

모델 클래스를 불러와야 Base.metadata에 등록되어 테이블이 만들어집니다.
