ORM 객체와 Pydantic 변환

데이터베이스에서 꺼낸 값은 딕셔너리가 아니라 Book 객체입니다. 응답 모델이 이 객체를 읽을 수 있게 설정 한 줄을 추가합니다.

app/schemas.py
from pydantic import BaseModel, ConfigDict


class BookRead(BaseModel):
    model_config = ConfigDict(from_attributes=True)

    id: int
    title: str
    ...

Pydantic 모델은 기본적으로 딕셔너리에서 book["title"]처럼 값을 꺼냅니다. from_attributes=True를 켜면 객체의 속성 book.title에서도 값을 읽습니다. 그래서 경로 함수가 Book 객체를 그대로 돌려줘도 response_model=BookRead가 응답으로 바꿔 줍니다.

돌려준 값from_attributes 없음from_attributes 있음
딕셔너리변환됨변환됨
Book 객체응답 검사 실패, 500 오류변환됨

응답 모델은 여전히 거름망 역할도 합니다. 나중에 Book 모델에 내부용 열이 생겨도 BookRead에 없으면 응답에 나가지 않습니다.
