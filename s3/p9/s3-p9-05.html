정리: 설정과 미들웨어

핵심 요약

  • 비밀 값과 환경마다 다른 값은 코드에 적지 않고 환경 변수와 .env로 관리합니다. .env는 Git에 올리지 않고 .env.example을 대신 올립니다.
  • pydantic-settings는 환경 변수, .env, 기본값 순으로 값을 찾고, 필수 설정이 빠지면 서버를 시작하지 않습니다.
  • 미들웨어는 모든 요청과 응답이 거치는 관문이고, call_next 앞뒤로 할 일을 적습니다.
  • CORS는 브라우저의 규칙이며, 서버는 허용할 출처를 명확히 정해 알려 줍니다.

확인 퀴즈

다음 중 Git 저장소에 올리면 안 되는 파일은 무엇인가요?

.env에는 실제 비밀 값이 들어 있습니다.

http://localhost:5173의 화면이 http://127.0.0.1:8000의 API를 호출할 때 CORS 설정이 필요한 이유는 무엇인가요?

주소와 포트가 다르면 다른 출처입니다. 브라우저는 서버가 허용한 출처일 때만 응답을 읽게 합니다.

처리 시간 미들웨어에서 await call_next(request) 뒤에 쓴 코드는 언제 실행되나요?

call_next가 경로 함수를 실행하고 응답을 돌려준 뒤에 나머지 코드가 실행됩니다.
