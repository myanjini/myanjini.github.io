CORS와 요청 로깅

CORS 미들웨어를 설정하고, 모든 요청의 처리 시간을 기록하는 미들웨어를 직접 만듭니다.

실습 목표허용한 출처에만 CORS 헤더가 붙는지 확인하고, 요청마다 처리 시간을 기록할 수 있습니다.

  1. CORS 미들웨어 추가

    app/main.py
    from fastapi.middleware.cors import CORSMiddleware

app = FastAPI(...)

# 이 주소에서 실행되는 웹 화면만 브라우저에서 이 API를 호출할 수 있습니다.
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins,
    allow_methods=["*"],
    allow_headers=["*"],
)

    허용할 출처 목록은 S3-P9-02에서 만든 설정값(CORS_ORIGINS)에서 읽습니다.

  2. 처리 시간 미들웨어 작성

    app/main.py
    import time

from fastapi import FastAPI, Request


@app.middleware("http")
async def log_process_time(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)  # 실제 경로 함수가 여기서 실행됩니다.
    elapsed_ms = (time.perf_counter() - start) * 1000
    response.headers["X-Process-Time"] = f"{elapsed_ms:.1f}ms"
    print(f"{request.method} {request.url.path} {response.status_code} {elapsed_ms:.1f}ms")
    return response

    call_next(request) 앞이 "들어갈 때", 뒤가 "나올 때" 하는 일입니다. call_next는 기다려야 하는 함수라서 이 미들웨어만큼은 async def와 await로 씁니다. print는 4일차에 로그 기록 도구로 바꿉니다.

  3. 허용된 출처로 요청

    -H "Origin: ..."은 브라우저처럼 출처를 밝혀 요청하는 옵션입니다.

    curl -i -H "Origin: http://localhost:5173" http://127.0.0.1:8000/books

    응답 헤더에 access-control-allow-origin: http://localhost:5173과 x-process-time이 보입니다.

  4. 허용되지 않은 출처로 요청

    curl -i -H "Origin: http://evil.example" http://127.0.0.1:8000/books

    응답 본문은 그대로 오지만 access-control-allow-origin 헤더가 없습니다. 브라우저였다면 이 응답을 화면 코드가 읽지 못하게 막습니다.

  5. 터미널 기록 확인

    서버 터미널에 요청마다 GET /books 200 1.2ms 같은 줄이 찍히는지 확인합니다.

지금까지의 app/main.py

전체 코드 펼치기
app/main.py
import time

from fastapi import FastAPI, Request
from fastapi.middleware.cors import CORSMiddleware
from fastapi.responses import JSONResponse

from app.config import settings
from app.errors import AppError
from app.routers import books

app = FastAPI(
    title=settings.app_name,
    description="도서를 등록하고 조회, 수정, 삭제하는 API입니다.",
    version="0.1.0",
)

# 이 주소에서 실행되는 웹 화면만 브라우저에서 이 API를 호출할 수 있습니다.
app.add_middleware(
    CORSMiddleware,
    allow_origins=settings.cors_origins,
    allow_methods=["*"],
    allow_headers=["*"],
)


@app.middleware("http")
async def log_process_time(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)  # 실제 경로 함수가 여기서 실행됩니다.
    elapsed_ms = (time.perf_counter() - start) * 1000
    response.headers["X-Process-Time"] = f"{elapsed_ms:.1f}ms"
    print(f"{request.method} {request.url.path} {response.status_code} {elapsed_ms:.1f}ms")
    return response


@app.exception_handler(AppError)
def handle_app_error(request: Request, exc: AppError):
    # 어떤 AppError든 같은 모양의 JSON으로 바꿔 응답합니다.
    return JSONResponse(
        status_code=exc.status_code,
        content={"code": exc.code, "message": exc.message},
    )


@app.get("/", tags=["기본"])
def read_root():
    return {"message": f"{settings.app_name}에 오신 것을 환영합니다."}


@app.get("/health", tags=["기본"])
def health_check():
    return {"status": "ok"}


app.include_router(books.router)
