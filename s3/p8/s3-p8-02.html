의존성 주입의 개념

여러 API가 똑같이 필요로 하는 준비 작업을 한곳에 모아 두고, FastAPI가 알아서 넣어 주게 하는 방법이 의존성 주입입니다.

반복되는 코드

도서 목록이 수천 권이 되면 한 번에 다 보낼 수 없으니, "몇 개를 건너뛰고 몇 개를 가져올지"를 정하는 skip과 limit이 필요합니다. 그런데 오후에 만들 저자 목록, 3일차의 대여 목록도 똑같이 필요합니다. 목록 API마다 이 두 값과 검사 규칙을 매번 적으면, 나중에 최대 개수를 바꿀 때 모든 함수를 찾아 고쳐야 합니다.

Depends: 먼저 실행해서 결과를 넣어 줘

from fastapi import Depends


def pagination(skip: int = 0, limit: int = 10) -> dict:
    return {"skip": skip, "limit": limit}


@router.get("")
def list_books(page: dict = Depends(pagination)):
    ...

Depends(pagination)는 "이 함수를 실행하기 전에 pagination을 먼저 실행하고, 그 결과를 page에 넣어 달라"는 뜻입니다. 이때 pagination을 의존성이라고 부릅니다. 의존성의 매개변수(skip, limit)도 FastAPI가 요청에서 꺼내 채워 줍니다.

의존성을 쓰면 좋은 점

좋은 점설명
재사용목록 API 여러 개가 같은 의존성을 씁니다.
한 곳만 고치기최대 개수를 100에서 50으로 바꾸려면 의존성 한 곳만 고칩니다.
바꿔 끼우기4일차 테스트에서는 진짜 데이터베이스 대신 테스트용 데이터베이스를 넣도록 의존성을 바꿔 끼웁니다.

Annotated로 짧게 쓰기

from typing import Annotated

PageDep = Annotated[dict, Depends(pagination)]


@router.get("")
def list_books(page: PageDep):
    ...

Annotated는 "타입은 dict이고, 값은 Depends(pagination)로 채운다"는 정보를 한 이름에 묶어 줍니다. 여러 함수에서 page: PageDep만 쓰면 되므로 코드가 짧아집니다. FastAPI 공식 문서도 이 방식을 권합니다.
