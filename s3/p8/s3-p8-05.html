정리: 의존성 주입

핵심 요약

  • 의존성은 경로 함수보다 먼저 실행되어 그 결과를 매개변수로 넣어 주는 함수나 클래스입니다.
  • Depends로 연결하고, Annotated로 타입과 의존성을 한 이름(PageDep)에 묶어 재사용합니다.
  • 클래스 의존성은 속성으로 값을 꺼내 오타를 줄이고, Query로 검사 규칙을 붙일 수 있습니다.
  • yield 의존성은 열기, 넘겨주기, 닫기를 한 함수에 담습니다. 닫는 코드는 finally에 둡니다.

확인 퀴즈

def list_books(page: PageDep)에서 Pagination은 언제 실행되나요?

의존성은 요청이 올 때마다 경로 함수보다 먼저 실행됩니다.

yield 의존성에서 자원을 닫는 코드를 finally에 두는 이유는 무엇인가요?

finally는 오류가 나도 실행되므로, 자원이 열린 채로 남는 것을 막습니다.

목록 API 다섯 개가 같은 PageDep를 씁니다. 최대 개수를 50으로 바꾸려면 어디를 고치나요?

의존성 한 곳만 고치면 그것을 쓰는 모든 API에 반영됩니다.
