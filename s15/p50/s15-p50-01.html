질문 1. 도서 API 컨테이너는 SECRET_KEY와 DATABASE_URL을 어디에서, 어떤 권한으로 읽나요?

예시 답안 보기

시작할 때 Parameter Store의 /book-api/ 아래 SecureString에서 읽습니다. EC2에 붙인 IAM 역할의 임시 자격 증명을 쓰고, 역할은 그 경로만 읽을 수 있습니다(S14-P47).

질문 2. 지금 서버에서 도는 이미지를 이전 버전으로 되돌리려면 무엇을 바꾸나요?

예시 답안 보기

서버 ~/book-api/.env의 IMAGE 태그를 이전 버전으로 바꾸고 docker compose -f compose.prod.yaml up -d를 실행합니다(S14-P48-04).

질문 3. RDS에 닿을 수 있는 것은 무엇이고, 연결은 어떻게 보호되나요?

예시 답안 보기

book-api-sg가 붙은 EC2만 5432로 닿을 수 있습니다. 프라이빗 서브넷에 있고 퍼블릭 액세스가 꺼져 있으며, 연결은 SSL로 암호화됩니다(S13-P46).
