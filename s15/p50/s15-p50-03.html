boto3로 S3 사용하기

boto3로 S3에 파일을 올리고 지우고, 미리 서명된 URL을 만드는 코드를 봅니다. 도서 API는 저장 위치만 S3로 바꾸고, 파일 검사(S6, S9)와 API 주소는 그대로 둡니다.

바꾸는 범위

부분지금(S6~S14)바꾼 뒤
파일 검사확장자, 크기, 매직 넘버 확인그대로
저장 이름서버가 만든 uuid 이름그대로. S3 키는 covers/ + 그 이름
저장 위치uploads/covers 폴더COVER_BUCKET이 있으면 S3, 없으면 폴더(내 PC, 테스트)
DB의 cover_url/covers/이름.png그대로
/covers/이름.png 요청StaticFiles가 폴더의 파일을 돌려줌S3면 307 리디렉션으로 미리 서명된 URL, 폴더면 파일

API의 주소와 응답 모양을 바꾸지 않았으므로, 앱을 쓰는 쪽(화면)은 고칠 것이 없습니다. 설정 한 줄로 저장 위치만 바뀝니다.

저장, 삭제, URL 만들기

app/services/covers.py(save_cover, remove_cover를 바꾸고 함수 하나를 더함)
# S3에 저장할 때 쓰는 값
COVER_KEY_PREFIX = "covers/"  # 버킷 안의 폴더처럼 쓰는 이름 앞부분
CONTENT_TYPES = {".png": "image/png", ".jpg": "image/jpeg"}
COVER_NAME = re.compile(r"[0-9a-f]{32}\.(png|jpg)")  # save_cover가 만드는 이름 모양
DOWNLOAD_URL_EXPIRES = 300  # 미리 서명된 URL의 유효 시간(초)


def _s3():
    """S3 클라이언트. 액세스 키 없이 EC2 역할의 임시 자격 증명을 씁니다."""
    import boto3

    return boto3.client("s3")


def save_cover(data: bytes, ext: str) -> str:
    """겹치지 않는 새 이름으로 저장하고, 브라우저에서 열 주소를 돌려줍니다."""
    filename = f"{uuid.uuid4().hex}{ext}"
    if settings.cover_bucket:
        _s3().put_object(Bucket=settings.cover_bucket, Key=COVER_KEY_PREFIX + filename,
                         Body=data, ContentType=CONTENT_TYPES[ext])
    else:
        COVER_DIR.mkdir(parents=True, exist_ok=True)
        (COVER_DIR / filename).write_bytes(data)
    return COVER_URL_PREFIX + filename


def remove_cover(cover_url: str | None) -> None:
    """저장해 둔 표지 파일을 지웁니다. 없으면 아무것도 하지 않습니다."""
    if not cover_url:
        return
    filename = Path(cover_url).name
    if settings.cover_bucket:
        _s3().delete_object(Bucket=settings.cover_bucket, Key=COVER_KEY_PREFIX + filename)
    else:
        (COVER_DIR / filename).unlink(missing_ok=True)


def cover_download_url(filename: str) -> str:
    """S3 객체를 잠깐 동안만 내려받을 수 있는 미리 서명된 URL을 만듭니다."""
    return _s3().generate_presigned_url(
        "get_object",
        Params={"Bucket": settings.cover_bucket, "Key": COVER_KEY_PREFIX + filename},
        ExpiresIn=DOWNLOAD_URL_EXPIRES,
    )
코드뜻
boto3.client("s3")S3 클라이언트를 만듭니다. 자격 증명을 적지 않았으므로 boto3가 환경 변수, 설정 파일, EC2 역할 순서로 찾아 씁니다. 서버에서는 역할을 씁니다.
put_object(..., ContentType=...)객체를 올립니다. Content-Type을 정해 두어야 브라우저가 이미지로 보여 줍니다.
delete_object이전 표지를 지웁니다. 지울 객체가 없어도 오류가 나지 않습니다.
generate_presigned_url("get_object", ...)서명이 붙은 URL을 만듭니다. AWS에 요청을 보내지 않고 내 자격 증명으로 계산만 하므로 빠릅니다.
COVER_NAME서버가 만든 이름 모양(32자리 16진수 + 확장자)입니다. 이 모양이 아닌 요청은 S3 키를 만들기 전에 404로 막습니다. 사용자 입력이 키에 섞여 다른 객체를 가리키는 것을 막는 허용 목록입니다.

표지 주소 경로

StaticFiles 마운트를 지우고, 두 저장 방식을 모두 처리하는 경로 하나로 바꿉니다. 응답 헤더 보안(nosniff)은 S9에서 만든 미들웨어가 그대로 붙입니다.

app/main.py(StaticFiles 마운트 자리)
# 표지 이미지 주소(/covers/파일이름). S3를 쓰면 미리 서명된 URL로 보내고, 아니면 uploads 폴더의 파일을 돌려줍니다.
@app.get("/covers/{filename}", include_in_schema=False)
def get_cover(filename: str):
    if not covers.COVER_NAME.fullmatch(filename):  # 서버가 만든 이름 모양이 아니면 찾지 않습니다.
        raise AppError(404, "COVER_NOT_FOUND", "표지 이미지를 찾을 수 없습니다.")
    if settings.cover_bucket:
        return RedirectResponse(covers.cover_download_url(filename), status_code=307)
    path = covers.COVER_DIR / filename
    if not path.is_file():
        raise AppError(404, "COVER_NOT_FOUND", "표지 이미지를 찾을 수 없습니다.")
    return FileResponse(path)

app/config.py의 설정에는 한 줄을 더합니다. 운영용 Compose에서 COVER_BUCKET 환경 변수로 넣습니다.

app/config.py(Settings 안)
    cover_bucket: str | None = None  # 값이 있으면 표지를 이 S3 버킷에 저장합니다(없으면 uploads 폴더).

IAM 역할에 더할 권한

EC2 역할이 이 버킷의 covers/ 아래에서만 올리고, 읽고, 지울 수 있게 합니다. 미리 서명된 URL은 "URL을 만든 쪽의 권한"으로 동작하므로 s3:GetObject도 필요합니다. 버킷 목록을 보는 권한(s3:ListBucket)은 주지 않습니다.

tests/test_covers_s3.py
"""표지를 S3에 저장하는 경우의 테스트: botocore Stubber로 S3 응답을 흉내 냅니다."""
import boto3
import pytest
from botocore.stub import ANY, Stubber

from app.config import settings
from app.services import covers
from tests.helpers import create_book

PNG = b"\x89PNG\r\n\x1a\n" + b"0" * 100
BUCKET = "book-api-covers-test"


@pytest.fixture
def s3(monkeypatch):
    client = boto3.client("s3", region_name="ap-northeast-2",
                          aws_access_key_id="test", aws_secret_access_key="test")
    monkeypatch.setattr(covers, "_s3", lambda: client)
    monkeypatch.setattr(settings, "cover_bucket", BUCKET)
    with Stubber(client) as stubber:
        yield stubber


def test_upload_saves_to_s3(client, auth_headers, author_id, s3):
    book = create_book(client, auth_headers, author_id)
    s3.add_response("put_object", {}, {"Bucket": BUCKET, "Key": ANY, "Body": PNG, "ContentType": "image/png"})

    response = client.post(f"/books/{book['id']}/cover", headers=auth_headers,
                           files={"file": ("cover.png", PNG, "image/png")})

    assert response.status_code == 200
    assert response.json()["cover_url"].startswith("/covers/")
    s3.assert_no_pending_responses()  # put_object가 정확히 한 번 불렸는지 확인합니다.


def test_cover_redirects_to_presigned_url(client, s3):
    name = "a" * 32 + ".png"
    response = client.get(f"/covers/{name}", follow_redirects=False)

    assert response.status_code == 307
    location = response.headers["location"]
    assert f"{BUCKET}" in location and f"covers/{name}" in location
    assert "X-Amz-Signature=" in location and "X-Amz-Expires=300" in location


@pytest.mark.parametrize("name", ["..%2Fsecret.txt", "evil.html", "A" * 32 + ".png"])
def test_cover_rejects_unexpected_names(client, s3, name):
    assert client.get(f"/covers/{name}", follow_redirects=False).status_code == 404

def test_uploaded_cover_can_be_downloaded(client, auth_headers, author_id, tmp_path, monkeypatch):
