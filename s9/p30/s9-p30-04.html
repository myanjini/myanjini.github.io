경로 조작과 자원 삽입

파일 이름을 받아 파일을 내주는 기능에서는 "그 파일"이 정말 내가 의도한 폴더 안의 파일인지 확인해야 합니다. 자료실 내려받기 API로 경로 조작을 재현하고 고칩니다.

실습 목표../를 이용한 경로 조작을 재현하고, 경로 정규화와 기준 폴더 검사로 막을 수 있습니다.

from fastapi import APIRouter

router = APIRouter(prefix="/files", tags=["자료실"])

FILES_DIR = Path("files")  # 이용 안내 같은 공개 자료를 두는 폴더

def download_file(name: str):

    path = FILES_DIR / name

  2. 경로 조작 재현

    name 값실제로 열리는 파일결과내 결과
    ../.envfiles/../.env, 즉 프로젝트의 .envSECRET_KEY가 그대로 보입니다.
    ../app/config.py앱의 소스 코드설정 코드가 보입니다.
    /etc/passwd(macOS), C:/Windows/win.ini(Windows)절대 경로는 앞의 files를 무시합니다.운영체제 파일이 보입니다.

    ..는 "한 단계 위 폴더"라는 뜻입니다. 비밀 키가 새면 공격자는 아무 사용자의 토큰이나 만들 수 있습니다(S5-P16). 이것이 경로 조작입니다. KISA 가이드는 사용자 입력으로 파일, 포트, 호스트 같은 자원을 고르게 하는 자원 삽입과 함께 묶어 다룹니다.

  3. 기준 폴더 검사로 고치기

    app/routers/files.py
    def safe_path(name: str) -> Path:
    """자료실 폴더 안의 파일만 가리키는지 확인한 실제 경로를 돌려줍니다."""
    path = (FILES_DIR / name).resolve()  # ..와 바로 가기를 모두 풀어 실제 경로로 바꿉니다.
    if not path.is_relative_to(FILES_DIR):
        raise AppError(400, "INVALID_FILE_NAME", "허용되지 않는 파일 이름입니다.")
    return path
    코드하는 일
    .resolve().., 바로 가기, 상대 경로를 모두 풀어 실제 절대 경로로 바꿉니다. 이것을 경로 정규화라고 합니다.
    is_relative_to(FILES_DIR)정규화한 경로가 자료 폴더 안에 있는지 확인합니다. 문자열 비교(startswith)는 files2 같은 이웃 폴더를 통과시키므로 쓰지 않습니다.

    입력 단계에서도 좁힙니다. 파일 이름에는 글자, 숫자, 점, 하이픈만 허용해 /와 \가 아예 들어오지 못하게 하고, 내려받기로 응답해 브라우저가 화면에 열지 않게 합니다.

    app/routers/files.py 전체 펼치기
    app/routers/files.py
    from pathlib import Path

from fastapi import APIRouter, Query
from fastapi.responses import FileResponse

from app.errors import AppError

router = APIRouter(prefix="/files", tags=["자료실"])

FILES_DIR = Path("files").resolve()  # 이용 안내 같은 공개 자료를 두는 폴더(절대 경로)


def safe_path(name: str) -> Path:
    """자료실 폴더 안의 파일만 가리키는지 확인한 실제 경로를 돌려줍니다."""
    path = (FILES_DIR / name).resolve()  # ..와 바로 가기를 모두 풀어 실제 경로로 바꿉니다.
    if not path.is_relative_to(FILES_DIR):
        raise AppError(400, "INVALID_FILE_NAME", "허용되지 않는 파일 이름입니다.")
    return path


@router.get("/download", summary="자료 내려받기")
def download_file(
    name: str = Query(max_length=100, pattern=r"^[\w.\-]+$", description="파일 이름(글자, 숫자, 점, 하이픈만)"),
):
    path = safe_path(name)
    if not path.is_file():
        raise AppError(404, "FILE_NOT_FOUND", "파일을 찾을 수 없습니다.")
    # filename을 주면 브라우저가 화면에 열지 않고 내려받기로 처리합니다.
    return FileResponse(path, filename=path.name)

  5. 회귀 테스트 추가

    tests/test_attacks.py 위쪽 가져오기에 from app.routers import files를 추가하고, 아래 테스트를 덧붙입니다. 두 번째 테스트는 monkeypatch로 자료 폴더를 임시 폴더로 바꿔, 실제 files 폴더에 기대지 않습니다.

    tests/test_attacks.py
    @pytest.mark.parametrize("name", ["../.env", "../app/config.py", "/etc/passwd", "..\\.env"])
def test_download_blocks_path_traversal(client, name):
    response = client.get("/files/download", params={"name": name})
    assert response.status_code in (400, 422)


def test_download_file(client, tmp_path, monkeypatch):
    (tmp_path / "guide.txt").write_text("이용 안내", encoding="utf-8")
    monkeypatch.setattr(files, "FILES_DIR", tmp_path.resolve())
    response = client.get("/files/download", params={"name": "guide.txt"})
    assert response.status_code == 200
    assert response.text == "이용 안내"
    assert "attachment" in response.headers["content-disposition"]
