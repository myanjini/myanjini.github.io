핵심 요약

주제핵심
절차탐지, 영향 확인, 복구, 원인 분석, 기록과 재발 방지. 복구가 원인 분석보다 먼저입니다.
롤백.env의 IMAGE를 직전 정상 태그로 바꾸고 up -d. 그다음 코드를 revert합니다.
로그로 원인 찾기Logs Insights에서 level = "ERROR"로 좁히고, 오류 필드의 마지막 원인을 읽습니다.
설정 복구Parameter Store의 이름:버전으로 이전 값을 읽어 새 버전으로 저장합니다.
데이터 복구RDS 시점 복원은 새 인스턴스를 만듭니다. 복원 가능 시각을 평소에 확인해 둡니다.

확인 퀴즈

배포 직후 서비스가 502를 돌려줍니다. 가장 먼저 할 일은 무엇인가요?

복구가 먼저이고, 원인 분석은 그다음입니다.

/health가 503이고 로그에 password authentication failed가 있습니다. 원인으로 가장 알맞은 것은 무엇인가요?

서버까지는 닿았지만 인증에서 실패한 것입니다. 네트워크 문제라면 시간 초과가 납니다.

RDS를 시점 복원하면 어떻게 되나요?

복원 후 앱의 DB 주소를 새 엔드포인트로 바꿔야 합니다.
