목록 조회 고도화

제목 검색, 가격 정렬, 페이지 정보를 갖춘 목록 조회 API를 만듭니다.

  3. 목록 조회 바꾸기

    기존 list_books를 지우고 아래 코드로 바꿉니다.

    app/routers/books.py
    # 정렬 기준으로 받을 수 있는 값과 실제 정렬 방법을 짝지어 둡니다.
SORT_OPTIONS = {
    "id": Book.id,
    "price": Book.price,
    "-price": Book.price.desc(),
}


@router.get("", response_model=BookPage, summary="도서 목록 조회")
def list_books(
    db: SessionDep,
    page: PageDep,
    q: str | None = Query(default=None, max_length=50, description="제목에 들어간 글자로 검색"),
    author: str | None = Query(default=None, description="저자 이름"),
    sort: Literal["id", "price", "-price"] = Query(default="id", description="정렬 기준"),
):
    conditions = []
    if q is not None:
        conditions.append(Book.title.contains(q))
    if author is not None:
        conditions.append(Book.author == author)

    total = db.scalar(select(func.count()).select_from(Book).where(*conditions))
    stmt = (
        select(Book)
        .where(*conditions)
        .order_by(SORT_OPTIONS[sort], Book.id)
        .offset(page.skip)
        .limit(page.limit)
    )
    items = db.scalars(stmt).all()
    return {"items": items, "total": total, "skip": page.skip, "limit": page.limit}

  4. 확인하기

    검색 결과가 잘 보이도록 도서를 한 권 더 등록합니다.

    {"title": "파이썬 데이터 분석", "author": "박서준", "price": 30000}
    요청기대하는 결과내 결과
    /books?q=파이썬제목에 파이썬이 들어간 도서, total 2
    /books?sort=-price&limit=2가장 비싼 두 권, total은 전체 개수
    /books?sort=title422, 허용된 값 안내
    /books?q=파이썬&author=박서준두 조건을 모두 만족하는 1권

    Swagger UI에서는 sort가 드롭다운으로 표시됩니다. Literal로 정한 값이 문서에도 그대로 반영된 것입니다.

/books?skip=0&limit=2의 응답에서 total이 5라면, 마지막 페이지를 보려면 skip을 얼마로 보내야 할까요? 어떻게 계산했는지도 적어 보세요.

예시 답안 보기

skip=4입니다. 한 페이지에 2권씩이면 1~2권, 3~4권, 5권으로 세 페이지가 됩니다. 마지막 페이지의 첫 도서는 다섯 번째이므로 앞의 4권을 건너뜁니다. 일반적으로 (전체 페이지 수 - 1) × limit이고, 전체 페이지 수는 total을 limit으로 나눠 올림한 값입니다.
