오늘 오후의 두 산출물은 "권한은 최소로"와 "연결은 꼭 필요한 것만"이라는 같은 원칙을 AWS에서 적용한 결과입니다. 5일차에 도서 API의 권한 검사와 입력 검증에서 지킨 원칙이 인프라에서도 그대로 이어집니다.

확인 퀴즈

서브넷을 퍼블릭 서브넷으로 만드는 것은 무엇인가요?

퍼블릭과 프라이빗은 라우팅으로 정해집니다.

RDS의 보안 그룹 인바운드 규칙으로 가장 알맞은 것은 무엇인가요?

API 서버의 보안 그룹을 출처로 두면 그 서버에서 오는 연결만 허용됩니다.

보안 그룹과 네트워크 ACL의 차이로 알맞은 것은 무엇인가요?

네트워크 ACL은 서브넷 단위, 상태 비저장이며 허용과 거부를 모두 씁니다.

7일차 예고

7일차에는 오늘 설계한 대로 실습 VPC와 보안 그룹을 만들고, 오늘 만든 IAM 역할을 붙인 EC2 서버를 띄워 Session Manager로 접속합니다. 서버에 Docker를 설치해 도서 API를 실행하고, RDS PostgreSQL에 연결한 뒤, 비밀 값을 Parameter Store로 옮기고 이미지를 ECR에 올려 AWS 배포를 완성합니다.
