부록 A. 설치 점검 체크리스트

번호확인 항목확인 명령 또는 방법
1Python 3.12 이상 설치python --version
2가상환경 생성과 활성화python -m venv .venv 후 활성화, 프롬프트에 (.venv) 표시
3FastAPI 설치pip install "fastapi[standard]" 후 fastapi --version
4Git 설치git --version
5GitHub 계정브라우저에서 로그인, 저장소 생성 가능 여부
6Docker 실행docker run hello-world
7Docker Composedocker compose version
8AWS CLIaws --version (계정 로그인은 6일차에 진행)
9예제 저장소 내려받기git clone 후 시작 브랜치 전환
10네트워크pip download 와 docker pull postgres 가 정상 동작
11Git Bash(Windows만)시작 메뉴에서 Git Bash를 열고 bash --version, aws --version 이 모두 출력되는지 확인(설정은 6일차 S12-P40-03)
