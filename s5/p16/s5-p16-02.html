OAuth2 Password Flow

로그인 요청을 어떤 모양으로 받고 토큰을 어떤 모양으로 돌려줄지는 이미 정해진 표준이 있습니다. FastAPI는 그 표준에 맞춘 도구 두 가지를 제공합니다.

OAuth2와 Password Flow

OAuth2는 토큰을 발급하고 사용하는 방법을 정한 표준입니다. 여러 방식(flow)이 있는데, 그중 Password Flow는 사용자가 아이디와 비밀번호를 우리 서버에 직접 보내고 토큰을 받는 가장 단순한 방식입니다. 우리 서비스의 화면이 우리 API에 로그인하는 경우처럼, 로그인 화면과 API를 같은 팀이 만들 때 씁니다.

FastAPI가 주는 두 도구

도구어디에 쓰나요하는 일
OAuth2PasswordRequestForm로그인 API (1번)요청 본문에서 username과 password를 꺼내 줍니다. 표준에 따라 JSON이 아니라 폼(form) 형식으로 받습니다.
OAuth2PasswordBearer보호된 API (3번)요청 헤더 Authorization: Bearer 토큰에서 토큰 부분만 꺼내 줍니다. 토큰을 받는 주소(tokenUrl)도 Swagger UI에 알려 줍니다.

폼 형식은 HTML 로그인 화면이 전송하는 형식으로, 본문이 username=user1%40example.com&password=practice-pass-1처럼 생겼습니다. 1일차에 설치한 fastapi[standard]에 폼을 읽는 모듈(python-multipart)이 들어 있습니다.

username 칸에 이메일을 넣습니다

표준은 입력 칸 이름을 username으로 정해 두었습니다. 이름을 바꾸면 Swagger UI와 다른 도구가 우리 로그인 API를 알아보지 못하므로, 칸 이름은 그대로 두고 그 안에 이메일을 넣습니다.
