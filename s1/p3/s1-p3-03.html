도서 조회 API 만들기

임시 도서 목록을 만들고, 전체 목록 조회와 도서 하나 조회 API를 작성합니다.

실습 목표경로 파라미터와 쿼리 파라미터를 써서 GET /books와 GET /books/{book_id}를 구현할 수 있습니다.

  1. 임시 도서 목록 만들기

    아직 데이터베이스가 없으므로 Python 리스트에 도서를 담아 둡니다. main.py의 윗부분을 다음처럼 바꿉니다. 기존의 read_root와 health_check 함수는 그대로 둡니다.

    main.py
    from fastapi import FastAPI, HTTPException

app = FastAPI(title="도서 관리 API")

# 데이터베이스 대신 쓰는 임시 도서 목록입니다. 2일차에 데이터베이스로 바꿉니다.
BOOKS = [
    {"id": 1, "title": "파이썬 첫걸음", "author": "김하늘", "price": 18000},
    {"id": 2, "title": "웹 개발 입문", "author": "이도윤", "price": 22000},
    {"id": 3, "title": "데이터베이스 기초", "author": "김하늘", "price": 25000},
    {"id": 4, "title": "알기 쉬운 네트워크", "author": "박서준", "price": 20000},
]

    HTTPException은 오류 응답을 보낼 때 쓰므로 함께 가져옵니다.

  2. 목록 조회 API 작성

    저자 이름으로 걸러 볼 수 있도록 쿼리 파라미터 author를 받습니다.

    main.py
    @app.get("/books")
def list_books(author: str | None = None):
    # author가 없으면 전체 목록을, 있으면 그 저자의 도서만 돌려줍니다.
    if author is None:
        return BOOKS
    return [book for book in BOOKS if book["author"] == author]

  3. 도서 하나 조회 API 작성

    main.py
    @app.get("/books/{book_id}")
def get_book(book_id: int):
    for book in BOOKS:
        if book["id"] == book_id:
            return book
    # 반복문을 다 돌아도 찾지 못하면 404 오류를 보냅니다.
    raise HTTPException(status_code=404, detail="도서를 찾을 수 없습니다.")

    raise HTTPException(...)을 만나면 함수가 그 자리에서 멈추고, 지정한 상태 코드와 메시지로 응답합니다. 오류 처리는 S2-P6에서 더 자세히 다룹니다.

  4. 요청 보내 확인하기

    서버가 자동으로 다시 시작되었는지 확인한 뒤, 아래 요청을 보내고 결과를 적어 봅니다.

    요청기대하는 결과내 결과
    /books도서 4권
    /books?author=김하늘도서 2권(1번, 3번)
    /books/2웹 개발 입문
    /books/99404, 도서를 찾을 수 없습니다.
    /books/abc422 오류

    브라우저 주소창에 한글을 넣어도 되고, Swagger UI에서 author 칸에 입력해도 됩니다.

더 해 보기

가격 상한을 정하는 쿼리 파라미터 max_price를 추가해, /books?max_price=20000으로 요청하면 20000원 이하인 도서만 돌려주도록 list_books를 고쳐 보세요. author와 함께 써도 동작해야 합니다.

예시 답안 보기
@app.get("/books")
def list_books(author: str | None = None, max_price: int | None = None):
    result = BOOKS
    if author is not None:
        result = [book for book in result if book["author"] == author]
    if max_price is not None:
        result = [book for book in result if book["price"] <= max_price]
    return result

조건마다 목록을 한 번씩 걸러 내면 조건이 늘어나도 코드가 복잡해지지 않습니다.
