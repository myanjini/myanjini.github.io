타입 힌트와 자동 검증

주소에 담긴 값을 함수에서 받는 두 가지 방법과, 타입 힌트만으로 값이 검사되는 과정을 강사 화면으로 함께 봅니다.

경로 파라미터

주소 안에 {이름}을 쓰고, 함수에 같은 이름의 매개변수를 만들면 그 자리의 값이 매개변수로 들어옵니다.

@app.get("/books/{book_id}")
def get_book(book_id: int):
    return {"book_id": book_id}

/books/3으로 요청하면 book_id에 정수 3이 들어옵니다. 주소는 원래 모두 문자열인데, 타입 힌트 int를 보고 FastAPI가 정수로 바꿔 준 것입니다.

정수가 아닌 값을 보내면

/books/abc로 요청하면 함수는 실행되지도 않고, FastAPI가 상태 코드 422와 함께 다음 응답을 돌려줍니다.

{
  "detail": [
    {
      "type": "int_parsing",
      "loc": ["path", "book_id"],
      "msg": "Input should be a valid integer, unable to parse string as an integer",
      "input": "abc"
    }
  ]
}
항목뜻
loc문제가 난 위치입니다. 경로(path)의 book_id입니다.
msg무엇이 문제인지 설명합니다. 정수로 바꿀 수 없다는 뜻입니다.
input실제로 들어온 값입니다.

검사 코드를 한 줄도 쓰지 않았는데 잘못된 입력이 걸러졌습니다. 타입 힌트가 곧 입력 검사 규칙이 된다는 점이 FastAPI의 가장 큰 장점입니다.

쿼리 파라미터

주소에 없는 이름의 매개변수는 쿼리 문자열(? 뒤)에서 값을 받습니다. 기본값을 주면 생략할 수 있는 값이 됩니다.

@app.get("/books")
def list_books(author: str | None = None, limit: int = 10):
    return {"author": author, "limit": limit}
요청authorlimit
/booksNone10
/books?author=김하늘"김하늘"10
/books?author=김하늘&limit=2"김하늘"2
/books?limit=many-422 오류

str | None = None은 "문자열이거나 값이 없을 수 있고, 기본값은 없음"이라는 뜻입니다. 여러 쿼리 값은 &로 이어서 보냅니다.

FastAPI가 구분하는 규칙

매개변수 이름이 주소의 { } 안에 있으면 경로 파라미터, 없으면 쿼리 파라미터입니다. 4교시에 배울 Pydantic 모델 타입이면 요청 본문에서 값을 받습니다.
