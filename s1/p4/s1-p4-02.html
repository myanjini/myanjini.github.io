요청 본문 받기

함수의 매개변수 타입을 Pydantic 모델로 적으면 요청 본문의 JSON이 검사를 거쳐 객체로 들어옵니다. 강사 화면으로 그 과정을 함께 봅니다.

요청 본문 받기

@app.post("/books")
def create_book(book_in: BookCreate):
    return book_in

매개변수 book_in의 타입이 Pydantic 모델이므로, FastAPI는 이 값을 경로나 쿼리가 아니라 요청 본문에서 찾습니다. 요청이 들어오면 다음 순서로 처리됩니다.

  1. 요청 본문의 JSON을 읽습니다.
  2. BookCreate의 규칙으로 검사합니다. 규칙을 어기면 여기서 422 응답을 보내고 끝냅니다.
  3. 검사를 통과하면 BookCreate 객체를 만들어 book_in에 넣고 함수를 실행합니다.

함수 안에서 값 쓰기

객체의 속성으로 값을 꺼냅니다. 딕셔너리가 필요하면 model_dump()로 바꿉니다.

book_in.title          # "FastAPI 실전"
book_in.price          # 27000
book_in.model_dump()   # {"title": "FastAPI 실전", "author": "최유나", "price": 27000, "isbn": None}

Swagger UI에서 보내기

/docs에서 POST /books를 펼치면 Request body 칸에 예시 JSON이 미리 채워져 있습니다. 모델에 적은 필드와 타입을 보고 FastAPI가 자동으로 만든 것입니다. Try it out을 누르고 값을 고쳐 Execute를 누르면 요청이 전송됩니다.

화면 아래쪽 Schemas에서는 BookCreate의 필드와 규칙(최소 길이, 최댓값 등)을 확인할 수 있습니다. 클라이언트를 만드는 개발자는 이 문서만 보고도 무엇을 보내야 하는지 알 수 있습니다.

브라우저 주소창으로는 안 되는 이유

주소창에 주소를 넣으면 항상 GET 요청이 갑니다. POST 요청과 요청 본문은 Swagger UI나 curl 같은 도구로 보내야 합니다.
