첫 앱 실행 과정 보기

강사 화면을 보며 가장 작은 FastAPI 앱이 실행되는 과정을 따라갑니다. 직접 입력은 다음 페이지에서 합니다.

가장 작은 FastAPI 앱

main.py
from fastapi import FastAPI

app = FastAPI()


@app.get("/")
def read_root():
    return {"message": "안녕하세요, FastAPI"}
코드하는 일
app = FastAPI()API 서버의 중심이 되는 앱 객체를 만듭니다. 모든 경로는 이 객체에 등록됩니다.
@app.get("/")GET 방식으로 / 주소에 요청이 오면 바로 아래 함수를 실행하라고 등록합니다.
return {...}딕셔너리를 돌려주면 FastAPI가 JSON으로 바꿔 응답합니다.

서버 실행

fastapi dev main.py

실행하면 다음과 비슷한 안내가 나옵니다. 출력 모양은 버전에 따라 조금씩 다르고, 줄 앞에 작은 기호가 붙어 보이기도 합니다.

Starting FastAPI in development mode
Using import string: main:app
Server started at http://127.0.0.1:8000
Documentation at http://127.0.0.1:8000/docs

INFO:     Will watch for changes in these directories: [...]
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Started reloader process [...] using WatchFiles
INFO:     Application startup complete.
출력뜻
Server started at http://127.0.0.1:8000내 PC의 8000번 포트에서 요청을 기다리고 있습니다. 127.0.0.1은 내 컴퓨터 자신을 가리키는 주소입니다.
Documentation at .../docs자동으로 만들어진 API 문서 주소입니다.
Will watch for changes파일이 바뀌는지 지켜보다가, 저장하면 서버를 자동으로 다시 시작합니다.
Application startup complete.앱이 요청을 받을 준비를 마쳤습니다.

브라우저로 확인

브라우저에서 http://127.0.0.1:8000을 열면 {"message":"안녕하세요, FastAPI"}가 보입니다. http://127.0.0.1:8000/docs를 열면 FastAPI가 자동으로 만든 API 문서가 나타납니다.

dev와 run

fastapi dev는 개발용 명령입니다. 코드를 저장할 때마다 자동으로 다시 시작해 편리하지만, 그만큼 자원을 더 씁니다. 실제 서비스에 올릴 때는 자동 재시작이 없는 fastapi run을 씁니다. 4일차 컨테이너 실습에서 다시 다룹니다.

서버 끄기

서버가 실행 중인 터미널에서 Ctrl + C를 누릅니다. 서버가 켜져 있는 동안 그 터미널은 다른 명령을 받지 않으므로, 다른 명령이 필요하면 터미널을 하나 더 열고 그 창에서도 가상환경을 켭니다.
