7일차 핵심 요약

시간만든 것핵심
오전VPC, 보안 그룹, EC2, RDSNAT 없는 퍼블릭과 프라이빗 구성, Session Manager, 프라이빗 RDS와 SSL
오후 1Parameter Store 비밀 값SecureString, 역할로 읽기, 서버 디스크에 비밀 값 없음, 교체 절차
오후 2ECR 저장소와 이미지태그 변경 불가, 스캔, 버전과 커밋 태그, 롤백
오후 3운영 배포운영용 Compose, production 설정, healthcheck, 로그 제한, 재부팅 확인

지금 도서 API는 이렇게 배포되어 있습니다. 내 PC → EC2(보안 그룹: 내 IP의 8000) → ECR에서 받은 book-api:1.0.0 컨테이너 → 시작할 때 역할로 Parameter Store에서 비밀 값을 읽음 → RDS(프라이빗, SSL).
