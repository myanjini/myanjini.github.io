Parameter Store 사용

Parameter Store에 값을 등록하는 방법과, 도서 API가 시작할 때 그 값을 읽어 오도록 바꾼 코드를 살펴봅니다.

파라미터 이름 짓기

파라미터 이름은 /로 나눈 경로처럼 짓습니다. 서비스 이름을 앞에 두면 IAM 정책에서 /book-api/*처럼 한 서비스의 값만 골라 권한을 줄 수 있습니다(S12-P41-02). 이번 실습의 파라미터는 두 개입니다.

이름유형값
/book-api/SECRET_KEYSecureStringJWT 서명 키(서버에서 새로 만든 32자 이상 값)
/book-api/DATABASE_URLSecureStringRDS 접속 주소. 마스터 암호가 들어 있으므로 통째로 비밀 값으로 다룹니다.

APP_ENV, LOG_LEVEL처럼 비밀이 아닌 설정은 운영용 Compose 파일에 그대로 적습니다(S14-P49). 비밀 값만 보관소에 두면 관리할 것이 줄어듭니다.

값 등록: 콘솔을 씁니다

CLI의 aws ssm put-parameter --value 비밀값으로도 등록할 수 있지만, 명령에 적은 값이 터미널의 명령 기록(history)에 남습니다. 그래서 비밀 값은 콘솔에서 입력합니다. Systems Manager 콘솔의 Parameter Store, 파라미터 생성에서 다음과 같이 입력합니다.

칸값
이름/book-api/SECRET_KEY
계층표준
유형SecureString
KMS 키 소스현재 계정, KMS 키 ID alias/aws/ssm(기본값)
값비밀 값
태그Owner = 내 식별자

앱이 시작할 때 읽기

도서 API의 설정은 S10부터 pydantic-settings가 환경 변수와 .env에서 읽습니다. 이 구조는 그대로 두고, 설정을 만들기 직전에 Parameter Store에서 값을 받아 환경 변수에 넣는 함수 하나를 더합니다. 내 PC와 테스트에서는 SSM_PREFIX 환경 변수가 없으므로 지금까지처럼 .env를 씁니다.

app/config.py(Settings 클래스 아래, settings = Settings() 바로 위)
# Parameter Store에서 읽을 비밀 값의 이름(앞에 SSM_PREFIX가 붙습니다. 예: /book-api/SECRET_KEY)
SSM_NAMES = ("SECRET_KEY", "DATABASE_URL")


def load_ssm_parameters() -> None:
    """SSM_PREFIX 환경 변수가 있으면 Parameter Store에서 비밀 값을 읽어 환경 변수에 넣습니다.

    내 PC와 테스트에서는 SSM_PREFIX가 없으므로 아무것도 하지 않고 .env를 그대로 씁니다.
    """
    prefix = os.environ.get("SSM_PREFIX")
    if not prefix:
        return
    import boto3  # AWS에서 실행할 때만 필요하므로 여기서 가져옵니다.

    names = [prefix + name for name in SSM_NAMES]
    response = boto3.client("ssm").get_parameters(Names=names, WithDecryption=True)
    if response.get("InvalidParameters"):  # 없는 이름이 있으면 시작하지 않습니다(값은 출력하지 않음).
        raise RuntimeError(f"Parameter Store에 없는 파라미터: {response['InvalidParameters']}")
    for parameter in response["Parameters"]:
        os.environ[parameter["Name"].removeprefix(prefix)] = parameter["Value"]


load_ssm_parameters()
부분뜻
SSM_PREFIX읽을 경로입니다. 운영용 Compose에서 /book-api/로 넣어 줍니다. 없으면 아무것도 하지 않습니다.
import boto3를 함수 안에boto3는 AWS SDK for Python입니다. AWS에서 실행할 때만 쓰므로 필요할 때 가져옵니다.
get_parameters(..., WithDecryption=True)여러 값을 한 번에 읽고, SecureString은 복호화한 값을 받습니다. 역할에 허용한 동작(ssm:GetParameters)입니다.
InvalidParameters없는 이름의 목록입니다. 하나라도 있으면 시작하지 않고 멈춥니다. 오류 메시지에는 이름만 넣고 값은 넣지 않습니다.
os.environ[...] = ...받은 값을 환경 변수로 넣습니다. 바로 다음 줄의 Settings()가 이 값을 읽고, S10의 비밀 키 검증도 그대로 거칩니다.

값을 시작할 때 한 번만 읽기 때문에, Parameter Store의 값을 바꾸면 컨테이너를 다시 시작해야 반영됩니다. 요청마다 읽지 않으니 느려지지 않고, Parameter Store가 잠시 응답하지 않아도 이미 실행 중인 앱은 영향을 받지 않습니다.

테스트

테스트에서 진짜 AWS를 부르면 안 됩니다. botocore에 들어 있는 Stubber로 "이런 요청이 오면 이렇게 답하라"를 정해 둔 가짜 클라이언트를 끼워 넣습니다. S11에서 requests.get을 가짜로 바꾼 것과 같은 생각입니다.

tests/test_ssm.py
"""Parameter Store 읽기 테스트: 실제 AWS에 요청하지 않고 botocore의 Stubber로 응답을 흉내 냅니다."""
import boto3
import pytest
from botocore.stub import Stubber

from app import config


@pytest.fixture
def ssm_stub(monkeypatch):
    client = boto3.client("ssm", region_name="ap-northeast-2",
                          aws_access_key_id="test", aws_secret_access_key="test")
    monkeypatch.setattr(boto3, "client", lambda service, **kw: client)  # 앱이 만드는 클라이언트를 바꿔 끼웁니다.
    monkeypatch.setenv("SSM_PREFIX", "/book-api/")
    monkeypatch.delenv("SECRET_KEY", raising=False)    # 테스트가 끝나면 원래 값으로 돌아옵니다.
    monkeypatch.delenv("DATABASE_URL", raising=False)
    with Stubber(client) as stubber:
        yield stubber


def test_loads_parameters_into_environment(ssm_stub):
    ssm_stub.add_response(
        "get_parameters",
        {"Parameters": [{"Name": "/book-api/SECRET_KEY", "Value": "k" * 40, "Type": "SecureString"},
                        {"Name": "/book-api/DATABASE_URL", "Value": "sqlite:///./x.db", "Type": "SecureString"}]},
        {"Names": ["/book-api/SECRET_KEY", "/book-api/DATABASE_URL"], "WithDecryption": True},
    )
    config.load_ssm_parameters()
    assert config.os.environ["SECRET_KEY"] == "k" * 40
    assert config.os.environ["DATABASE_URL"] == "sqlite:///./x.db"


def test_missing_parameter_stops_startup(ssm_stub):
    ssm_stub.add_response(
        "get_parameters",
        {"Parameters": [], "InvalidParameters": ["/book-api/SECRET_KEY", "/book-api/DATABASE_URL"]},
    )
    with pytest.raises(RuntimeError, match="없는 파라미터"):
        config.load_ssm_parameters()


def test_without_prefix_does_nothing(monkeypatch):
    monkeypatch.delenv("SSM_PREFIX", raising=False)
    monkeypatch.setattr(boto3, "client", lambda *a, **kw: pytest.fail("AWS를 부르면 안 됩니다."))
    config.load_ssm_parameters()
