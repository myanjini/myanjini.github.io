삭제와 업로드 확인

  1. 내가 등록한 도서를 삭제하면 확인 창이 뜨고, 확인을 누르면 목록으로 이동합니다. 브라우저 뒤로 가기를 눌러도 삭제한 도서의 상세 화면으로 돌아가지 않는지 확인합니다.
  2. 3MB 이미지나 .gif 파일을 표지로 고르면 요청 없이 안내 문구가 나옵니다.
  3. 2MB 이하 PNG를 표지로 올리면 상세 화면에 새 표지가 바로 나타납니다.
  4. 표지 업로드 요청을 Network 탭에서 열어 Request Headers의 Content-Type에 boundary=가 포함되어 있는지, Payload에 file 필드가 있는지 확인합니다.
  5. 확장자를 .png로 바꾼 텍스트 파일을 올려 봅니다. 프론트엔드 검사는 통과하지만 백엔드가 거절하는지(백엔드 S9-P31의 파일 형식 검사) 확인합니다.
