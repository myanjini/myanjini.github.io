정리: 삭제와 표지 업로드

핵심 요약

  • 되돌릴 수 없는 동작은 한 번 더 확인하고, 삭제 후에는 replace로 이동해 없는 화면이 방문 기록에 남지 않게 합니다.
  • 파일 업로드는 FormData로 보내고, 크기와 확장자는 미리 검사하되 최종 판단은 백엔드에 맡깁니다.
  • 처리 중에는 버튼을 막아 같은 요청이 두 번 전송되지 않게 합니다.

확인 퀴즈

삭제 후 navigate('/', { replace: true })를 쓰는 이유는 무엇인가요?

replace는 현재 기록을 새 주소로 바꿔 끼웁니다.

표지 파일을 브라우저에서 미리 검사해도 백엔드 검사가 필요한 이유는 무엇인가요?

실제 내용 검사는 서버가 해야 합니다.
