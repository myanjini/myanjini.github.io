S9. 프론트엔드 개발 보안

섹션 목표프론트엔드에서 지켜야 할 개발 보안 요소를 이해하고 점검합니다.

  • 프론트엔드 보안의 전제(브라우저 코드는 공개되고 조작될 수 있다)를 이해하고 백엔드 보안과의 역할을 구분합니다.
  • XSS의 원리와 React에서 위험해지는 지점을 알고 방어합니다.
  • 토큰 저장 위치별 위험을 비교하고 이 과정의 선택 근거를 설명합니다.
  • CSRF, 클릭재킹, 열린 리디렉션, 정보 노출, 공급망 위험에 대한 대책을 적용합니다.
  • 보안 헤더와 CSP의 의미를 이해하고, 백엔드 과정의 보안약점 분류와 연결해 점검합니다.

S9-P19 XSS와 토큰 보호

XSS, 토큰 저장 위치, CSRF와 클릭재킹의 위험과 대책을 설명할 수 있습니다.

  1. 프론트엔드 보안의 전제 주요 개념, 5분
  2. XSS(크로스 사이트 스크립팅) 주요 개념, 10분
  3. 토큰 저장 위치 주요 개념, 10분
  4. CSRF와 클릭재킹 주요 개념, 5분

S9-P20 보안 헤더와 정보 보호

보안 헤더, CSP, 비밀정보 관리, 열린 리디렉션 대책을 적용할 수 있습니다.

  1. 보안 헤더와 CSP 주요 개념, 15분
  2. 비밀정보와 빌드 결과물 주요 개념, 5분
  3. 오류 처리와 정보 노출 주요 개념, 5분
  4. 열린 리디렉션 주요 개념, 5분

S9-P21 공급망 보안과 점검

의존성을 점검하고 보안 점검표로 코드를 확인할 수 있습니다.

  1. 의존성과 공급망 보안 주요 개념, 5분
  2. 요청 제한과 중복 요청 주요 개념, 5분
  3. 보안 점검표 주요 개념, 10분
  4. 보안 점검하기 실습, 10분
