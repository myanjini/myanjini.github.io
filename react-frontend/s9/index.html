S9. 쓰기 기능

섹션 목표도서 등록과 수정, 삭제, 표지 업로드, 대여와 반납을 구현하고 백엔드의 업무 규칙 오류를 사용자에게 안내합니다.

5일차 오전, 4시간, 파트마다 50분 학습과 10분 휴식

S9-P29 등록과 수정 폼

입력값을 백엔드 규칙으로 검증하고 API 본문으로 변환해 도서를 등록하고, 바뀐 필드만 보내 수정할 수 있습니다.

  1. 쓰기 화면의 공통 원칙 주요 개념, 10분
  2. 도서 등록과 수정 폼 실습, 35분
  3. 정리: 등록과 수정 폼 정리, 5분

S9-P30 삭제와 표지 업로드

되돌릴 수 없는 삭제를 안전하게 처리하고, 표지 파일을 미리 검사해 멀티파트로 업로드할 수 있습니다.

  1. 상세 화면에 삭제와 표지 업로드 추가 실습, 30분
  2. 삭제와 업로드 확인 실습, 15분
  3. 정리: 삭제와 표지 업로드 정리, 5분

S9-P31 대여, 반납과 시간대 처리

대여와 반납을 구현해 업무 규칙 오류를 안내하고, 백엔드가 보낸 UTC 시각을 사용자의 시간대로 표시할 수 있습니다.

  1. 대여와 반납 API 실습, 10분
  2. 상세 화면에 대여 버튼 추가 실습, 15분
  3. 내 대여 화면 실습, 20분
  4. 정리: 대여, 반납과 시간대 처리 정리, 5분

S9-P32 5일차 통합 실습

역할에 따라 다른 기능을 제공하는 폼을 직접 구현하고, 쓰기 기능 전체를 시나리오로 점검할 수 있습니다.

  1. 관리자 저자 추가 기능 실습, 25분
  2. 쓰기 기능 종합 점검 실습, 20분
  3. 정리: 5일차 통합 실습 정리, 5분
