S16. GitHub Actions와 S3 배포

섹션 목표GitHub Actions로 테스트를 자동화하고, S3 정적 웹 호스팅에 OIDC 인증으로 자동 배포하는 파이프라인을 만듭니다.

8일차 오후, 3시간, 파트마다 50분 학습과 10분 휴식

S16-P54 CI: 테스트 자동화

GitHub Actions의 구성 요소를 설명하고, 풀 리퀘스트마다 린트, 테스트, 빌드, E2E를 실행하는 CI를 만들 수 있습니다.

  1. CI/CD와 GitHub Actions 주요 개념, 15분
  2. CI 워크플로 작성과 실행 실습, 30분
  3. 정리: CI: 테스트 자동화 정리, 5분

S16-P55 S3 정적 웹 호스팅

S3 정적 웹 호스팅으로 프론트엔드를 배포하고, 다른 출처가 되는 API와의 CORS 설정을 맞출 수 있으며, CloudFront를 쓰는 이유를 설명할 수 있습니다.

  1. S3 정적 웹 호스팅 주요 개념, 10분
  2. CloudFront를 쓰는 이유 주요 개념, 10분
  3. S3 버킷 만들고 수동 배포하기 실습, 25분
  4. 정리: S3 정적 웹 호스팅 정리, 5분

S16-P56 CD: OIDC, 자동 배포, 롤백

장기 액세스 키 없이 OIDC로 AWS에 인증해 main에 병합될 때 자동으로 S3에 배포하고, 이전 버전으로 롤백할 수 있습니다.

  1. OIDC로 AWS에 인증하기 주요 개념, 10분
  2. 배포 역할 준비와 배포 워크플로 실습, 30분
  3. 롤백 실습, 5분
  4. 정리: CD: OIDC, 자동 배포, 롤백 정리, 5분
