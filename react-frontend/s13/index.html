S13. 관제 대시보드

섹션 목표관제 환경에 맞는 대시보드를 설계하고, 폴링과 요청 기록, 지표 계산을 거쳐 Recharts로 상태와 추세를 시각화합니다.

7일차 오전, 4시간, 파트마다 50분 학습과 10분 휴식

S13-P43 설계 원칙과 지표

관제 대시보드가 해야 할 일과 설계 원칙을 설명하고, 지표와 데이터 소스를 고를 수 있습니다.

  1. 관제 대시보드란 주요 개념, 15분
  2. 설계 원칙 주요 개념, 20분
  3. 무엇을 볼 것인가: 지표와 데이터 소스 주요 개념, 10분
  4. 정리: 설계 원칙과 지표 정리, 5분

S13-P44 차트 형태와 시각화 도구

데이터가 하는 일에 맞는 차트 형태를 고르고, 시각화 도구를 비교해 선택할 수 있습니다.

  1. 차트 형태 고르기 주요 개념, 10분
  2. 시각화 도구 비교 주요 개념, 15분
  3. 대시보드 화면 설계하기 실습, 20분
  4. 정리: 차트 형태와 시각화 도구 정리, 5분

S13-P45 폴링, 요청 기록, 지표 계산

폴링을 올바르게 구현하는 규칙을 설명하고, 브라우저 요청 기록과 지표 계산 함수를 만들어 테스트할 수 있습니다.

  1. 실시간 갱신 방식 주요 개념, 10분
  2. 브라우저 요청 기록 실습, 20분
  3. 지표 계산 함수와 테스트 실습, 15분
  4. 정리: 폴링, 요청 기록, 지표 계산 정리, 5분

S13-P46 상태 패널과 차트

Recharts로 상태 패널과 차트를 만들고, 폴링으로 갱신되는 관제 대시보드 화면을 조립할 수 있습니다.

  1. Recharts 설치와 공통 표시 컴포넌트 실습, 15분
  2. 헬스 체크 패널과 상태 코드 분포 실습, 15분
  3. 대시보드 화면 조립 실습, 15분
  4. 정리: 상태 패널과 차트 정리, 5분
