핵심 요약

  • API 함수, 쿼리 연결, 화면 상태, 라우트 순서로 바깥에서 안쪽으로 구현합니다.

확인 퀴즈

API 함수에 signal을 넘기는 이유는 무엇인가요?

TanStack Query는 쿼리가 더 필요 없어지면 signal로 요청을 취소합니다.

조회 화면에서 구분해 보여 줘야 할 네 가지 상태가 아닌 것은 무엇인가요?

로딩, 오류, 빈 결과, 정상 결과를 구분합니다.
