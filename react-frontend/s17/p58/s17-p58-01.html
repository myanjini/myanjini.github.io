구현 순서

파트 목표설계에 따라 API 함수와 조회 화면을 구현하고, 로딩, 오류, 빈 결과를 구분해 보여 줄 수 있습니다.

구현은 바깥(API)에서 안쪽(화면)으로 진행합니다. 각 단계가 끝날 때마다 브라우저나 테스트로 확인하고 커밋합니다.

  1. API 함수: src/api/에 함수를 추가합니다. 요청 형식(쿼리, 본문, 폼)만 책임지고, 화면 로직은 넣지 않습니다(S6).
  2. 쿼리 연결: 화면에서 useQuery로 API 함수를 부릅니다. 쿼리 키는 기존 규칙(['도메인', '종류', 조건])을 따릅니다(S10).
  3. 화면 상태: 로딩, 오류(ErrorMessage), 빈 결과, 정상 결과를 차례로 만듭니다(S7).
  4. 라우트와 메뉴: App.jsx에 라우트를 추가하고, 필요하면 Layout에 메뉴를 추가합니다.
