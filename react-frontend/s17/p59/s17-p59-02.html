정리: 구현 2: 인증과 쓰기

핵심 요약

  • 화면의 권한 처리는 사용자 경험을 위한 것이며 실제 권한 검사는 백엔드가 합니다.
  • 쓰기는 useMutation으로 처리하고, 성공하면 관련 쿼리를 무효화하며, 처리 중에는 버튼을 비활성화합니다.
  • 되돌릴 수 없는 동작에는 확인 단계를 두고, 오류 코드별로 안내합니다.

확인 퀴즈

관리자 메뉴를 일반 사용자에게 숨겼다면 보안 대책으로 충분한가요?

프론트엔드 코드는 사용자가 조작할 수 있으므로 권한의 최종 판단은 백엔드가 합니다.

처리 중 버튼 비활성화에 쓰는 useMutation의 값은 무엇인가요?

isPending은 요청이 진행 중일 때 true입니다.
