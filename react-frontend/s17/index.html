S17. 미니 프로젝트 설계와 구현

섹션 목표지금까지 만든 도서 관리 화면에 새 기능을 하나 골라 설계하고, API 계층부터 화면, 테스트까지 스스로 구현합니다.

9일차 오전, 4시간, 파트마다 50분 학습과 10분 휴식

S17-P57 주제 선정과 화면 설계

미니 프로젝트의 주제를 고르고, 사용할 API, 화면, 상태, 권한을 설계 문서로 정리할 수 있습니다.

  1. 미니 프로젝트 안내 주요 개념, 10분
  2. 주제 고르고 설계 문서 쓰기 실습, 35분
  3. 정리: 주제 선정과 화면 설계 정리, 5분

S17-P58 구현 1: API 계층과 조회

설계에 따라 API 함수와 조회 화면을 구현하고, 로딩, 오류, 빈 결과를 구분해 보여 줄 수 있습니다.

  1. 구현 순서 주요 개념, 5분
  2. API 함수와 조회 화면 구현 실습, 40분
  3. 정리: 구현 1: API 계층과 조회 정리, 5분

S17-P59 구현 2: 인증과 쓰기

권한에 따라 화면을 나누고, 쓰기 기능을 useMutation으로 구현해 오류와 캐시 갱신을 처리할 수 있습니다.

  1. 권한과 쓰기 기능 구현 실습, 45분
  2. 정리: 구현 2: 인증과 쓰기 정리, 5분

S17-P60 구현 3: 테스트

미니 프로젝트 기능에 단위, 컴포넌트, E2E 테스트를 작성하고 CI에서 통과시킬 수 있습니다.

  1. 기능 테스트 작성 실습, 45분
  2. 정리: 구현 3: 테스트 정리, 5분
