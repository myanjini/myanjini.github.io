확인 퀴즈

미니 프로젝트의 MSW 가짜 응답에 409 오류 경우를 함께 만드는 이유는 무엇인가요?

정상 흐름뿐 아니라 사용자가 만날 오류 상황도 테스트로 지킵니다.

관리자 전용 화면을 컴포넌트 테스트할 때 로그인 상태를 만드는 방법으로 알맞은 것은 무엇인가요?

Context 값을 직접 넣으면 화면 하나만 떼어 원하는 상태로 테스트할 수 있습니다.
