기능 테스트 작성

파트 목표미니 프로젝트 기능에 단위, 컴포넌트, E2E 테스트를 작성하고 CI에서 통과시킬 수 있습니다.

설계 문서의 테스트 계획에 따라 테스트를 작성합니다. 다음을 최소 기준으로 합니다.

종류 최소 개수 예 (주제 2)
단위 1 저자 이름 검증 함수
컴포넌트(MSW) 2 목록 표시, 409 안내
E2E 1 관리자 로그인 후 저자 등록
  1. MSW 가짜 서버(src/test/server.js)에 새 API의 응답을 추가합니다. 응답 형식은 설계 문서의 API 표와 같게 만듭니다.
http.post(`${API}/authors`, async ({ request }) => {
  const { name } = await request.json();
  if (name === '한강') {
    return HttpResponse.json(
      { detail: { code: 'DUPLICATE_AUTHOR', message: 'Author already exists' } },
      { status: 409 },
    );
  }
  return HttpResponse.json({ id: 99, name }, { status: 201 });
}),
  1. 컴포넌트 테스트는 renderWithProviders로 화면을 그리고, 사용자가 하는 순서대로 조작합니다. 관리자 화면은 AuthContext.Provider로 관리자 사용자를 넣어 그립니다(S11-P37-02).
  2. E2E는 e2e/mockApi.js에 새 경로를 추가하고, 핵심 흐름 하나만 테스트합니다.
  3. 모두 통과하면 다음 명령을 한 번에 실행해 CI와 같은 검사를 로컬에서 통과하는지 확인합니다.
npm run lint && npm run test:run && npm run build && npm run test:e2e
  1. 기능 브랜치를 push하고 풀 리퀘스트를 열어 CI가 통과하는지 확인합니다. 아직 병합하지 않습니다.
