조건부 렌더링과 리스트

파트 목표상황에 따라 다른 화면을 보여 주고, key를 지켜 리스트를 그릴 수 있습니다.

화면은 상황에 따라 다른 내용을 보여 줘야 합니다. 데이터를 불러오는 화면이라면 최소한 "불러오는 중", "오류", "결과 없음", "결과 있음" 네 가지 상태를 모두 고려합니다.

{loading && <p>불러오는 중입니다.</p>}
{error && <p className="error">{error.message}</p>}
{!loading && books.length === 0 && <p>도서가 없습니다.</p>}

배열은 map으로 요소 배열을 만들어 그립니다. 이때 각 요소에는 형제 사이에서 고유한 key를 줘야 합니다. React는 key로 어떤 행이 추가, 삭제, 이동했는지 구분합니다. 데이터베이스 id처럼 변하지 않는 값을 쓰고, 배열의 순번(index)은 정렬이나 삭제가 있는 목록에서는 쓰지 않습니다.

<tbody>
  {books.map((book) => (
    <BookRow key={book.id} book={book} />
  ))}
</tbody>

&&를 쓸 때 왼쪽 값이 숫자 0이면 화면에 0이 그대로 찍힙니다. {books.length && <List />} 대신 {books.length > 0 && <List />}처럼 불리언으로 만들어 씁니다.
