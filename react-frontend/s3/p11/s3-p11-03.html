정리: 조건부 렌더링과 리스트

핵심 요약

  • 데이터를 보여 주는 화면은 로딩, 오류, 빈 결과, 정상 결과를 모두 고려합니다.
  • 리스트에는 형제 사이에서 고유하고 변하지 않는 key를 줍니다. 정렬이나 삭제가 있는 목록에 순번을 쓰지 않습니다.
  • {count && ...}는 0이 그대로 찍히므로 {count > 0 && ...}처럼 불리언으로 씁니다.

확인 퀴즈

리스트의 key로 가장 알맞은 것은 무엇인가요?

key는 항목을 구분하는 고유하고 안정적인 값이어야 합니다. 제목은 겹칠 수 있습니다.

{books.length && <BookTable />}에서 books가 빈 배열이면 화면에 무엇이 나오나요?

0은 거짓이지만 React는 숫자 0을 그대로 그립니다.
