S3. React 기초

섹션 목표Vite로 React 프로젝트를 만들고 JSX, 컴포넌트, props, state, 이벤트, 리스트 렌더링으로 화면을 구성합니다.

2일차 오전, 4시간, 파트마다 50분 학습과 10분 휴식

S3-P8 Vite 프로젝트와 실행 흐름

Vite로 React 프로젝트를 만들어 실행하고, 화면이 그려지기까지의 흐름을 설명할 수 있습니다.

  1. Vite란 주요 개념, 10분
  2. 프로젝트 만들기와 Git 저장소 시작 실습, 20분
  3. 프로젝트 구조와 실행 흐름 주요 개념, 15분
  4. 정리: Vite 프로젝트와 실행 흐름 정리, 5분

S3-P9 JSX, 컴포넌트, props

JSX 규칙에 맞게 화면을 작성하고, props를 받는 컴포넌트로 화면을 나눌 수 있습니다.

  1. JSX 주요 개념, 15분
  2. 컴포넌트와 props 주요 개념, 10분
  3. 샘플 데이터로 도서 표 만들기 실습, 20분
  4. 정리: JSX, 컴포넌트, props 정리, 5분

S3-P10 state와 이벤트

useState로 화면 상태를 만들고, 이벤트로 상태를 바꿔 화면을 다시 그릴 수 있습니다.

  1. state와 이벤트 주요 개념, 20분
  2. 제목 검색 기능 만들기 실습, 25분
  3. 정리: state와 이벤트 정리, 5분

S3-P11 조건부 렌더링과 리스트

상황에 따라 다른 화면을 보여 주고, key를 지켜 리스트를 그릴 수 있습니다.

  1. 조건부 렌더링과 리스트 주요 개념, 15분
  2. 정렬과 빈 결과 처리 실습, 30분
  3. 정리: 조건부 렌더링과 리스트 정리, 5분
