정리: Vite와 React 기초

핵심 요약

  • Vite는 개발 서버와 운영 빌드 두 역할을 하며, React 앱의 시작점은 index.html과 main.jsx입니다.
  • 컴포넌트는 props를 받아 화면을 반환하는 함수이고, state가 바뀌면 다시 그려집니다.
  • state는 직접 고치지 않고 새 값으로 교체하며, 리스트에는 변하지 않는 key를 줍니다.
  • 네트워크 요청과 타이머는 useEffect에서 하고, 정리 함수로 뒷정리를 합니다.

확인 퀴즈

React의 state를 올바르게 바꾸는 방법은 무엇인가요?

state는 직접 고치지 않고, 전개 문법으로 만든 새 객체를 설정 함수에 넘깁니다.

개발 모드에서 같은 요청이 두 번 보이는 가장 흔한 이유는 무엇인가요?
