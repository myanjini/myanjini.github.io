프로젝트 만들기와 Git 저장소 시작

workspace 폴더에서 다음 명령을 실행합니다. --template react는 TypeScript가 아닌 JavaScript 기반 React 템플릿을 뜻합니다.

cd workspace
npm create vite@latest react-frontend -- --template react
cd react-frontend
npm install
npm run dev

터미널에 Local: http://localhost:5173/이 나오면 브라우저로 접속합니다. Vite와 React 로고가 있는 기본 화면이 보이면 성공입니다. 개발 서버는 Ctrl + C로 종료합니다.

참고

주소 표기에 주의합니다. 이 과정에서는 프론트엔드를 항상 http://localhost:5173으로 엽니다. 백엔드는 http://127.0.0.1:8000으로 부릅니다. 두 주소의 차이가 S5의 핵심 주제와 연결됩니다.

이제 이 폴더를 Git 저장소로 만들고 첫 커밋을 남깁니다. Vite 템플릿에는 node_modules와 dist를 제외하는 .gitignore가 이미 들어 있습니다.

git init -b main
git add .
git commit -m "Vite React 템플릿 생성"

앞으로 파트를 하나 마칠 때마다 커밋합니다. 커밋 메시지에 파트 번호를 넣어 두면(P9: 샘플 데이터와 컴포넌트) 나중에 예제 저장소의 브랜치와 비교하기 쉽습니다.
