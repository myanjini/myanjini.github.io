정리: Vite 프로젝트와 실행 흐름

핵심 요약

  • Vite는 개발 서버(npm run dev)와 운영 빌드(npm run build) 두 역할을 합니다.
  • 브라우저는 index.html을 받고, main.jsx가 React를 #root에 연결한 뒤 App을 그립니다.
  • 파트를 마칠 때마다 커밋해 두면 예제 저장소의 pN-done 브랜치와 비교하기 쉽습니다.

확인 퀴즈

React 앱이 화면에 처음 연결되는 곳은 어디인가요?

main.jsx가 index.html의 #root 요소에 React를 연결하고 App을 그립니다.

개발 서버에서 파일을 저장하면 새로고침 없이 바뀐 부분만 반영되는 기능은 무엇인가요?

HMR(Hot Module Replacement)은 바뀐 모듈만 교체해 화면에 바로 반영합니다.
