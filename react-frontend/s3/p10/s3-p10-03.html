정리: state와 이벤트

핵심 요약

  • state가 바뀌면 React가 컴포넌트를 다시 호출해 화면을 새로 그립니다.
  • state는 직접 고치지 않고 새 값으로 교체하며, 다른 값에서 계산할 수 있는 값은 state로 두지 않습니다.
  • 여러 컴포넌트가 함께 쓰는 값은 공통 부모로 끌어올리고, 값과 변경 함수를 props로 내립니다.

확인 퀴즈

onClick={handleClick()}의 문제점은 무엇인가요?

함수 자체(handleClick)를 넘겨야 합니다. 괄호를 붙이면 호출 결과가 넘어갑니다.

검색어로 거른 목록(visible)을 state로 따로 두지 않는 이유는 무엇인가요?

계산할 수 있는 값을 state로 중복해 두면 동기화 버그가 생기기 쉽습니다.
