정리: JSX, 컴포넌트, props

핵심 요약

  • JSX의 중괄호에는 값이 되는 식만 넣고, className, 닫는 태그, 하나의 최상위 요소 규칙을 지킵니다.
  • 컴포넌트는 props를 받아 화면을 반환하는 함수이며, 자식은 props를 읽기만 합니다.
  • 화면을 먼저 샘플 데이터로 만들면 API 연결 전에 화면 구성을 따로 연습할 수 있습니다.

확인 퀴즈

JSX에서 CSS 클래스를 지정하는 속성은 무엇인가요?

JSX는 JavaScript 예약어인 class 대신 className을 씁니다.

props에 대한 설명으로 옳은 것은 무엇인가요?

props는 부모에서 자식으로 흐르는 읽기 전용 값입니다.
