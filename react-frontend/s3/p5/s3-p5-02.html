프로젝트 만들기

workspace 폴더에서 다음 명령을 실행합니다. --template react는 TypeScript가 아닌 JavaScript 기반 React 템플릿을 뜻합니다.

cd workspace
npm create vite@latest book-admin-web -- --template react
cd book-admin-web
npm install
npm run dev

터미널에 Local: http://localhost:5173/이 나오면 브라우저로 접속합니다. Vite와 React 로고가 있는 기본 화면이 보이면 성공입니다. 개발 서버는 Ctrl + C로 종료합니다.

참고

주소 표기에 주의합니다. 이 과정에서는 프론트엔드를 항상 http://localhost:5173으로 엽니다. 백엔드는 http://127.0.0.1:8000으로 부릅니다. 두 주소의 차이가 S4의 핵심 주제와 연결됩니다.
