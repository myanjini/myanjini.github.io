프로젝트 구조와 실행 흐름

생성된 프로젝트의 주요 파일은 다음과 같습니다.

book-admin-web/
├── index.html        # 브라우저가 처음 받는 HTML. <div id="root">가 있습니다.
├── package.json      # 의존성 목록과 실행 스크립트(dev, build, lint, preview)
├── vite.config.js    # Vite 설정. React 플러그인이 등록되어 있습니다.
├── public/           # 가공 없이 그대로 제공할 파일
└── src/
    ├── main.jsx      # 시작점. React를 #root에 연결합니다.
    ├── App.jsx       # 첫 화면 컴포넌트
    └── index.css     # 전역 스타일

화면이 그려지는 순서는 다음과 같습니다.

  1. 브라우저가 index.html을 받습니다. 이 파일에는 빈 <div id="root"></div>와 <script type="module" src="/src/main.jsx">가 있습니다.
  2. main.jsx가 실행되어 createRoot(document.getElementById('root')).render(<App />)로 React를 #root에 연결합니다.
  3. React가 App 컴포넌트를 호출해 반환된 화면을 DOM으로 만듭니다.

main.jsx에 있는 <StrictMode>는 개발 중에만 동작하는 점검 장치입니다. 잠재적인 실수를 찾기 위해 일부 함수를 일부러 두 번 실행합니다. S3-P7-01에서 다시 다룹니다.

실습을 시작하기 전에 템플릿의 예제 파일을 정리합니다. src/assets 폴더와 src/App.css를 지우고, src/App.jsx와 src/index.css의 내용을 모두 지운 상태에서 시작합니다. index.html에서는 문서 언어와 제목을 이 앱에 맞게 바꿉니다. lang 속성은 화면 낭독기와 번역 기능이 문서의 언어를 올바르게 판단하는 데 쓰입니다.

<html lang="ko">
  <head>
    <!-- 나머지는 그대로 둡니다 -->
    <title>도서 관리</title>
  </head>
