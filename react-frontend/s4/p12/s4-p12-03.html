정리: 폼과 제어 컴포넌트

핵심 요약

  • 제어 컴포넌트는 입력 칸의 값을 state와 연결해 React가 항상 값을 쥐고 있게 합니다.
  • 입력값은 항상 문자열이므로 API로 보낼 값은 숫자나 null로 변환합니다.
  • 폼은 결과를 콜백으로 부모에게 알리고, 상태를 가진 쪽에서만 상태를 바꿉니다.

확인 퀴즈

<input type="number">에서 event.target.value의 자료형은 무엇인가요?

입력 칸의 값은 type과 관계없이 항상 문자열입니다.

폼 제출 시 페이지가 새로고침되는 것을 막는 코드는 무엇인가요?

preventDefault는 브라우저의 기본 동작(폼 제출로 인한 페이지 이동)을 막습니다.
