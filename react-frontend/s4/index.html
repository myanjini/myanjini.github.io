S4. 백엔드 연결 준비: Origin, SOP, CORS

섹션 목표백엔드와 처음 연결하며 Origin, 동일 출처 정책, CORS를 이해하고 CORS 오류를 해결합니다.

  • 브라우저에서 백엔드로 처음 요청을 보내고 CORS 오류를 직접 관찰합니다.
  • 출처(Origin)의 정의와 동일 출처 정책(SOP)이 막는 것과 막지 않는 것을 구분합니다.
  • 단순 요청과 사전 요청(preflight)의 차이, CORS 관련 헤더의 의미를 설명합니다.
  • 백엔드의 CORS 설정을 고쳐 오류를 해결하고, 프록시라는 다른 해결 방법과 비교합니다.

S4-P8 출처와 동일 출처 정책

CORS 오류를 관찰하고 출처와 동일 출처 정책을 설명할 수 있습니다.

  1. 첫 요청 보내기 실습, 10분
  2. 출처(Origin) 주요 개념, 10분
  3. 동일 출처 정책(SOP) 주요 개념, 5분

S4-P9 CORS와 해결 방법

CORS의 동작을 설명하고 백엔드 설정이나 프록시로 문제를 해결할 수 있습니다.

  1. CORS 주요 개념, 20분
  2. 백엔드 CORS 설정 고치기 주요 개념, 20분
  3. 다른 해결 방법: 프록시 주요 개념, 10분
  4. CORS에 대한 흔한 오해 주요 개념, 5분
  5. 출처를 바꿔 가며 관찰하기 실습, 10분
