정리: useEffect와 정리 함수

핵심 요약

  • 네트워크 요청, 타이머, 브라우저 API처럼 React 밖과 연결하는 작업은 useEffect에서 합니다.
  • 의존성 배열은 다시 실행할 조건이며, 이펙트 안에서 쓰는 값은 모두 넣는 것이 원칙입니다.
  • 정리 함수는 다음 실행이나 화면이 사라지기 직전에 호출되어 타이머를 끄거나 늦은 결과를 무시하게 합니다.

확인 퀴즈

의존성 배열이 빈 배열([])인 이펙트는 언제 실행되나요?

빈 배열은 바뀔 값이 없다는 뜻이므로 처음 한 번 실행됩니다.

이펙트의 정리 함수에서 하는 일로 알맞지 않은 것은 무엇인가요?

정리 함수는 뒷정리를 하며, 화면은 컴포넌트 함수가 반환합니다.
