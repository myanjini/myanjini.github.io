S14. 대시보드 고도화

섹션 목표로그 분석 화면을 더하고, 대시보드의 성능과 접근성을 개선한 뒤 장애 상황에서 화면이 어떻게 반응하는지 관찰합니다.

7일차 오후, 3시간, 파트마다 50분 학습과 10분 휴식

S14-P47 로그 분석 화면

백엔드 JSON 로그를 브라우저에서 분석하는 화면을 만들고, 장애 상황을 만들어 대시보드의 반응을 관찰할 수 있습니다.

  1. 백엔드 로그 분석 화면 실습, 25분
  2. 장애 상황 관찰과 로그 분석 실습, 20분
  3. 정리: 로그 분석 화면 정리, 5분

S14-P48 성능: 코드 분할과 렌더링 최적화

큰 화면을 코드 분할로 분리하고, 불필요한 다시 그리기와 계산을 줄일 수 있습니다.

  1. 렌더링 성능 기초 주요 개념, 15분
  2. 코드 분할과 메모이제이션 적용 실습, 30분
  3. 정리: 성능: 코드 분할과 렌더링 최적화 정리, 5분

S14-P49 접근성과 장애 관찰 실습

대시보드의 접근성 문제를 찾아 개선하고, 키보드와 보조 기술로 화면을 점검할 수 있습니다.

  1. 대시보드 접근성 주요 개념, 15분
  2. 표 보기, 상태 알림, 키보드 점검 실습, 30분
  3. 정리: 접근성과 장애 관찰 실습 정리, 5분
