정리: 로그 분석 화면

핵심 요약

  • JSON Lines 로그는 한 줄씩 JSON.parse하고, 요청 로그만 골라 집계합니다.
  • 고른 파일은 서버로 보내지 않고 브라우저 안에서만 처리하며, 너무 큰 파일은 미리 거절합니다.
  • DB 중지와 API 중지는 대시보드에서 다르게 나타나며, 그 차이로 장애 위치를 좁힐 수 있습니다.

확인 퀴즈

로그 분석 화면이 고른 파일을 서버로 보내지 않고 file.text()로 브라우저에서 읽는 이유로 알맞은 것은 무엇인가요?

로그에는 요청 경로와 ID 같은 운영 정보가 있으므로 불필요하게 전송하지 않습니다.

docker compose stop db를 실행했을 때 대시보드에 나타나는 모습으로 옳은 것은 무엇인가요?
