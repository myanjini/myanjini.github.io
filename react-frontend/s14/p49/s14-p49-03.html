정리: 접근성과 장애 관찰 실습

핵심 요약

  • 상태는 색, 모양, 글자로 함께 전달하고, 차트에는 요약 문장과 같은 데이터의 표 보기를 제공합니다.
  • aria-live 영역은 바뀐 내용만 보조 기술에 알리며, 숨길 때는 display: none이 아니라 sr-only를 씁니다.
  • 키보드만으로 모든 기능을 쓸 수 있는지, Lighthouse와 화면 낭독기로 점검합니다.

확인 퀴즈

화면에는 보이지 않지만 화면 낭독기는 읽게 하려면 어떻게 숨겨야 하나요?

display: none, visibility: hidden, aria-hidden은 보조 기술에서도 숨깁니다.

SVG 차트의 접근성을 높이는 방법으로 알맞은 것은 무엇인가요?

화면 낭독기는 차트의 모양을 읽지 못하므로 글로 된 대체 정보가 필요합니다.
