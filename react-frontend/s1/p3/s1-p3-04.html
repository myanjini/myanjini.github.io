정리: 개발 환경 구성과 백엔드 준비

핵심 요약

  • Node.js 22.22 이상(LTS 24 권장), VS Code, Chrome 또는 Edge, Git을 준비했습니다.
  • 백엔드는 Docker Compose로 http://127.0.0.1:8000에서 실행하고, /health와 /docs로 동작을 확인합니다.
  • 연계 API 표는 과정 전체에서 참고하는 기준 자료이며, 요청 형식이 헷갈리면 이 표로 돌아옵니다.

확인 퀴즈

백엔드가 정상 실행 중인지 가장 간단히 확인하는 방법은 무엇인가요?

헬스 체크 API는 API와 데이터베이스 연결 상태를 함께 알려 줍니다.

로그인 API POST /auth/token이 요구하는 본문 형식은 무엇인가요?

OAuth2 Password Flow를 따르므로 폼 형식으로 username과 password를 보냅니다.
