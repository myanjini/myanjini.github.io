백엔드 실행과 실습 데이터

3) 백엔드 준비

백엔드 과정의 프로젝트 폴더(이 교안에서는 book-api라고 부릅니다)에서 백엔드 S8-P27의 Docker Compose 구성으로 API와 PostgreSQL을 실행합니다.

cd book-api
docker compose up -d --build
docker compose ps          # db와 api가 모두 running(healthy)인지 확인
curl http://127.0.0.1:8000/health

{"status":"ok","database":"ok"}가 출력되면 준비가 끝났습니다. 브라우저에서 http://127.0.0.1:8000/docs를 열어 Swagger UI가 보이는지도 확인합니다.

4) 실습용 계정과 데이터

Swagger UI에서 다음 순서로 실습 데이터를 만들어 둡니다.

  1. POST /auth/signup으로 일반 사용자 계정과 관리자로 쓸 계정을 하나씩 만듭니다.
  2. 백엔드 과정 S5-P17-03에서 다룬 app/make_admin.py로 관리자로 쓸 계정의 role을 "admin"으로 바꿉니다.
  3. 관리자 계정으로 로그인(Swagger UI 오른쪽 위 Authorize)한 뒤 POST /authors로 저자 두세 명을, POST /books로 도서 15권 이상을 등록합니다. 페이지 이동을 확인하려면 도서가 10권을 넘어야 합니다.

5) 작업 폴더 배치

프론트엔드 프로젝트는 백엔드 폴더와 나란히 만듭니다. S15에서 백엔드의 Compose 파일이 상대 경로로 프론트엔드 폴더를 찾기 때문입니다.

workspace/
├── book-api/          # 백엔드 과정 결과물
└── react-frontend/    # 이 과정에서 만들 프론트엔드
