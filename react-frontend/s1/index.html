S1. 웹 프론트엔드와 개발 환경

섹션 목표과정의 목표와 결과물을 확인하고, 실습 환경과 연계할 백엔드를 준비한 뒤 프론트엔드 관점에서 HTTP와 JSON을 다룹니다.

1일차 오전, 4시간, 파트마다 50분 학습과 10분 휴식

S1-P1 과정 소개와 결과물

9일 동안 무엇을 만들고 어떤 순서로 배우는지, 교안과 예제 저장소를 어떻게 쓰는지 설명할 수 있습니다.

  1. 과정 소개와 로드맵 주요 개념, 10분
  2. 학습 목표와 사전 지식 주요 개념, 10분
  3. 최종 결과물 주요 개념, 15분
  4. 예제 저장소와 단계별 브랜치 주요 개념, 10분
  5. 정리: 과정 소개와 결과물 정리, 5분

S1-P2 브라우저, DOM, SPA

브라우저가 화면을 만드는 과정과 SPA의 동작 방식을 설명하고 개발자 도구로 관찰할 수 있습니다.

  1. 브라우저가 화면을 만드는 방식 주요 개념, 15분
  2. MPA와 SPA 주요 개념, 15분
  3. 개발자 도구로 화면과 요청 관찰하기 실습, 15분
  4. 정리: 브라우저, DOM, SPA 정리, 5분

S1-P3 개발 환경 구성과 백엔드 준비

Node.js와 편집기를 설치하고, 연계할 백엔드를 실행해 실습 데이터를 준비할 수 있습니다.

  1. Node.js, 편집기, Git 준비 실습, 15분
  2. 백엔드 실행과 실습 데이터 실습, 20분
  3. 연계할 백엔드 API 한눈에 보기 주요 개념, 10분
  4. 정리: 개발 환경 구성과 백엔드 준비 정리, 5분

S1-P4 프론트엔드 관점의 HTTP와 JSON

요청과 응답의 구성 요소를 구분하고, JSON을 JavaScript 값과 서로 변환할 수 있습니다.

  1. 프론트엔드 관점에서 본 HTTP 주요 개념, 15분
  2. JSON 주요 개념, 10분
  3. JSON 변환과 백엔드 응답 읽기 실습, 20분
  4. 정리: 프론트엔드 관점의 HTTP와 JSON 정리, 5분
