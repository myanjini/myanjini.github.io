정리: Fetch API와 axios로 API 계층 만들기

핵심 요약

  • fetch는 응답을 받으면 상태 코드와 관계없이 성공으로 처리하므로 response.ok를 직접 확인해야 합니다.
  • 본문 형식은 JSON(JSON.stringify), 폼(URLSearchParams), 멀티파트(FormData)로 보내며, 멀티파트는 Content-Type을 직접 지정하지 않습니다.
  • AbortController로 필요 없어진 요청을 취소하고, useEffect 정리 함수에서 호출합니다.
  • axios 인스턴스와 인터셉터로 기본 주소, 시간 제한, 오류 모양을 한 곳에서 통일합니다.
  • VITE_로 시작하는 환경 변수는 빌드 결과물에 공개되므로 비밀정보를 넣지 않습니다.

확인 퀴즈

fetch로 요청했는데 서버가 404를 돌려주었습니다. 어떻게 되나요?

fetch는 응답을 받으면 상태 코드와 관계없이 성공으로 처리하므로 response.ok를 확인해야 합니다.

표지 업로드에서 Content-Type을 직접 지정하지 않는 이유는 무엇인가요?

FormData를 넘기면 boundary가 포함된 Content-Type이 자동으로 만들어집니다.

VITE_ 환경 변수에 비밀 키를 넣으면 안 되는 이유는 무엇인가요?

VITE_ 값은 빌드할 때 JavaScript에 새겨지므로 공개된 값으로 취급해야 합니다.
