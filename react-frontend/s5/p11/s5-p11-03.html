환경 변수

API 주소를 코드에 직접 적으면 개발 환경과 운영 환경을 바꿀 때마다 코드를 고쳐야 합니다. Vite는 프로젝트 루트의 .env 파일을 읽어 import.meta.env로 제공합니다.

파일 적용 시점
.env 항상
.env.development npm run dev
.env.production npm run build
.env.local, .env.[모드].local 위와 같으며 Git에 올리지 않는 개인 설정용

프로젝트 루트에 .env.development를 만듭니다.

.env.development
# 개발 서버(npm run dev)에서 사용하는 값입니다.
# VITE_ 로 시작하는 값은 빌드 결과물에 그대로 들어가므로 비밀정보를 넣지 않습니다.
VITE_API_BASE_URL=http://127.0.0.1:8000

코드에서는 import.meta.env.VITE_API_BASE_URL로 읽습니다. 이름이 VITE_로 시작하는 값만 코드에 노출됩니다. 이 값들은 빌드할 때 JavaScript 파일에 문자열로 새겨지므로, 사용자가 개발자 도구에서 누구나 볼 수 있습니다. 비밀번호나 API 키 같은 비밀정보를 프론트엔드 환경 변수에 넣으면 안 되는 이유이며, S9에서 다시 다룹니다. .env 파일을 고친 뒤에는 개발 서버를 다시 시작해야 반영됩니다.
