정리: 운영 빌드와 환경 변수

핵심 요약

  • 운영 환경에서는 Vite 개발 서버가 아니라 npm run build로 만든 정적 파일을 웹 서버가 제공합니다.
  • Vite의 VITE_ 환경 변수는 빌드할 때 코드에 새겨지므로 실행할 때 바꿀 수 없습니다.
  • 같은 출처 프록시를 쓰면 /api처럼 환경과 무관한 상대 경로로 빌드할 수 있습니다.

확인 퀴즈

컨테이너를 실행할 때 VITE_API_BASE_URL 환경 변수를 바꿔도 화면의 API 주소가 바뀌지 않는 이유는 무엇인가요?

빌드 결과물은 정적 파일이므로 실행 환경의 변수를 읽지 않습니다.

npm run preview로 연 화면에서 API 요청이 실패하는 이유는 무엇인가요?

운영 빌드는 /api를 같은 출처로 부르며, 이를 백엔드로 넘기는 일은 Nginx가 맡습니다.
