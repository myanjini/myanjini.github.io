정리: Compose 통합 실행

핵심 요약

  • 백엔드 Compose 구성에 web 서비스를 추가하면 화면, API, 데이터베이스를 한 명령으로 실행할 수 있습니다.
  • 통합 환경에서는 사전 요청이 없고, 새로고침, 표지 주소, 코드 분할, 보안 헤더, CSP가 운영과 같게 동작하는지 확인합니다.
  • 프록시 뒤의 백엔드는 신뢰할 프록시를 지정한 뒤에만 X-Forwarded-For를 사용해야 합니다.

확인 퀴즈

통합 환경(localhost:8080)에서 API 요청에 OPTIONS 사전 요청이 생기지 않는 이유는 무엇인가요?

같은 출처 요청에는 CORS 검사가 적용되지 않습니다.

/api/... 요청이 502 Bad Gateway일 때 먼저 확인할 것은 무엇인가요?

502는 Nginx가 뒤의 서버에서 응답을 받지 못했다는 뜻입니다.
