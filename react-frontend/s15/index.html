S15. 도커라이징과 운영 빌드

섹션 목표운영 빌드를 Nginx로 제공하는 컨테이너 이미지를 만들고, 백엔드와 함께 Compose로 실행해 같은 출처 구성으로 점검합니다.

8일차 오전, 4시간, 파트마다 50분 학습과 10분 휴식

S15-P50 운영 빌드와 환경 변수

개발 서버와 운영 환경의 차이를 설명하고, 운영용 환경 변수로 빌드한 결과물을 확인할 수 있습니다.

  1. 운영 환경의 구조 주요 개념, 15분
  2. 운영 빌드 만들고 확인하기 실습, 30분
  3. 정리: 운영 빌드와 환경 변수 정리, 5분

S15-P51 Nginx와 리버스 프록시

Nginx로 정적 파일 제공, SPA 대체 응답, API 리버스 프록시, 보안 헤더를 설정할 수 있습니다.

  1. 리버스 프록시와 SPA 대체 응답 주요 개념, 10분
  2. Nginx 설정 작성 실습, 35분
  3. 정리: Nginx와 리버스 프록시 정리, 5분

S15-P52 멀티 스테이지 Dockerfile

멀티 스테이지 빌드로 작고 안전한 프론트엔드 이미지를 만들고, 컨테이너 하나로 실행해 응답을 확인할 수 있습니다.

  1. Dockerfile 작성 실습, 30분
  2. 이미지 빌드와 단독 실행 실습, 15분
  3. 정리: 멀티 스테이지 Dockerfile 정리, 5분

S15-P53 Compose 통합 실행

백엔드 Compose 구성에 프론트엔드를 추가해 함께 실행하고, 운영 형태의 동작과 보안 설정을 점검할 수 있습니다.

  1. Compose에 web 서비스 추가 실습, 20분
  2. 통합 환경 점검 실습, 25분
  3. 정리: Compose 통합 실행 정리, 5분
