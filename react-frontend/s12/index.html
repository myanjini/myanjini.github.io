S12. 종합 점검과 확장 과제

섹션 목표완성한 애플리케이션을 시나리오와 점검표로 점검하고 확장 과제에 도전합니다.

  • 완성한 애플리케이션을 사용자, 관리자, 운영자 관점의 시나리오로 처음부터 끝까지 점검합니다.
  • 기능, 보안, 관제, 배포 점검표로 빠진 부분을 찾아 보완합니다.
  • 자주 만나는 문제의 원인을 증상으로부터 찾아냅니다.
  • 확장 과제로 학습한 내용을 스스로 응용합니다.

S12-P27 종합 점검과 확장

완성한 애플리케이션을 종합 점검하고 확장 과제를 계획할 수 있습니다.

  1. 종합 시나리오 주요 개념, 10분
  2. 점검표 주요 개념, 20분
  3. 문제 해결 가이드 주요 개념, 10분
  4. 확장 과제 주요 개념, 5분
  5. 과정을 마치며 주요 개념, 5분
