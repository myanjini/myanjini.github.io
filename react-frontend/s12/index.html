S12. 프론트엔드 개발 보안

섹션 목표프론트엔드에서 지켜야 할 개발 보안 요소를 이해하고, 백엔드 과정의 보안약점 분류에 맞춰 코드를 점검합니다.

6일차 오후, 3시간, 파트마다 50분 학습과 10분 휴식

S12-P40 XSS, 토큰 보호, CSRF

프론트엔드 보안의 전제를 이해하고, XSS, 토큰 저장 위치, CSRF와 클릭재킹의 위험과 대책을 설명할 수 있습니다.

  1. 프론트엔드 보안의 전제 주요 개념, 10분
  2. XSS(크로스 사이트 스크립팅) 주요 개념, 15분
  3. 토큰 저장 위치 주요 개념, 10분
  4. CSRF와 클릭재킹 주요 개념, 10분
  5. 정리: XSS, 토큰 보호, CSRF 정리, 5분

S12-P41 보안 헤더, CSP, 비밀정보

보안 헤더와 CSP의 의미를 설명하고, 비밀정보 관리, 정보 노출 방지, 열린 리디렉션 대책을 적용할 수 있습니다.

  1. 보안 헤더와 CSP 주요 개념, 15분
  2. 비밀정보와 빌드 결과물 주요 개념, 10분
  3. 정보 노출과 열린 리디렉션 주요 개념, 10분
  4. XSS 동작 확인 실습, 10분
  5. 정리: 보안 헤더, CSP, 비밀정보 정리, 5분

S12-P42 공급망 보안과 보안 점검 실습

의존성과 요청 제한의 위험을 관리하고, 린트 규칙과 점검표로 프론트엔드 코드의 보안을 점검할 수 있습니다.

  1. 의존성, 공급망, 요청 제한 주요 개념, 10분
  2. 보안 린트 규칙 추가 실습, 15분
  3. 보안 점검하기 실습, 20분
  4. 정리: 공급망 보안과 보안 점검 실습 정리, 5분
