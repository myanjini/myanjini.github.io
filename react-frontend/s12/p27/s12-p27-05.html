과정을 마치며

이 과정에서는 백엔드 과정의 도서 관리 API를 실제 사용자가 쓰는 화면으로 완성했습니다. JSON과 HTTP의 기초에서 출발해, 브라우저가 지키는 출처의 규칙을 이해하고, 인증과 쓰기 기능을 구현한 뒤, 보안 대책과 관제 대시보드를 더하고, 마지막으로 컨테이너로 묶어 운영 형태로 실행했습니다.

프론트엔드와 백엔드는 서로의 규칙을 알 때 가장 잘 맞물립니다. 화면의 검증은 백엔드의 규칙을 따라야 하고, 화면의 권한 처리는 백엔드의 권한 표를 반영해야 하며, CORS와 프록시는 두 쪽의 설정이 함께 맞아야 동작합니다. 앞으로 새 API를 연결할 때도 S1-P2-01처럼 API 명세를 먼저 정리하고, 이 과정에서 만든 계층(API 함수, 인터셉터, 화면)에 맞춰 차근차근 확장해 나가기를 권합니다.
