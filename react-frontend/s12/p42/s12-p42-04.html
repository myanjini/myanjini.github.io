정리: 공급망 보안과 보안 점검 실습

핵심 요약

  • npm audit, npm ci, 잠금 파일 관리로 의존성의 위험을 줄이고, 처리 중 버튼 비활성화와 요청 취소로 불필요한 요청을 막습니다.
  • 위험한 코드는 린트 규칙(react/no-danger, no-eval 등)으로 자동으로 막습니다.
  • KISA 보안약점 분류에 맞춘 점검표로 코드를 정기적으로 확인합니다.

확인 퀴즈

공급망 보안을 위해 CI와 Docker 빌드에서 npm install 대신 npm ci를 쓰는 이유는 무엇인가요?

npm ci는 잠금 파일과 package.json이 맞지 않으면 실패하며, 재현 가능한 설치를 보장합니다.

react/no-danger 린트 규칙이 막는 것은 무엇인가요?

dangerouslySetInnerHTML은 XSS의 대표적인 통로라 린트로 사용을 막습니다.
