정리: 보안 헤더, CSP, 비밀정보

핵심 요약

  • CSP의 script-src 'self'는 인라인 코드와 eval을 막아 XSS의 피해를 크게 줄입니다. 설정은 S15-P51의 Nginx에서 적용합니다.
  • VITE_ 값은 공개된 값으로 취급하고, 운영 빌드에는 소스맵을 넣지 않으며, 민감정보를 로그로 남기지 않습니다.
  • 로그인 후 이동 주소는 /로 시작하는 내부 경로만 허용하고 //로 시작하는 주소는 거부합니다.

확인 퀴즈

CSP script-src 'self'의 효과로 옳은 것은 무엇인가요?

인라인 스크립트와 onerror 같은 이벤트 속성, eval이 차단됩니다.

로그인 후 이동 주소로 //evil.example을 거부해야 하는 이유는 무엇인가요?

//로 시작하는 주소는 프로토콜 상대 주소로, 외부 사이트로 보내는 열린 리디렉션이 됩니다.
