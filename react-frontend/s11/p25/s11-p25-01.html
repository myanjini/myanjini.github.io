운영 환경의 구조

npm run dev로 띄운 Vite 개발 서버는 코드 변환, HMR 같은 개발 편의 기능을 위한 서버이며 운영 용도가 아닙니다. 운영 환경에서는 npm run build로 만든 정적 파일(dist)을 웹 서버가 제공합니다. 빌드 결과물은 HTML, JavaScript, CSS 파일일 뿐이므로 Node.js가 실행될 필요가 없습니다.

이 과정은 Nginx를 웹 서버로 사용하며, Nginx가 두 가지 일을 맡습니다.

브라우저 ── http://localhost:8080 ──> [web 컨테이너: Nginx]
                                        ├─ /, /books/7, /dashboard ...  -> dist의 index.html, JS, CSS
                                        └─ /api/...  ──(프록시)──> [api 컨테이너: FastAPI :8000] ──> [db]
  1. 정적 파일 제공: 빌드 결과물을 보내고, 모든 응답에 S9의 보안 헤더를 붙입니다.
  2. 리버스 프록시: /api/로 시작하는 요청을 백엔드 컨테이너로 전달합니다.

이 구조에서 브라우저가 보는 출처는 http://localhost:8080 하나뿐입니다. 화면도 API도 같은 출처에서 오므로 CORS가 필요 없고 사전 요청도 생기지 않습니다. S4-P9-03에서 비교한 프록시 방식을 운영 환경에 적용한 것입니다.
