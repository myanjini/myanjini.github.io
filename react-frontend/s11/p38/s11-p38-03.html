정리: MSW로 API 모킹

핵심 요약

  • MSW는 네트워크 수준에서 응답을 가짜로 바꿔, 앱 코드를 고치지 않고 요청부터 화면까지 검증합니다.
  • 가짜 API의 응답 형식은 실제 백엔드 명세와 같게 맞추고, 테스트마다 필요한 응답만 server.use로 바꿉니다.
  • 테스트마다 새 Query 캐시를 만들어 테스트끼리 영향을 주지 않게 합니다.

확인 퀴즈

MSW를 쓰는 테스트가 API 함수를 vi.mock으로 바꾸는 테스트보다 나은 점은 무엇인가요?

요청 자체를 가로채므로 앱 코드의 모든 계층이 실제처럼 동작합니다.

테스트마다 새 QueryClient를 만드는 이유는 무엇인가요?

테스트는 서로 독립적이어야 순서와 관계없이 같은 결과가 나옵니다.
