정리: 테스트 전략과 Vitest

핵심 요약

  • 단위 테스트를 가장 많이, E2E를 가장 적게 두고, 규칙이 있고 실수하기 쉬운 곳을 우선 테스트합니다.
  • 컴포넌트 안의 검증과 변환 함수를 별도 파일로 꺼내면 화면 없이 빠르게 테스트할 수 있습니다.
  • 테스트 환경은 시간대와 API 주소처럼 컴퓨터마다 다를 수 있는 값을 고정합니다.

확인 퀴즈

다음 중 단위 테스트로 검사하기 가장 알맞은 것은 무엇인가요?

화면과 무관한 순수 함수는 단위 테스트로 빠르게 검증합니다.

테스트 설정에서 시간대를 Asia/Seoul로 고정한 이유는 무엇인가요?

CI 서버는 보통 UTC입니다. 환경에 따라 결과가 바뀌는 테스트는 믿을 수 없습니다.
