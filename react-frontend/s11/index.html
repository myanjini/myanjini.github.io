S11. 프론트엔드 테스트

섹션 목표Vitest, React Testing Library, MSW, Playwright로 함수부터 화면, 실제 브라우저까지 자동으로 검증합니다.

6일차 오전, 4시간, 파트마다 50분 학습과 10분 휴식

S11-P36 테스트 전략과 Vitest

프론트엔드 테스트의 종류와 역할을 구분하고, Vitest로 순수 함수를 테스트할 수 있습니다.

  1. 프론트엔드 테스트 전략 주요 개념, 15분
  2. Vitest 설정과 첫 테스트 실습, 30분
  3. 정리: 테스트 전략과 Vitest 정리, 5분

S11-P37 React Testing Library

사용자가 화면을 쓰는 방식대로 요소를 찾고 조작하는 컴포넌트 테스트를 작성할 수 있습니다.

  1. 사용자처럼 테스트하기 주요 개념, 15분
  2. 페이지 이동과 로그인 화면 테스트 실습, 30분
  3. 정리: React Testing Library 정리, 5분

S11-P38 MSW로 API 모킹

MSW로 네트워크 수준에서 가짜 API를 만들어, 백엔드 없이 데이터를 불러오는 화면을 테스트할 수 있습니다.

  1. 어디를 가짜로 바꿀 것인가 주요 개념, 10분
  2. 목록 화면을 가짜 API로 테스트하기 실습, 35분
  3. 정리: MSW로 API 모킹 정리, 5분

S11-P39 Playwright E2E

Playwright로 실제 브라우저에서 화면 흐름을 검증하고, CI에서도 돌아가도록 API를 가로챌 수 있습니다.

  1. E2E 테스트 주요 개념, 10분
  2. 핵심 흐름 E2E 테스트 실습, 35분
  3. 정리: Playwright E2E 정리, 5분
