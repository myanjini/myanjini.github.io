정리: 목록: URL 조건과 페이지네이션

핵심 요약

  • 검색, 정렬, 페이지 조건은 URL 쿼리 문자열에 두어 새로고침, 뒤로 가기, 주소 공유에도 유지되게 합니다.
  • 입력 중인 검색어는 state로 두고, 검색할 때만 URL에 반영해 요청 수를 줄입니다.
  • 백엔드의 skip, limit, total로 화면의 현재 페이지와 마지막 페이지를 계산합니다.

확인 퀴즈

total이 23, limit이 10일 때 3쪽의 skip 값은 무엇인가요?

skip은 (페이지 - 1) x limit이므로 3쪽은 20입니다.

검색 조건을 URL에 두는 이유로 알맞지 않은 것은 무엇인가요?

URL에 두는 것은 화면 상태 관리 방법일 뿐이며 백엔드 검증은 여전히 필요합니다.
