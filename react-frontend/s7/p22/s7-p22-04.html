정리: React Router와 앱 뼈대

핵심 요약

  • React Router의 선언형 모드로 주소와 화면을 연결하고, 레이아웃 라우트와 <Outlet>으로 공통 틀을 만듭니다.
  • 앱 안의 이동은 <Link>로 해야 새로고침 없이 이동하고 메모리의 상태가 유지됩니다.
  • 화면은 pages, 공통 표시는 components에 두며, 연습용 코드는 정리합니다.

확인 퀴즈

앱 안에서 다른 화면으로 이동할 때 <a href> 대신 <Link to>를 쓰는 이유는 무엇인가요?

Link는 History API로 주소만 바꾸고 화면을 교체합니다.

레이아웃 라우트에서 자식 화면이 그려지는 자리를 표시하는 컴포넌트는 무엇인가요?

부모 라우트의 element 안에 Outlet을 두면 그 자리에 일치하는 자식 화면이 그려집니다.
