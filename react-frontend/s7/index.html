S7. 라우팅과 조회 화면

S7-P22 React Router와 앱 뼈대

React Router로 주소와 화면을 연결하고, 공통 레이아웃과 404 화면을 갖춘 앱의 뼈대를 만들 수 있습니다.

  1. 클라이언트 측 라우팅 주요 개념, 10분
  2. 라우터 구성 요소 주요 개념, 10분
  3. 앱 뼈대 만들기 실습, 25분
  4. 정리: React Router와 앱 뼈대 정리, 5분

S7-P23 목록: URL 조건과 페이지네이션

검색, 정렬, 페이지 조건을 URL로 관리하고, 백엔드의 페이지네이션 응답으로 페이지 이동을 구현할 수 있습니다.

  1. 검색 조건을 URL에 두는 이유 주요 개념, 10분
  2. 백엔드 페이지네이션과 화면 페이지 주요 개념, 10분
  3. 목록 화면 완성 실습, 25분
  4. 정리: 목록: URL 조건과 페이지네이션 정리, 5분

S7-P24 상세 화면과 로딩, 오류 처리

주소의 매개변수로 데이터를 불러오는 상세 화면을 만들고, 상황별 로딩과 오류 표시를 설계할 수 있습니다.

  1. 도서 상세 화면 실습, 20분
  2. 로딩, 오류, 빈 상태 설계 주요 개념, 15분
  3. 상세 화면 확인 실습, 10분
  4. 정리: 상세 화면과 로딩, 오류 처리 정리, 5분

S7-P25 조회 화면 통합 실습

백엔드의 저자 조건으로 목록을 거르는 기능을 스스로 추가하고, 조회 화면 전체를 시나리오로 점검할 수 있습니다.

  1. 저자별 보기 추가하기 실습, 30분
  2. 조회 화면 종합 점검 실습, 15분
