정리: 조회 화면 통합 실습

핵심 요약

  • 새 조건을 추가할 때도 "URL에 두고, 바뀌면 첫 페이지로, 바뀌면 다시 불러오기" 규칙을 그대로 따릅니다.
  • 조건과 무관한 데이터는 별도의 이펙트로 한 번만 불러옵니다.
  • 보조 기능의 실패가 핵심 기능을 막지 않도록 실패를 나눠 처리합니다.

확인 퀴즈

저자 목록과 도서 목록을 하나의 이펙트에서 불러오면 생기는 문제는 무엇인가요?

이펙트는 의존성 단위로 나누어, 필요한 조건이 바뀔 때만 다시 실행되게 합니다.

저자 선택 상자의 값으로 저자 이름이 아니라 id를 쓴 이유는 무엇인가요?

화면의 값은 API 명세에 맞춥니다. 이름은 선택 상자에 보이는 글자로만 씁니다.
