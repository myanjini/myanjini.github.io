정리: 커스텀 훅으로 반복 줄이기

핵심 요약

  • 이름이 use로 시작하고 다른 훅을 부르는 함수로 반복되는 상태 로직을 추출할 수 있습니다.
  • 커스텀 훅은 상태를 다루는 방법을 공유할 뿐, 상태 자체를 화면 사이에 공유하지 않습니다.
  • 화면마다 서버 데이터를 따로 들고 있으면 중복 요청과 화면 사이의 불일치가 생깁니다.

확인 퀴즈

커스텀 훅에 대한 설명으로 옳은 것은 무엇인가요?

커스텀 훅을 부르는 컴포넌트마다 독립된 state가 생깁니다. 이름은 use로 시작해야 훅 규칙 검사가 적용됩니다.
