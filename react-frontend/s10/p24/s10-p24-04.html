라우트 등록과 코드 분할

대시보드를 관리자 전용 라우트로 등록합니다. 이때 코드 분할을 함께 적용합니다. Recharts는 크기가 큰 라이브러리라서 모든 화면의 JavaScript에 포함하면, 대시보드를 쓰지 않는 일반 사용자도 첫 화면을 열 때 이를 모두 내려받아야 합니다. lazy와 동적 import()를 쓰면 빌드 시 대시보드가 별도 파일로 분리되고, 관리자가 대시보드를 처음 열 때만 내려받습니다. 내려받는 동안에는 Suspense의 fallback이 표시됩니다. App.jsx의 최종 코드는 다음과 같습니다.

src/App.jsx
import { lazy, Suspense } from 'react';
import { Route, Routes } from 'react-router';
import RequireAuth from './auth/RequireAuth';
import Layout from './components/Layout';
import BookDetailPage from './pages/BookDetailPage';
import BookFormPage from './pages/BookFormPage';
import BookListPage from './pages/BookListPage';
import LoginPage from './pages/LoginPage';
import MyLoansPage from './pages/MyLoansPage';
import NotFoundPage from './pages/NotFoundPage';
import SignupPage from './pages/SignupPage';

// 차트 라이브러리가 큰 대시보드는 처음 열 때만 따로 내려받습니다.
const DashboardPage = lazy(() => import('./dashboard/DashboardPage'));

export default function App() {
  return (
    <Routes>
      <Route element={<Layout />}>
        <Route index element={<BookListPage />} />
        <Route path="books/:bookId" element={<BookDetailPage />} />
        <Route path="books/new" element={<RequireAuth><BookFormPage /></RequireAuth>} />
        <Route path="books/:bookId/edit" element={<RequireAuth><BookFormPage /></RequireAuth>} />
        <Route path="loans" element={<RequireAuth><MyLoansPage /></RequireAuth>} />
        <Route
          path="dashboard"
          element={
            <RequireAuth adminOnly>
              <Suspense fallback={<p className="muted">대시보드를 불러오는 중입니다.</p>}>
                <DashboardPage />
              </Suspense>
            </RequireAuth>
          }
        />
        <Route path="login" element={<LoginPage />} />
        <Route path="signup" element={<SignupPage />} />
        <Route path="*" element={<NotFoundPage />} />
      </Route>
    </Routes>
  );
}

npm run build를 실행하면 결과에 index-...js와 DashboardPage-...js가 따로 생성되는 것을 확인할 수 있습니다. 이 과정의 코드로 확인했을 때 첫 화면용 파일은 약 340KB(gzip 약 110KB), 대시보드 파일은 약 450KB(gzip 약 127KB)였습니다. 코드 분할을 하지 않으면 첫 화면용 파일 하나가 약 790KB가 되고 Vite가 500KB 초과 경고를 출력합니다.
