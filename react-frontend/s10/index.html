S10. 관제 대시보드와 데이터 시각화

섹션 목표관제 환경에 맞는 대시보드를 설계하고 Recharts로 상태와 추세를 시각화합니다.

  • 관제 환경에서 대시보드가 해야 할 일과 설계 원칙을 설명합니다.
  • 서비스 상태를 나타내는 지표를 고르고, 이 백엔드에서 얻을 수 있는 데이터 소스와 연결합니다.
  • 데이터의 성격에 맞는 차트 형태와 시각화 도구를 고릅니다.
  • 주기적 갱신, 요청 기록, 로그 분석을 갖춘 관제 대시보드를 Recharts로 구현합니다.

S10-P22 관제 대시보드 설계

관제 대시보드의 원칙, 지표, 차트 형태, 도구를 고를 수 있습니다.

  1. 관제 대시보드란 주요 개념, 5분
  2. 설계 원칙 주요 개념, 5분
  3. 무엇을 볼 것인가: 지표와 데이터 소스 주요 개념, 10분
  4. 차트 형태 고르기 주요 개념, 5분
  5. 시각화 도구 비교 주요 개념, 10분

S10-P23 대시보드 구현 1: 데이터 준비

폴링, 요청 기록, 지표 계산, 공통 표시 컴포넌트를 만들 수 있습니다.

  1. 실시간 갱신 방식 실습, 10분
  2. Recharts 설치 실습, 10분
  3. 브라우저 요청 기록 실습, 25분
  4. 지표 계산 함수 실습, 20분
  5. 공통 표시 컴포넌트 실습, 15분

S10-P24 대시보드 구현 2: 화면 완성

차트와 로그 분석 화면을 만들고 장애 상황을 관찰할 수 있습니다.

  1. 헬스 체크 패널과 상태 코드 분포 실습, 20분
  2. 백엔드 로그 분석 실습, 25분
  3. 대시보드 화면 조립 실습, 20분
  4. 라우트 등록과 코드 분할 실습, 10분
  5. 관제 대시보드 운영해 보기 실습, 10분
  6. 정리: 관제 대시보드와 데이터 시각화 정리, 5분
