S10. 서버 상태 관리

섹션 목표반복되는 조회 코드를 커스텀 훅으로 줄이고, TanStack Query로 서버 데이터를 캐시하며 변경 후 화면을 일관되게 갱신합니다.

5일차 오후, 3시간, 파트마다 50분 학습과 10분 휴식

S10-P33 커스텀 훅으로 반복 줄이기

반복되는 불러오기 코드를 커스텀 훅으로 추출하고, 그 한계를 설명할 수 있습니다.

  1. 반복 코드와 커스텀 훅 주요 개념, 15분
  2. useAsync 훅 만들고 적용하기 실습, 30분
  3. 정리: 커스텀 훅으로 반복 줄이기 정리, 5분

S10-P34 TanStack Query로 조회 다루기

서버 상태와 클라이언트 상태를 구분하고, TanStack Query로 조회 결과를 캐시해 화면 사이에서 공유할 수 있습니다.

  1. 서버 상태와 TanStack Query 주요 개념, 15분
  2. 목록과 상세를 useQuery로 바꾸기 실습, 30분
  3. 정리: TanStack Query로 조회 다루기 정리, 5분

S10-P35 변경 요청과 캐시 무효화

useMutation으로 서버 데이터를 바꾸고, 관련 캐시를 무효화해 모든 화면을 일관되게 갱신할 수 있습니다.

  1. useMutation과 캐시 무효화 주요 개념, 10분
  2. 대여, 반납, 삭제, 저장을 useMutation으로 실습, 35분
  3. 정리: 변경 요청과 캐시 무효화 정리, 5분
