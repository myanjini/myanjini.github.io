정리: API 계층 설계와 구현

핵심 요약

  • 화면은 listBooks() 같은 의미 있는 함수만 호출하고, 경로와 본문 형식은 API 함수가, 공통 처리는 axios 인스턴스가 맡습니다.
  • 헬스 체크처럼 503 응답 본문 자체가 정보인 API는 Fetch API로 직접 호출합니다.
  • 화면에서는 로딩, 오류, 결과 상태를 관리하고, 조건이 바뀌거나 화면을 떠나면 이전 요청을 취소합니다.

확인 퀴즈

API 계층을 따로 두는 가장 큰 이유는 무엇인가요?

화면과 백엔드의 세부 사항을 분리하면 변경의 영향 범위가 줄어듭니다.

헬스 체크를 axios 인스턴스가 아니라 Fetch API로 호출한 이유는 무엇인가요?

fetch는 503도 정상 응답으로 돌려주므로 본문을 그대로 읽어 관제 화면에 쓸 수 있습니다.
