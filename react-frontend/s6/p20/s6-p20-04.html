정리: axios와 환경 변수

핵심 요약

  • axios는 JSON 변환, 4xx와 5xx 오류 처리, 기본 주소와 시간 제한, 인터셉터를 제공합니다.
  • 응답 인터셉터에서 모든 실패를 ApiError 하나로 바꿔 화면 코드가 오류 형식의 차이를 몰라도 되게 합니다.
  • VITE_로 시작하는 환경 변수는 빌드 결과물에 공개되므로 비밀정보를 넣지 않고, 바꾼 뒤에는 개발 서버를 다시 시작합니다.

확인 퀴즈

응답 인터셉터에서 취소된 요청을 ApiError로 바꾸지 않고 그대로 넘기는 이유는 무엇인가요?

취소는 의도한 동작입니다. axios.isCancel로 구분해 오류로 표시하지 않습니다.

VITE_ 환경 변수에 비밀 키를 넣으면 안 되는 이유는 무엇인가요?

VITE_ 값은 빌드할 때 JavaScript에 새겨지므로 공개된 값으로 취급해야 합니다.
