정리: 라우팅과 조회 화면

핵심 요약

  • React Router의 선언형 모드로 주소와 화면을 연결하고, 레이아웃 라우트와 <Outlet>으로 공통 틀을 만듭니다.
  • 앱 안의 이동은 <Link>로 해야 메모리의 상태가 유지됩니다.
  • 검색, 정렬, 페이지 조건은 URL 쿼리 문자열에 두어 새로고침과 공유에도 유지되게 합니다.
  • 백엔드의 skip, limit, total로 화면의 페이지 번호를 계산합니다.
  • 조회 화면은 로딩, 오류, 빈 결과, 정상 결과를 모두 표현해야 합니다.

확인 퀴즈

검색 조건을 URL 쿼리 문자열에 두는 이유로 알맞지 않은 것은 무엇인가요?

URL에 두는 것은 화면 상태 관리 방법일 뿐이며 백엔드 검증은 여전히 필요합니다.

total이 23, limit이 10일 때 3쪽의 skip 값은 무엇인가요?

skip은 (페이지 - 1) x limit이므로 3쪽은 20입니다.
