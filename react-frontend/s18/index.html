S18. 배포와 발표

섹션 목표미니 프로젝트를 점검하고 자동 배포한 뒤 발표하며, 과정 전체를 회고하고 실습 자원을 정리합니다.

9일차 오후, 3시간, 파트마다 50분 학습과 10분 휴식

S18-P61 보안 점검과 S3 배포

점검표로 미니 프로젝트를 점검하고, 풀 리퀘스트 병합으로 S3에 자동 배포하며, 문제가 생기면 증상으로 원인을 찾을 수 있습니다.

  1. 점검표로 확인하기 실습, 20분
  2. 병합, 배포, 문제 해결 실습, 25분
  3. 정리: 보안 점검과 S3 배포 정리, 5분

S18-P62 프로젝트 발표

미니 프로젝트의 설계와 구현을 시연과 함께 발표하고, 다른 팀의 결과에 질문과 피드백을 줄 수 있습니다.

  1. 발표와 질의응답 실습, 45분
  2. 정리: 프로젝트 발표 정리, 5분

S18-P63 평가, 회고와 자원 정리

과정 전체를 돌아보고 확장 과제를 정하며, 실습에 만든 AWS 자원을 안전하게 정리할 수 있습니다.

  1. 회고 실습, 15분
  2. AWS 자원 정리 실습, 15분
  3. 과정을 마치며 주요 개념, 15분
  4. 정리: 평가, 회고와 자원 정리 정리, 5분
