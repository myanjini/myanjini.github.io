  • 다른 팀의 결과를 화면 상태, 권한, 캐시 갱신, 테스트 관점으로 살펴보고 피드백합니다.

확인 퀴즈

완성도는 정상 흐름보다 예외 상황 처리에서 드러납니다.

발표에서 CI 결과 화면을 보여 주는 이유는 무엇인가요?

자동화된 검사 결과는 품질을 객관적으로 보여 주는 근거입니다.
