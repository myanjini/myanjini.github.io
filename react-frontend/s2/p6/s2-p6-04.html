정리: 배열 메서드와 모듈

핵심 요약

  • map, filter, find, reduce는 원본을 바꾸지 않고 새 값을 돌려주며, 이어 쓰면 데이터 흐름이 드러납니다.
  • sort는 원본을 바꾸므로 복사본을 정렬하거나 toSorted를 씁니다.
  • 컴포넌트는 기본 내보내기, API와 도우미 함수는 이름 내보내기로 나눕니다.

확인 퀴즈

배열의 원본을 바꾸는 메서드는 무엇인가요?

sort는 배열 자체를 정렬합니다. 원본을 지키려면 복사본을 정렬하거나 toSorted를 씁니다.

export default function App()으로 내보낸 컴포넌트를 가져오는 코드는 무엇인가요?

기본 내보내기는 중괄호 없이 원하는 이름으로 가져옵니다.
