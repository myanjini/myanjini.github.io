정리: 변수, 함수, 객체와 배열

핵심 요약

  • 기본은 const, 바꿔야 할 때만 let을 쓰며, const라도 객체 내부는 바뀔 수 있습니다.
  • 구조 분해로 필요한 값만 꺼내고, 전개 문법으로 원본을 바꾸지 않는 복사본을 만듭니다.
  • ?.로 없는 값에 안전하게 접근하고, 0이 정상 값이면 || 대신 ??를 씁니다.

확인 퀴즈

const p = { skip: 0 }일 때 p.skip ?? 10의 결과는 무엇인가요?

??는 null과 undefined일 때만 오른쪽 값을 쓰므로 0은 그대로입니다.

원본 book을 바꾸지 않고 가격만 바꾼 새 객체를 만드는 코드는 무엇인가요?

전개 문법으로 복사본을 만들면서 일부 값만 바꿉니다. 대입만 하면 같은 객체를 가리킵니다.
