비동기 처리: Promise와 async/await

네트워크 요청은 시간이 걸리므로 결과가 바로 나오지 않습니다. JavaScript는 이런 작업을 Promise라는 "나중에 결과가 채워질 상자"로 표현합니다. async 함수 안에서 await를 쓰면 Promise의 결과가 나올 때까지 기다렸다가 다음 줄을 실행하므로, 비동기 코드를 위에서 아래로 읽히게 쓸 수 있습니다. 실패는 try...catch로 잡습니다.

function wait(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function demo() {
  try {
    console.log('요청 시작');
    await wait(1000);           // 1초 기다림 (네트워크 요청이라고 생각합니다)
    console.log('응답 도착');
  } catch (error) {
    console.error('실패:', error.message);
  } finally {
    console.log('성공과 실패에 상관없이 실행');
  }
}
demo();

여러 요청을 동시에 보내고 모두 끝날 때까지 기다릴 때는 Promise.all을 사용합니다. S8의 도서 수정 화면에서 저자 목록과 도서 정보를 함께 불러올 때 이 방법을 씁니다.
