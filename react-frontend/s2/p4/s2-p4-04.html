브라우저 콘솔에서 백엔드 JSON 다루기

  1. 브라우저 주소창에 http://127.0.0.1:8000/books?limit=3을 입력합니다. 화면에 JSON 텍스트가 그대로 보입니다. 이것이 백엔드가 보내는 실제 응답입니다.
  2. 같은 탭에서 개발자 도구의 Console 탭을 열고 다음 코드를 입력합니다. 지금은 페이지와 API의 주소가 같아서 문제없이 동작합니다. 주소가 다른 페이지에서 같은 코드를 실행하면 어떻게 되는지는 S4에서 확인합니다.
const response = await fetch('/books?limit=3');
const page = await response.json();
console.log(page.total, page.items.length);
console.table(page.items.map((b) => ({ id: b.id, title: b.title, author: b.author.name, price: b.price })));
  1. 다음 질문에 스스로 답해 봅니다.
    • page.total과 page.items.length가 다른 이유는 무엇입니까?
    • 전체 도서의 평균 가격을 구하려면 어떤 배열 메서드를 써야 합니까? 이 응답만으로 전체 평균을 구할 수 있습니까?
    • JSON.stringify(page.items[0], null, 2)의 결과에서 author는 어떤 모양입니까?
