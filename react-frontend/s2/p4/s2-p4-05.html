정리: 웹 프론트엔드 기초와 JSON

핵심 요약

  • 브라우저 화면은 DOM이며, React는 상태에 따라 DOM을 자동으로 맞추는 도구입니다.
  • JSON만 돌려주는 백엔드와 함께 쓰는 화면은 SPA 구조가 됩니다.
  • 요청 본문 형식은 JSON, 폼, 멀티파트 세 가지이며, API마다 요구하는 형식을 정확히 맞춰야 합니다.
  • JSON에는 날짜와 undefined가 없으므로 변환 과정에서 생기는 차이를 의식해야 합니다.
  • 구조 분해, 전개 문법, 옵셔널 체이닝, 배열 메서드, async/await는 이후 모든 코드의 기본 문법입니다.

확인 퀴즈

JSON.stringify({ a: 1, b: undefined })의 결과로 알맞은 것은 무엇인가요?

JSON에는 undefined가 없으므로 값이 undefined인 속성은 결과에서 빠집니다.

로그인 API POST /auth/token이 요구하는 본문 형식은 무엇인가요?

OAuth2 Password Flow를 따르므로 폼 형식으로 username과 password를 보냅니다.
