S2. 모던 JavaScript

섹션 목표React 코드를 읽고 쓰는 데 필요한 모던 JavaScript 문법을 백엔드 데이터로 연습합니다.

1일차 오후, 3시간, 파트마다 50분 학습과 10분 휴식

S2-P5 변수, 함수, 객체와 배열

const와 let, 화살표 함수, 구조 분해, 전개 문법, 옵셔널 체이닝을 사용할 수 있습니다.

  1. 변수와 함수 주요 개념, 15분
  2. 구조 분해, 전개, 옵셔널 체이닝 주요 개념, 15분
  3. 도서 객체 다루기 연습 실습, 15분
  4. 정리: 변수, 함수, 객체와 배열 정리, 5분

S2-P6 배열 메서드와 모듈

map, filter, reduce 같은 배열 메서드로 데이터를 가공하고, 모듈로 코드를 나누고 가져올 수 있습니다.

  1. 배열 메서드 주요 개념, 15분
  2. 모듈 주요 개념, 10분
  3. 백엔드 목록 데이터 가공하기 실습, 20분
  4. 정리: 배열 메서드와 모듈 정리, 5분

S2-P7 Promise와 async/await

비동기 처리의 원리를 이해하고 async/await와 Promise.all로 백엔드 요청을 다룰 수 있습니다.

  1. 비동기와 Promise 주요 개념, 15분
  2. async/await와 Promise.all 주요 개념, 10분
  3. 백엔드 요청을 순서대로, 동시에 보내기 실습, 20분
  4. 정리: Promise와 async/await 정리, 5분
