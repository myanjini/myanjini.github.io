정리: Promise와 async/await

핵심 요약

  • 시간이 걸리는 작업은 Promise로 표현되며, then/catch 또는 async/await와 try/catch로 다룹니다.
  • 서로 의존하지 않는 요청은 Promise.all로 동시에 보내 기다리는 시간을 줄입니다.
  • fetch는 404 같은 오류 응답도 정상적으로 돌려주므로 상태 코드를 직접 확인해야 합니다.

확인 퀴즈

다음 코드의 출력 순서로 알맞은 것은 무엇인가요? console.log('A'); setTimeout(() => console.log('B'), 0); console.log('C');

setTimeout은 0ms여도 함수를 예약만 하고 넘어가므로 지금 실행 중인 코드가 끝난 뒤에 B가 출력됩니다.

서로 의존하지 않는 요청 세 개를 가장 빨리 끝내는 방법은 무엇인가요?

Promise.all은 요청을 동시에 진행시키므로 가장 느린 요청만큼만 걸립니다.
