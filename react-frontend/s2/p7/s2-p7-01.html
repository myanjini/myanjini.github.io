비동기와 Promise

파트 목표비동기 처리의 원리를 이해하고 async/await와 Promise.all로 백엔드 요청을 다룰 수 있습니다.

네트워크 요청은 응답이 올 때까지 시간이 걸립니다. JavaScript가 응답을 기다리는 동안 멈춰 있으면 화면이 굳어 버리므로, 시간이 걸리는 작업은 "시작만 해 두고 결과가 나오면 알려 달라"는 비동기 방식으로 처리합니다.

console.log('1. 요청 시작');
setTimeout(() => console.log('3. 1초 뒤 실행'), 1000);
console.log('2. 기다리지 않고 바로 다음 줄');

출력 순서는 1, 2, 3입니다. setTimeout은 함수를 예약만 하고 바로 넘어가며, 1초 뒤에 예약한 함수가 실행됩니다.

Promise는 "나중에 결과가 채워질 상자"입니다. 처음에는 대기(pending) 상태이고, 작업이 끝나면 성공(fulfilled)이나 실패(rejected) 중 하나로 정해집니다. then으로 성공 결과를, catch로 실패를 받습니다.

function wait(ms) {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

fetch('/books?limit=1')            // Promise<Response>
  .then((res) => res.json())       // Promise<본문>
  .then((page) => console.log(page.total))
  .catch((err) => console.error('실패:', err.message))
  .finally(() => console.log('끝'));

fetch는 Promise를 돌려줍니다. 응답 객체의 json()도 본문을 끝까지 받아 해석해야 하므로 Promise를 돌려줍니다. 그래서 then이 두 번 이어집니다.
