async/await와 Promise.all

async 함수 안에서 await를 쓰면 Promise의 결과가 나올 때까지 기다렸다가 다음 줄을 실행합니다. 비동기 코드를 위에서 아래로 읽히게 쓸 수 있고, 실패는 try...catch로 잡습니다.

async function loadTotal() {
  try {
    const res = await fetch('/books?limit=1');
    const page = await res.json();
    return page.total;
  } catch (err) {
    console.error('실패:', err.message);
    return null;
  } finally {
    console.log('성공과 실패에 관계없이 실행');
  }
}

async 함수는 항상 Promise를 돌려줍니다. 그래서 loadTotal()의 결과를 쓰려면 다시 await하거나 then을 붙여야 합니다.

서로 기다릴 필요가 없는 요청 여러 개는 Promise.all로 동시에 보냅니다. 하나씩 await하면 시간이 더해지지만, 동시에 보내면 가장 느린 요청만큼만 걸립니다. 하나라도 실패하면 전체가 실패합니다.

const [booksRes, authorsRes] = await Promise.all([fetch('/books?limit=5'), fetch('/authors')]);
const [page, authors] = await Promise.all([booksRes.json(), authorsRes.json()]);
