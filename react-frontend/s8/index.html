S8. 인증 연동

섹션 목표JWT 토큰으로 로그인, 자동 재발급, 로그아웃, 역할에 따른 접근 제어를 구현합니다.

4일차 오후, 3시간, 파트마다 50분 학습과 10분 휴식

S8-P26 SPA 인증 흐름과 토큰 보관

액세스 토큰과 리프레시 토큰을 쓰는 SPA의 인증 흐름을 설명하고, 토큰 보관소와 인증 API 함수를 만들 수 있습니다.

  1. SPA의 인증 흐름 주요 개념, 20분
  2. 토큰 보관소와 인증 API 실습, 15분
  3. Console로 로그인 API 확인하기 실습, 10분
  4. 정리: SPA 인증 흐름과 토큰 보관 정리, 5분

S8-P27 인터셉터와 자동 재발급

axios 인터셉터로 모든 요청에 토큰을 붙이고, 만료 시 한 번만 재발급해 원래 요청을 다시 보낼 수 있습니다.

  1. 토큰 부착과 자동 재발급 실습, 30분
  2. 재발급 흐름 직접 확인하기 실습, 15분
  3. 정리: 인터셉터와 자동 재발급 정리, 5분

S8-P28 로그인 상태 공유와 접근 제어

Context로 로그인 상태를 공유하고, 로그인과 회원가입 화면, 역할에 따른 화면 접근 제어를 구현할 수 있습니다.

  1. 로그인 상태 공유: Context 실습, 20분
  2. 로그인과 회원가입 화면 실습, 10분
  3. 접근 제어와 인증 흐름 점검 실습, 15분
  4. 정리: 로그인 상태 공유와 접근 제어 정리, 5분
