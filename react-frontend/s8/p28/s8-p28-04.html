정리: 로그인 상태 공유와 접근 제어

핵심 요약

  • AuthProvider가 로그인 상태를 Context로 공유하고, 새로고침 후에는 재발급 흐름으로 상태를 복원합니다.
  • 로그인 오류 메시지는 하나로 통일하고, 429 잠금은 Retry-After로 안내하며, 이동 주소는 내부 경로만 허용합니다.
  • 메뉴 숨기기와 보호 라우트는 사용자 경험을 위한 장치이며, 실제 권한 검사는 백엔드가 합니다.

확인 퀴즈

프론트엔드에서 관리자 메뉴를 숨기는 것에 대한 설명으로 옳은 것은 무엇인가요?

프론트엔드 코드는 조작될 수 있으므로 권한 판단은 항상 백엔드가 합니다.

새로고침 직후 로그인 상태가 복원되는 과정으로 옳은 것은 무엇인가요?

메모리의 액세스 토큰은 사라지지만 sessionStorage의 리프레시 토큰으로 복원합니다.
