정리: SPA 인증 흐름과 토큰 보관

핵심 요약

  • 액세스 토큰은 API 호출에, 리프레시 토큰은 재발급에만 쓰며, 재발급 때 리프레시 토큰도 새로 받습니다.
  • 화면 코드는 토큰을 직접 다루지 않고 tokenStore를 통해서만 접근합니다.
  • 토큰을 보관하는 것만으로는 부족하며, 요청마다 Authorization 헤더로 보내야 합니다.

확인 퀴즈

리프레시 토큰의 용도로 옳은 것은 무엇인가요?

리프레시 토큰은 /auth/refresh에만 보내며, 노출 범위를 줄이기 위해 다른 요청에는 쓰지 않습니다.

토큰을 tokenStore로만 다루게 한 이유는 무엇인가요?
