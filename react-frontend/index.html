React로 만드는 도서 관리 프론트엔드와 관제 대시보드

FastAPI 백엔드 과정에서 만든 도서 관리 API를 사용자 화면으로 완성합니다. Vite와 React로 화면을 만들고, CORS와 인증, 개발 보안, 관제 대시보드를 거쳐 Docker로 통합 실행합니다. 섹션을 눌러 시작하세요.
